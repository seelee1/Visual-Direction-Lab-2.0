核心资产是具体视觉表现知识、案例与艺术判断；流程和应用载体服务于这些能力，最终形式不预设为 Skill。150 张知识卡和 120 张表现卡说明已整理的范围，不证明穷尽专业领域或获得艺术效果；全面性还需检验面对不同场景时能否主动提出具体、多样、协调且有表现力的方案。
