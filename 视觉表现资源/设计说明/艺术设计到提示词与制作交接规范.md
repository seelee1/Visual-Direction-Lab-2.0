# 艺术设计到提示词与制作交接规范

日期：2026-10-10。模型无关的文档规范候选，补足整体交付。与 v0.5 [最小输出约定](../../助手指令/共用内容/输出与信息保留.md)配合；不改写历史输入，不代表完整模型适配或制作已经验证。默认直接成稿仍有效，不要求向用户展示两阶段报告。

当前特定输出采用[Anima / MiniMax-H3 适配](../../助手指令/共用内容/输出适配/README.md)，完成艺术设计后再按其标签、字段和资产角色转换。格式规则不改变本规范的信息保留责任；具体工作流仍需实际核验。

## 转换对象与交付形式

艺术母版是选定作品的可见设计，不是隐藏思考、知识命中列表或待选技法集合。简单任务可以在创作中形成短母版并直接成稿；复杂设计、压缩比较或制作协作时，保存母版便于交接和修订。

| 目标交付 | 需要承载什么 | 可省略什么 |
|---|---|---|
| 连续视频提示词 | 可独立理解的主体、布局、事件、关键变化、关系、时间和形式 | 探索过程、章节分析、反复修饰 |
| 静态画面 | 同一时刻的空间、受光、材料、构图与观看重点 | 动作时间线和未发生的后续事件 |
| 分镜 | 各镜的观看职责、画面状态、衔接与时长关系 | 全片重复说明；不能暗中增镜解决单镜头约束 |
| 关键帧说明 | 可辨的起始、关键和结束状态以及帧间联系 | 与状态无关的研究解释；关键帧不是完整运动保证 |
| 分层或制作交接 | 对象职责、遮挡顺序、控制依赖、合成关系及损失 | 未核验的节点名称、工具能力和自动保证 |
| 具体模型适配版 | 经核验环境能接受的文本与控制材料 | 超出该环境的无依据承诺；母版另存 |

## 母版的最小信息

根据作品保留以下内容，允许自然段、分镜或简短表格；不是固定字段配额，也不要求普通用户填写。

- 用户明确要求及所选的合理创作条件。
- 观看重点与画面布局：重要对象、目标与空间关系在哪里可见。
- 关键状态或持续关系：开始怎样，哪些变化重要，结束或持续状态怎样。
- 决定表现的联系：参与对象、驱动或图形规则、可见结果以及必要条件。
- 风格与节奏：哪些线、色、影形、姿态或时间组织决定作品身份。
- 仅在实际制作时记录环境、控制分工、版本及允许的损失。

母版没有必要列遍专业领域。对安静或纯形式作品，保持、间隔与图底关系同样可以承担核心表现。

## 保留优先级

| 信息层 | 转换处理 |
|---|---|
| 用户约束 | 原样保留其意义；冲突先明确处理，不能以压缩为由改变 |
| 核心事件与关系 | 表达成画面句，保留对象、变化与联系，不只留术语 |
| 核心成立条件 | 保护必要的接触、连接、方向、观察位置、遮挡、照明或形式规则 |
| 形式与时间 | 保留决定辨认和体验的节奏、关键姿态、线色影形及信息先后 |
| 支撑与装饰 | 按作品贡献压缩、合并或删除 |
| 研究解释与创作评语 | 默认移出提示词；制作或研究任务另存 |

先压缩解释和重复，再压缩装饰；不能删掉关键条件后用“真实、细腻、复杂”补回字数。两项条件可合为一句画面关系，但不能互换驱动来源或参考系。

## 从概念到可见表达

以下是转换方法示例，不是所有作品的标准效果。它们为规范示范，没有新增模型运行或成片证据。

| 母版表达 | 连续画面表达 | 应保留的区别 |
|---|---|---|
| 稳定层衬托变化 | 固定机位，岸边石块的位置保持；薄雾依次遮住并显露石块间的暗色空隙 | 主体稳定与可见性变化不同 |
| 光独立承担事件 | 人物站在柱旁；窗外光源缓慢转向，斜光经窗框移过地面，再越过肩侧，柱影分开亮区 | 光源变化与人物越过固定光区不同 |
| 形式变化保留身份 | 墨色线群间距收窄，中央空隙逐渐组成同一个偏斜叶形；外缘仍断续，形状由负形被读出 | 图形显现与实体生长不同 |
| 两者共同运动 | 两人持续托住木板两端，前者引导板端进入门口，后者沿通行方向跟进；手位与板端保持联系 | 支撑关系不能只写成“默契配合” |

具体方案的尺度、照明或通行条件仍由当前设计决定。规范示例不能反过来替换用户的原作品。

## 压缩与长度冲突

先明确交付容量，优先让作品独立可读。可通过合并重复描述、缩短背景、相对位置与节奏表达来压缩，不为每层强行配置时间码。数值只在表达制作或艺术职责时保留，并具备参考尺度。

若容量不足以保护核心，保留完整母版，并标出短版实际损失或另分制作交接；不能宣称一份短提示词已经承载所有设计。没有模型或用户限制时不主动猜测一个通用最大长度。

### 可选的关系去向记录

研究和复杂交接可为核心关系赋予临时编号，逐项记录去向；编号不进入默认成稿，也不成为知识调用配额。

| 母版关系 | 成稿或控制位置 | 状态 | 损失与责任 |
|---|---|---|---|
| 当前设计的一项核心关系 | 对应画面句、关键帧或合成层 | 保留／改写／转交／丢失／待澄清 | 为什么改变，谁负责实现，需看什么证据 |

正常压缩解释不算核心丢失；保留同一词不等于保留同一关系。无法比较时标为待澄清，不自行补造母版原意。

## 母版存在冲突时

区分意图歧义、缺条件、无意矛盾和有意风格化。能在已授权设计范围内解决的，先修订母版并留版本差异，再转换。任务明确要求忠实转换时，实质冲突应简短指出或标成待处理，不能静默重构，也不能把原样复制冲突当作转换成功。

艺术上有意的错位、形变或非现实时间不必被纠正成写实。必要时明确图形层规则及作品保留项，使它与实体描述共存。修订的依据是当前关系，而不是永久禁止某种效果。

## Codex 与 ComfyUI 的交接边界

艺术设计先成立，再读取用户实际提供的生成环境。由 Codex 核对模型、工作流、输入输出、可用节点、参考图与控制职责；本项目没有已验证的节点清单或万能工作流，不能据本规范直接声称某个模型能执行细节。

制作交接可包含：母版和实现版、连续提示词、需要的参考画面、关键状态、分层职责、时长画幅要求、工作流版本以及生成后检查目标。哪个关系交给文本、参考图、关键帧、运动控制、分层合成或剪辑，依据实际环境选择；不固定每段都需要这些工具。

| 制作阶段 | 应保留的记录 |
|---|---|
| 环境核对 | 实际读取的配置、模型与工作流版本；未知项明确列出 |
| 适配 | 母版关系的实现去向，替代或省略的代价 |
| 生成 | 输入、参数、输出与失败；实际可记录项按环境保存 |
| 观看与修订 | 设计问题、转换损失、生成失真、控制或合成问题分别记录 |

单独文字不能保证脚部接触、空间连续、投影或材料状态。生成后必须观察实际结果；这里是交接责任约定，不是已经完成的自动制作能力。
