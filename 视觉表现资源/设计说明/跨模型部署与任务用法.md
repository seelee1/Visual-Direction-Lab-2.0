# 跨模型部署与任务用法

日期：2026-10-10。使用现有 v0.5 内容，不新建平台专属创作规则。平台入口和容量会变化；以下把已核对的产品行为与本项目建议区分，不承诺所有账号均有相同功能。

## 选择一个使用版本

当前生图用[Anima 单文件版](../../助手指令/Anima.md)，视频用[MiniMax-H3 单文件版](../../助手指令/MiniMax-H3.md)；或选择一个通用包，再只加载对应模型的[适配文件](../../助手指令/共用内容/输出适配/README.md)。两适配独立管理，生图与视频只支持这两个目标，创作 LLM 仍可按本页部署。

| 用法 | 选择 | 适合情况 |
|---|---|---|
| 轻量创作 | [核心指令](../../助手指令/共用内容/核心指令.md) | 主要调动模型自身知识，可单独使用 |
| 单文件基础 | [基础版](../../历史归档/单文件版本/VDL-v0.5-基础版.md) | 核心、广域激活与输出约定一起复制 |
| 单文件扩展 | [扩展版](../../历史归档/单文件版本/VDL-v0.5-扩展版.md) | 更具体的运动物理、关系及风格入口 |
| 单文件深化 | [深化版](../../历史归档/单文件版本/VDL-v0.5-深化版.md) | 增加变体、过程、观察形式与日漫发展 |
| 模块化 | 核心＋[路由](../资源路由.md)＋相关资源 | 能实际提供附件、检索或上下文时，按任务选择 |

三个单文件版择一，也不要把整包再与同一套核心、模块重复加载。更长不保证更好。平台不能读取本地相对链接时，必须提供对应正文或文件；只贴路由不是知识已经装载。

## ChatGPT 项目

官方说明：项目可共享指令、上传文件与连接来源；ChatGPT 项目并不直接获得本地目录访问。[Projects and chats](https://learn.chatgpt.com/docs/projects?surface=app)（2026-10-10 核对）。

本项目建议：把核心正文作为项目创作要求，提供输出约定、路由与需要的构思资源；或者只提供一个单文件包并要求按其正文创作。容量不足时保留核心和相关材料，不把报告或全部研究卡强行塞入指令。用项目内的新创作会话输入简单创意。不同作品可另开会话，避免旧方案被当作新任务事实。

附件读取、检索命中和实际上下文不能仅凭上传成功推断。先用一个任务检查是否能理解明确要求与关键关系；要诊断加载时可另要求确认实际可访问文件，日常作品无需附命中列表。

## DeepSeek 与其他聊天模型

若平台没有可配置的系统或项目指令入口，将选定使用包正文作为当前会话起始要求，再提供创意；有入口时按其实际支持的方式装载。不要假定各平台角色优先级、持久记忆或文件读取方式相同。

本项目已有 DeepSeek 网页实测，采用新会话、正文装载、深度思考开、搜索关；后台版本未知。这是测试配置，不是所有创作的强制模式，也不证明其他模型等效。切换搜索、思考或版本时，验证记录应分开。

## API 或自建助手

通用配置将持久创作责任与每次任务分开，知识资源作为明确上下文提供。消息角色与附件格式必须按实际供应商接口映射；仓库中的测试 JSON 是冻结记录，不能当作任意 API 的即用请求。

OpenAI 官方指南说明可用 `instructions` 或消息角色表达要求，`developer` 与 `user` 职责不同。[Prompt engineering](https://developers.openai.com/api/docs/guides/prompt-engineering)（2026-10-10 核对）。具体实现按所用 API 选择入口，保存实际发送的指令、任务及资源；不能从这一说明推导其他供应商完全相同。

本项目没有附带 API 调用程序、凭据或默认模型。密钥由部署环境保管，不放入提示词、实验文件或仓库。版本、可控生成参数、截断和重试只记录实际可取得的内容。

## 普通用户输入示例

这些是任务入口，不是固定创作答案：

- “设计一个少女站在雨中的日漫镜头，直接给完整连续提示词。”
- “同一创意给我观看重点实质不同的方案，再选择一个展开。”
- “设计一幅静态水墨画，不要添加时间线。”
- “将这份母版转成短提示词，另外记录核心关系的损失。”
- “根据已有设计做分镜，保留原事件与空间方向。”

用户有时长、景别、风格、画外目标或禁用项时直接补充。没有专业语言也应能开始。助手根据任务决定是否澄清，不把普通用户引入专业问卷。

## 与 Codex、ComfyUI 协作

先把选定母版和[制作交接规范](艺术设计到提示词与制作交接规范.md)交给执行环境。Codex 负责读取实际工作流和配置、选择控制方式并保存实现差异；艺术助手负责保留作品关系，不提前迁就猜测限制。

当前没有已读取并验证的 ComfyUI 工作流或已生成视频。需用户实际提供环境后才能确认节点、模型和控制分工。文字交接、工作流可执行与成片有效是三个不同验收对象。

## 版本与材料范围

使用记录至少说明包名或核心版本、装载资源、模型/平台与任务。可访问文件不等于实际调用；参数未知可以留空。创作材料通常从 `模型使用/` 或一个发布包选取；完整转换规范按交接需要另提供。

`研究资料/` 是深入参考，`评估/` 是诊断记录，`维护/` 是版本资料。这些不默认进入创作上下文。历史 v0.1 指令不要与当前核心并用；旧冻结实验保持原输入。完整交付与未验证范围见[当前状态](整体交付与当前状态.md)。
