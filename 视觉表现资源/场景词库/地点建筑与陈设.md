# 地点、建筑与陈设词库

名称用于唤起模型已有的场景知识；每个地点都可有不同尺度、布局、文化和使用状态。英文是语义入口，不保证为模型标签。先发展有贡献的结构，再选局部细节，不逐行组装背景。

## 城乡与公共地点

| 名称／英文入口 | 可见展开 | 组合关系 |
|---|---|---|
| 住宅街／residential street | 建筑、道路、入口与日常设施的组织 | 高低、退界、密度与交通方式可不同 |
| 巷道／alley, lane | 较窄通行空间与两侧边界 | 转折、坡度、开口和生活痕迹发展纵深 |
| 商业街／shopping street | 店面、通行与停留区域 | 店面密度、开合和街道尺度共同决定 |
| 广场／plaza, square | 开敞地面与周边围合 | 中心、边缘、出入口与使用方式不必相同 |
| 市场／market | 摊位、货物、遮棚与通道 | 不默认密集杂乱，经营方式与时间可变化 |
| 路口／intersection | 路线交汇、边界与交通设施 | 视线、方向、等待区与人物行动相容 |
| 车站、站台／station, platform | 交通空间、候车与上下层连接 | 铁路、公交等具体用途决定结构 |
| 码头／pier, wharf | 陆地、水面、装卸或停留设施 | 高差、系泊、栈道与使用方式明确 |
| 天桥、地下通道／footbridge, underpass | 穿越路线与高差 | 入口、台阶、围护和光区延续 |
| 停车场、车库／parking area, garage | 车辆、通道、停放与覆盖结构 | 空置与有人使用可产生不同空间组织 |
| 公园／park | 路径、开放地、植被与停留设施 | 自然或规则布局均可，非固定花园套餐 |
| 庭院／courtyard | 建筑或边界围合的开放空间 | 开口、铺地、阴影与内部用途配合 |
| 花园／garden | 种植、路径、围合与观赏组织 | 风格、季节、维护和密度可不同 |
| 屋顶空间／rooftop | 地面、围护、设备及远景 | 可供活动与不可达区域分开 |
| 村落／village | 建筑群、道路、地形与生活用途 | 不只缩小城市，也不统一破旧材料 |
| 农场／farmstead | 居住、工作、储藏与生产空间 | 土地利用和动线决定设施关系 |
| 田地、果园／field, orchard | 种植分布、边界、路线与季相 | 作物尺度和地形、维护配合 |
| 工业区／industrial area | 厂房、设备、运输与围合 | 不只烟囱和管道，具体用途决定布局 |
| 遗址、废墟／ruins | 原结构残余、断面与后续环境 | 可识别用途、塌落与新生植被分别发展 |
| 宗教或仪式场所／religious, ceremonial site | 场所用途、结构和活动区域 | 具体文化与参考明确，不任意混合标志性符号 |

## 室内用途

| 名称／英文入口 | 可见展开 | 组合关系 |
|---|---|---|
| 卧室／bedroom | 休息、收纳与私人活动空间 | 床、窗、门和使用路径可多种安排 |
| 客厅／living room | 坐席、共同活动与通行 | 不只把沙发放在画面中央 |
| 厨房／kitchen | 操作、清洁、储藏与器具 | 不同规模、文化和用途决定工作区 |
| 浴室／bathroom | 洗浴、排水、通风与物件 | 干湿区和材质状态有位置差异 |
| 玄关／entrance hall | 室外与室内的过渡 | 高差、换鞋、收纳与门向按设计决定 |
| 走廊／corridor | 房间、开口和行进路线 | 长短、转折与光区可组织观看 |
| 楼梯间／stairwell | 台阶、平台、上下层与围护 | 连续路径与层高共同成立 |
| 阁楼、地下室／attic, basement | 屋顶或地下结构限制的空间 | 斜面、高差、开口与用途另选 |
| 教室／classroom | 教学、座席、板面与通行 | 年龄、时期、教学方式不同，不固定桌椅阵列 |
| 图书馆／library | 书架、阅读、查找和通行 | 架高、密度、坐席与采光共同设计 |
| 书店／bookshop | 陈列、购买与停留 | 与图书馆功能和布局分别考虑 |
| 咖啡店、餐厅／café, restaurant | 服务、坐席、操作与入口 | 不自动加入同一暖灯木桌组合 |
| 店铺／shop interior | 商品、陈列、操作与顾客路线 | 类型和经营方式决定陈设 |
| 办公室／office | 工作、会议、储藏与交通 | 开放、独立与混合空间可不同 |
| 工作室／studio | 创作、工具、材料与作品存放 | 绘画、音乐、手工等各有组织 |
| 实验室／laboratory | 操作台、设备、通行与分区 | 按具体用途设计，不凭空声明设施性能 |
| 工坊／workshop | 工作台、材料与加工设备 | 清洁、磨损、储藏和活动空间配合 |
| 温室／greenhouse | 透明围护、种植、通道与水分 | 骨架、玻璃状态、植被密度和光影关系 |
| 仓库／warehouse | 物资、搬运与储藏体系 | 堆放高度、通道与使用状态明确 |
| 展厅、舞台、剧场／gallery, stage, theater | 展示或表演与观看区域 | 幕后、坐席、灯光与可见边界可不同 |

## 建筑部件与形状

| 名称／英文入口 | 可见结构 | 变化与组合 |
|---|---|---|
| 立面／facade | 建筑朝向观察者的外部组织 | 开口、分段、材料和体量共同决定 |
| 拱、拱廊／arch, arcade | 开口或重复支撑形成的轮廓 | 与真实承重、装饰性用法和风格分开 |
| 柱、柱廊／column, colonnade | 竖向支撑与重复排列 | 柱距、层次、视线与通行共同设计 |
| 门廊、檐下／porch, space beneath eaves | 建筑与外部的遮蔽过渡 | 光区、天气与人物停留关系 |
| 雨棚、遮阳篷／canopy, awning | 开口或活动区域的上部覆盖 | 固定方式、材质、坡度和环境响应 |
| 屋檐、女儿墙／eaves, parapet | 屋顶末端或边缘围护 | 两者位置与用途不同，不机械合并 |
| 坡屋顶、平屋顶／pitched, flat roof | 屋顶主要体量与轮廓 | 坡度、排水和建筑群体关系 |
| 天窗／skylight | 屋顶开口与采光方向 | 透射、框架和天气影响可见状态 |
| 窗、窗台／window, windowsill | 开口、玻璃、框和内外边界 | 不同窗向不默认受同一直接光源照射 |
| 百叶、格栅／louvers, lattice | 分段遮挡与透隙 | 材料、方向、密度和光影共同设计 |
| 门、门框／door, door frame | 开口、开合和通行边界 | 转轴、推拉方向及活动空间明确 |
| 阳台、露台／balcony, terrace | 与建筑或地形相接的外部平台 | 高差、围护、支撑与用途不同 |
| 台阶、平台／steps, landing | 路线中的高度变化和停留区 | 台阶数量可概括，路径不能无意断开 |
| 栏杆、扶手／railing, handrail | 围护、接触与引导 | 位置、高度、材质和重复组织 |
| 中庭、挑空／atrium, double-height space | 垂直开放空间与周围层次 | 视线、层高和可见楼层相互支持 |
| 隔断、壁龛／partition, niche | 分区或墙内局部空间 | 不同结构与陈设、遮挡和采光配合 |
| 天花、梁、桁架／ceiling, beam, truss | 上部结构与形状组织 | 风格与跨度明确，不只增加乱线 |
| 石砌、砖砌、抹面／stonework, brickwork, plaster finish | 墙体和表面组织的不同入口 | 接缝尺度、边缘、磨损与光线配合 |
| 木、金属、玻璃构件／timber, metal, glass elements | 分区材料与接合方式 | 不把整个建筑涂成单一材料效果 |
| 建筑风格方向／architectural language | 整体比例、构件、材料与空间组织 | 历史、文化或幻想名称需落实，不只加装饰符号 |

## 家具、陈设与环境细节

| 名称／英文入口 | 可见展开 | 组合关系 |
|---|---|---|
| 桌、椅、凳／table, chair, stool | 支撑、工作或坐姿接点 | 尺度、结构和人物姿态配合 |
| 床、沙发／bed, sofa | 休息体量、软面与空间占用 | 使用、压叠、覆盖和通行关系 |
| 柜、架、箱／cabinet, shelf, storage box | 收纳、开合、重复与堆叠 | 物件类型与取用路径决定位置 |
| 灯具／light fixture | 固定点、光源形状与照明范围 | 外观和实际发光状态分开 |
| 窗帘、帘幕／curtains, drapery | 悬挂、褶量、遮挡和光透 | 厚薄、收束与风的响应 |
| 地毯、织物覆盖／rug, textile covering | 区域边界与表面层 | 与地面材料、家具压痕和配色关系 |
| 书、纸张、画作／books, papers, pictures | 摆放、尺度与使用痕迹 | 文字需要时单独明确，不用乱码当装饰 |
| 器皿、餐具、容器／vessels, tableware, containers | 功能、口部、材质和摆放 | 接触与使用关系比随机散布更有贡献 |
| 植物盆器、花架／plant pots, plant stands | 生长、容器与支撑 | 采光、水分和用途可组织分布 |
| 路灯、标牌、长椅／streetlights, signs, benches | 公共空间中的尺度与功能 | 位置、文字及可见程度按任务选择 |
| 电线、管道、排水设施／wires, pipes, drainage | 连接、走向与用途 | 不随机穿过出入口或人物行动路线 |
| 栅栏、围墙、界石／fence, boundary wall, boundary marker | 分隔与通过的关系 | 材质、高度、缺口与地形配合 |
| 门牌、张贴物、标记／number plate, posted notice, marking | 局部身份或使用信息 | 是否可读、内容和时代语境另选 |
| 工具与维护物／tools, maintenance items | 活动与整理的可见证据 | 选择使用区域，不到处平均堆放 |

空间与生活痕迹继续调用[空间状态词库](空间状态与特殊背景.md)。建筑观察可深入[V&A 的建筑空间介绍](https://www.vam.ac.uk/articles/va-trail-architectural-wonders)，整体设计回到[场景入口](../13-场景设计与背景组合.md)。
