# 自然环境与地貌词库

地形、水域、植被、地表和天空共同决定场所。名称提供联想入口，不是生态分类全集。选择尺度、分布、连接与可见状态；需要真实地区或物种准确性时依据具体参考，幻想环境可以自主发展统一规则。

## 地形与自然场所

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 平原／plain | 较开敞地面与远处地平关系 | 植被、道路和地表起伏可组织尺度 |
| 丘陵／hills | 起伏体量与交叠轮廓 | 坡向、密度、植被和观看位置不同 |
| 山脉、山脊／mountain range, ridge | 连续高差、脊线与体量层次 | 不只重复三角形山头 |
| 山谷／valley | 两侧地形与内部路线 | 河流、道路、聚落及高差可不同 |
| 峡谷／canyon, gorge | 较强的侧壁、高差与狭长空间 | 岩层、通路、底部尺度与光区配合 |
| 高原／plateau | 高处相对开敞的地形体量 | 边缘、坡面和远景连接可展开 |
| 悬崖／cliff | 地形显著断落与边缘 | 支撑、深度、材料和观察位置明确 |
| 洞穴／cave | 入口、内部体积与光暗连接 | 地面、顶壁、深处路径与材质配合 |
| 沙丘／dunes | 沙面体量、脊线与风向组织 | 不同时将所有表面画成硬岩折面 |
| 荒漠／desert landscape | 干旱环境的地形、地表与稀疏分布 | 不只有沙海，也可岩地或其他地表 |
| 草原／grassland | 大尺度草本分布与开敞空间 | 高矮、密度、季相和地形共同设计 |
| 林缘、林间空地／forest edge, clearing | 密林与开放区域的过渡 | 光、低植被、路径与视线关系 |
| 岩岸、沙岸／rocky coast, sandy beach | 陆地、水体与岸线形态 | 近处接触、浪区与远景分别发展 |
| 海岛／island | 陆地体量与周围水域 | 地形、岸线、植被和人类活动可不同 |
| 雪原、冰面／snowfield, ice surface | 覆盖或冻结的地表 | 起伏、裂隙、积累、足迹与反光分别设计 |
| 火山、熔岩地／volcanic, lava landscape | 地形、岩石与可能的热过程 | 已冷却地表与持续熔融状态不混用 |

## 水域与岸边

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 溪流／stream | 小尺度水流、岸边与地形 | 水深、流向、石块和植被关系 |
| 河流／river | 水面、河道、岸与周边利用 | 宽度、弯曲、流态和水位可不同 |
| 湖泊／lake | 水域边界、远岸与地形 | 不必静止镜面，风与观察角度影响表面 |
| 池塘／pond | 较小水域与近处岸边 | 植被、用途、水位与环境关系 |
| 瀑布／waterfall | 高差、水流落点与下部水域 | 分段、飞溅、介质和尺度配合 |
| 海面／sea surface | 开敞水域、波形与天空关系 | 风、波、视距与光线共同成立 |
| 潮间带／intertidal zone | 岸边干湿与水位变化的区域 | 露出地表和残留水体按当前状态选择 |
| 湿地／wetland | 水、饱和地面与植被的组合 | 不简单等同深水湖或每处都有泥浆 |
| 草本湿地／marsh | 水地与草本植被关系 | 水深、分布和地域差异可展开 |
| 林木湿地／swamp | 林木与湿润地面的关系 | 植被、水面和通路有区域差异 |
| 泥炭湿地／peatland | 地表、植被与湿润组织入口 | bog、fen 等细分类按需要核对，不凭颜色判断 |
| 水洼、暂时积水／puddle, temporary standing water | 局部低洼、水边与地面 | 汇集、干湿、反射和使用痕迹配合 |
| 水下环境／underwater setting | 水体、地形、植物与观察条件 | 深度、悬浮物、光与运动尺度共同设计 |

## 植被与生长结构

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 阔叶林、针叶林／broadleaf, conifer forest | 树形、冠层与分布的方向入口 | 实际物种、密度与季相另选 |
| 混合林／mixed forest | 不同树形和尺度的共同组织 | 不随机放置互不关联的所有树种 |
| 竹林／bamboo grove | 竿、节、叶与群体分布 | 疏密、高低、根部和路径关系 |
| 棕榈方向植被／palm vegetation | 树干与冠叶组织 | 地区与物种变化大，不只重复同一剪影 |
| 灌丛／shrubland, shrubs | 较低木本体量与地表关系 | 边缘、分布、枝叶与开口 |
| 高草、低草／tall, short grasses | 草本高度与群体覆盖 | 风响应、路径、踩压与地形配合 |
| 藤蔓／vines | 生长与依附、悬垂的关系 | 根部、支撑和覆盖范围可辨 |
| 苔藓／moss | 小尺度表面覆盖 | 水分、朝向、材质与分布有关 |
| 花丛、花地／flower beds, flowering patches | 花叶、色块和生长密度 | 不均匀撒满每层，也不把花作为浮空粒子 |
| 地被、落叶层／ground cover, leaf litter | 地表组织与覆盖 | 缺口、厚度、材质和季相不同 |
| 树根、倒木、树桩／roots, fallen logs, stumps | 生长或残留结构与接触 | 支撑、分解、植被与地形联系 |
| 冠层、枝隙／canopy, gaps between branches | 上部覆盖与透隙 | 光区、天空显露和远近层次 |
| 新芽、开花、结果、枯落／buds, bloom, fruiting, dieback | 当前生长状态的形态 | 地区、时间和物种明确，不默认同株全阶段齐全 |

## 地表与天空

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 土地、泥地／soil, mud | 颗粒、湿度、压痕与表面组织 | 不同材料与干湿分区 |
| 沙、砾石、卵石／sand, gravel, pebbles | 不同尺度颗粒的排列 | 路径、坡度、流动与接触关系 |
| 岩层、裂隙／rock strata, fissures | 岩体方向、分段与断面 | 大体量、局部纹理与风化层级 |
| 雪、霜、冰／snow, frost, ice | 覆盖、结晶或冻结的不同形态 | 不把三者当同一白色涂层 |
| 云层、云隙／cloud cover, cloud openings | 天空体量、分布与透光区域 | 与地面光区及当前风向组织相关 |
| 晴空、薄霾／clear sky, light haze | 天空与远距空气的当前状态 | 明度、色彩和视距关系，而非默认加滤镜 |
| 晨昏天空／dawn, dusk sky | 太阳位置、天色与地面明暗关系 | 不把所有晨昏都画成同样橙紫渐变 |
| 夜空／night sky | 天空明度、星月及环境光 | 不必每夜都有银河与满月 |
| 天空反射与水中倒影／sky reflection, landscape reflection | 环境与水面的对应关系 | 波形、视角、遮挡改变形状，不简单复制整个场景 |
