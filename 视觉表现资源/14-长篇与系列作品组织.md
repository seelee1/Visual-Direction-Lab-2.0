# 长篇与系列作品组织

用于跨场景视频、长篇动画、连载漫画、系列插画与连续商业作品。调用叙事、人物发展、段落节奏、连续性与系列美术知识。长篇不是把很多漂亮单镜头串起来；系列也不必有剧情，可以由主题、观察、形式或变化组织。

## 作品、段落与画面的接力

先判断作品靠什么持续：行动与后果、人物关系、信息揭示、环境过程、观念对照或纯形式发展。用户已有故事时保留核心事实与发展范围；只有视觉创意时可以合理构思，不自动补危险、反派、对白或标准三幕剧情。

| 激活方向 | 具体发展 | 判断重点 |
|---|---|---|
| 全片与章节结构 | 起势、积累、转折、释放、余韵、循环、开放结束或并置 | 结构服务作品，不为固定节点硬添事件 |
| 场景进入与离开 | 从什么状态进入，哪些变化值得观看，何时离开 | 不均匀铺满每段的起因经过结果 |
| 因果与状态后果 | 一个行动怎样改变人物、环境、资源或下一步选择 | 不能每场结束就清空伤痕、物件、湿态或关系 |
| 多线与视点 | 谁在何处、何时发生、观众暂时跟随谁 | 交替出现不自动意味着同时发生 |
| 信息与期待 | 埋设、暗示、迟延、重新理解、兑现或有意未解 | 未给观众的信息不能当成已经知道 |
| 主线与支线 | 支线如何改变主线、人物理解或作品形式 | 不要求所有支线最后都汇合，但不能无意遗忘 |
| 重复与变体 | 同一动作、地点、构图、声音或物件再次出现 | 差异来自关系与状态，不只换滤镜 |
| 转场与场景桥接 | 行动、图形、空间、声音、时间或主题承担衔接 | 不为每次换场安排花哨转场 |
| 非叙事系列 | 光色、材料、尺度、形式或观察方式渐变与对照 | 不强迫每个作品都有冲突和人物成长 |

单镜与镜头组的具体发展调用[分镜资源](11-分镜与镜头组织发展.md)。这里决定各段为何相接，不重新复制所有景别与剪辑技法。

## 人物发展与关系变化

调用目标、需要、欲望、信念、习惯、矛盾、选择、代价、回避与重新行动。人物可以改变、保持、反复、受限或逐渐被观众理解；不是每个角色必须完成成长弧。

将发展落实到可见行为与选择：此前先整理自己的物件，后来先替他人留出空间；同一门口从犹疑到直接进入；关系变化使两人在同一画面中的距离和行动顺序不同。动作、服饰、光色和场景可协作，但不把每个变化都强加心理象征。

群像发展不同的行动方式、所知信息和关系位置，不仅给每人一个颜色标签。事件后果与人物感受不必同时达到峰值；让反应、行动和观看有自己的时间。用户给定人物时不能为满足剧情模板改性格、改经历或增添动机。

## 整体节奏与观看负担

调用段落长度、事件密度、信息负担、空间变化、动作强度、反应时间与回顾机会。快动作、快剪、短场景和高信息密度分别判断；全片都高强度会丢失对比，但安静段也不必被当作填充。

重要变化留出理解与感受时间；场景转移可用简洁锚点恢复方向，不必每次重新全景交代。重复段落可以建立韵律，也可通过删减或错位制造差异。视频按总时长分配段落，漫画按页与阅读单元组织，系列插画按幅间关系组织；不能用同一套秒数强行换算。

## 长期视觉语言

分别维护人物轮廓与身份、地点与物件结构、线色影形、材质简化、构图习惯和时空规则。统一不等于所有场景同一配色、同一镜位；白天夜晚、不同章节或人物视点可以变化，但变化有明确作品理由。

调用视觉母题的建立、弱化、回归、反转与变体。保持系列中最有价值的少量锚点，不让每件物品都成为符号。商业系列可共享主体比例、背景语言、构图网格与文字位置，同时发展各幅的用途和差异。

## 连续性：稳定事实与可变状态

只记录当前作品需要延续的内容，避免重复巨型设定书。

共同方向、当前方案、备选与修改后的交付版本统一按[作品组织](../助手指令/创作规范/作品组织.md)管理；本模块负责长篇的叙事、节奏与连续发展，不另建第二套作品档案。

| 内容 | 保存什么 | 可以怎样变化 |
|---|---|---|
| 已确认事实 | 用户事实、已选人物、地点、世界与事件关系 | 实质修改要同步相关设计，不暗中重写过去 |
| 身份与视觉锚点 | 脸与比例、发型分区、标志配件、场景地标、形式规则 | 视角、光线和画法简化可变化，身份不能漂移 |
| 当前状态 | 位置、朝向、持物、衣物、湿态、损伤、时间与进行中的过程 | 后续变化有来由；省略可以保留足够理解证据 |
| 人物与观众所知 | 谁看见或听见了什么，哪些揭示尚未发生 | 叙述顺序可变，但不让人物凭空知道信息 |
| 承诺与后续关系 | 已建立的期待、重要物件、未完成行动与计划内回应 | 可有意开放或转向，避免无意遗漏 |

未确定的候选与已经选定的设计分开。继续作品时先取得相关段落和最新状态；缺失信息不能靠猜测冒充已经建立的设定。可以在授权范围内明确补足，不让普通用户先填写完整世界观。

## 默认交付与制作交接

用户要求整部设计而未指定格式时，交付简短整体方向、必要的连续设定，以及下表。需要执行的段落再展开为分镜或漫画，不机械一次输出全片每个细节；用户明确要完整分镜时覆盖全片，不用只做第一场代替完成。

| 段落／场景 | 时间或篇幅 | 可见事件与关系变化 | 前后接力与需延续的状态 |
|---|---|---|---|
| 编号及地点 | 视频时间段、漫画页范围或系列幅号 | 当前作品实际发生与值得观看的变化 | 从上一段继承什么，向下一段留下什么 |

视频总时长与各段相接，页码或幅号连续，估计值明确标注。人物发展、伏笔和风格解释只在有用时另列，不为表格增加永久必填列。

制作时分别保存段落设计、镜头、关键画格、生成片段和最终剪辑的对应关系。每次生成只取得相关连续设定与当前段落信息，但该片段的提示词应能独立理解，不能依赖生成模型读取先前聊天。文字、参考图、首尾状态、分层与剪辑各自承担什么，依据实际工具选择，不能仅凭相同种子承诺身份一致。

改一个场景时，检查受影响的后续状态、信息、时间与素材；未受影响的设计无需重新发明。声音连续、转场接点、环境变化阶段与长短镜头切换要进入交接。母版的理想设计先成立，实现分段和损失另记；不提前按单次生成时长限制写故事。模型生成不等于最终合成完成。
