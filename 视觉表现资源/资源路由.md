# 资源路由 v0.5

从场景中的关系和希望发展的表现出发查找。模型可以首先运用自身知识，再按需要读资源；不要求依次遍历。链接仅是位置，只有实际取得内容才算加载。

## 使用

沿当前有价值的关系深入，可读取相关完整章节，不全表执行。没有合适入口时继续使用自身知识；具体表现卡、专业来源和案例只在需要时取得。研究与验证记录不进入默认创作上下文。
