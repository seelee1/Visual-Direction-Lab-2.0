# 资源路由 v0.5

从场景中的关系和希望发展的表现出发查找。模型可以首先运用自身知识，再按需要读资源；不要求依次遍历。链接仅是位置，只有实际取得内容才算加载。

| 创作线索或当前不足 | 优先构思资源 | 可继续深入的既有材料 |
|---|---|---|
| 日常行动说得出，但身体协调、衣发、材料或空间过程难以描述 | [人类视觉语言库](../人类视觉语言库/日常经验索引.md) | 按关系条目进入已有专业卡，不默认全库装载 |
| 输入简单、首稿常规、想打开表现范围 | [视觉激活地图](01-视觉表现激活地图.md) | [表现库导读](../参考资料/表现库/00-表现库导读.md) |
| 长篇、连载、系列、跨场景叙事或整片节奏与一致性 | [长篇与系列作品组织](14-长篇与系列作品组织.md) | 分镜、人物、场景资源按当前段落组合；连续设定不全库重复 |

| 海报、封面、标题卡、字幕或文字版式 | 专门用途的文字版式章节 | 漫画文字与页面阅读、静态观看路径 |
| 信息图、机制解释、流程或动态数据说明 | 专门用途的信息图章节 | 准确数据、语义编码、阅读顺序与时间揭示 |

| 纯背景、立绘、海报、梦境或特殊空间 | 场景入口及空间状态中的特殊与非叙事背景 | 用户指定无人或纯图形时保持，不强制加入人物或真实地点 |
| 人物只有普通外貌标签，想创造或延续有辨识度的角色 | [人物设计与外观组合](12-人物设计与外观组合.md) | 按实际部位选择身体面貌、发型或服装词库，不全库加载 |
| 发型、服装名称抽象，或元素很多但无法形成一个人 | 人物资源中的名称展开、轮廓、穿着与身份关系 | [发型](人物外观词库/发型与毛发.md)、[服装与配件](人物外观词库/服装与配件.md)、[身体与面貌](人物外观词库/身体与面貌.md) |
| 角色二创、换装，或设计过度受原设限制 | [人物设计](12-人物设计与外观组合.md)中的创作任务与参考职责 | [艺术方向](10-艺术风格与审美方向发展.md)；服装参考与身份参考分别使用 |
| 人物描述只有部位名，缺比例、表情、视线或姿态关系 | [状态与关系词库](人物外观词库/状态与关系.md) | 身体面貌中的局部形态及既有表演资源 |
| 特殊年龄、身体差异、兽人、机械或非实体人物 | [特殊人物与非人设计](人物外观词库/特殊人物与非人设计.md) | 运动物理、生物机械、二维与风格资源 |
| 服装类别太普通，或要职业、运动、历史文化和完整穿搭 | [服饰语境与穿搭](人物外观词库/服饰语境与穿搭.md) | 服装结构词库；忠实复现按具体时期与参考深入 |
| 画面细节具体，但整体艺术语言常规或只有风格标签 | [艺术风格与审美方向发展](10-艺术风格与审美方向发展.md) | 结合静态表现、二维转译或具体事件关系落实风格 |

| 多风格像拼贴、系列只有统一滤镜、时代符号彼此无联系 | 高层风格资源中的分层融合、世界语言与个人语言 | 必要历史事实另核对，幻想融合保留明确艺术规则 |
| 插画只有漂亮人物与背景，空间、造型或整体关系展开不足 | [画面深度与静态表现发展](09-画面深度与静态表现发展.md) | [空间](../参考资料/表现库/V03-空间与观察.md)、[构图色彩](../参考资料/表现库/V12-构图与色彩发展.md) |

| 想发展造型魅力、材质区别、观看路径与细节层次 | 静态表现资源中的形、观看、材料、尺度与媒介入口 | [观察与形式](07-观察证据与视觉形式.md)、[二维发展](08-日式二维的多种表现发展.md) |

## 使用

沿当前有价值的关系深入，可读取相关完整章节，不全表执行。没有合适入口时继续使用自身知识；具体表现卡、专业来源和案例只在需要时取得。研究与验证记录不进入默认创作上下文。
