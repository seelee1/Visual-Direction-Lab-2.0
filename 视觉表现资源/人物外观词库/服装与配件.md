# 服装与配件词库

衣服类别、廓形、局部结构、材料、穿着状态与配件可以组合。先决定穿着者和整体形状，再选择值得展开的部件。英文是描述入口，不保证是模型标签；文化或时代名称不能替代具体结构，衣服廓形不直接等于身体轮廓。

## 类别与整体廓形

| 名称／英文入口 | 可见结构 | 变化与组合 |
|---|---|---|
| T 恤／T-shirt | 较简单的针织上衣形态 | 领型、袖长、版型、图案分别选择 |
| 衬衫／shirt | 衣身、袖、领与前开合的组合 | 不要求每件都有完全相同领型和纽扣排列 |
| 女式上衣／blouse | 服装类别入口，结构范围较广 | 需补具体廓形、领袖与材料，不能只靠类别定外观 |
| 针织衫／knit top, sweater | 针织组织与衣身结构 | 细粗、贴身、松量、领袖不同 |
| 开衫／cardigan | 前开式针织上衣 | 开合、衣长、层叠和边缘组织另选 |
| 连帽上衣／hoodie | 帽、衣身及可能的口袋组织 | 套头或前开不同，帽放下时也有后颈体积 |
| 背心／vest, waistcoat, sleeveless top | 无袖衣身 | 英文范围不同：西装马甲与无袖内搭不混用 |
| 西装外套／blazer, suit jacket | 翻领、前襟、肩部和衣身剪裁 | 单双排、松量、衣长和套装关系不同 |
| 短夹克／jacket | 较短外层衣身 | 用具体款式、材料和收口展开，不固定一种轮廓 |
| 飞行夹克／bomber jacket | 衣身体积与领袖下摆收口的关系 | 长短、厚薄和领型可不同 |
| 骑行夹克／biker jacket | 常见斜襟、翻领等外套组织 | 不默认每件都具所有拉链和金属装饰 |
| 风衣／trench coat | 外层衣身及腰带、前襟等结构入口 | 版型细节按款式决定，不自动等于所有长外套 |
| 大衣／overcoat | 覆盖内层的较长外套体积 | 直身、收腰、茧形和材料重量另选 |
| 派克外套／parka | 较有包覆感的外层衣身 | 帽、口袋、抽绳与厚度按款式选择 |
| 斗篷、披肩／cape, shawl | 披覆而非普通袖身结构 | 固定点、包覆范围、开口和手臂活动空间明确 |
| 连衣裙／dress | 上下衣身连为整体 | 轮廓、腰线、袖领、开合和长度分别选 |
| 无袖罩裙／pinafore dress | 常作叠穿的无袖裙装结构 | 肩带、围兜、侧开口与内搭另选 |
| 吊带裙／slip dress | 细肩带与较轻的衣身组织 | 不等于所有无袖裙，也不自动规定场合 |
| 衬衫裙／shirt dress | 衬衫式上部结构延伸为裙装 | 腰带、衣摆与袖长可以变化 |
| 裹身裙／wrap dress | 衣片交叠、系合并形成衣身 | 交叠方向与固定点清楚，不随镜头翻转 |
| 连体裤／jumpsuit | 上衣与裤部连接 | 腰线、裤腿、开合与袖领另选 |
| 直筒裤／straight-leg trousers | 裤腿整体宽度变化较小 | 裤腰、松量、长度与面料不同 |
| 阔腿裤／wide-leg trousers | 裤腿整体较宽 | 跨部、腰胯和垂坠决定体积，不只是放大脚口 |
| 锥形裤／tapered trousers | 裤腿向下逐渐收窄 | 与贴身裤、束脚裤区分 |
| 喇叭裤／flared trousers | 下段裤腿向外展开 | 起始高度、幅度与长度可变 |
| 工装裤／cargo trousers | 衣身与功能口袋形成组织 | 口袋位置和体积明确，不必到处加带扣 |
| 短裤／shorts | 较短裤部轮廓 | 长度、裤腿宽度、褶和用途另选 |
| 百褶裙／pleated skirt | 重复褶线组织裙身 | 褶宽、褶型、开合与体积可不同 |
| 铅笔裙／pencil skirt | 相对收束的裙部轮廓 | 长度、开衩与活动余量配合 |
| 圆裙／circle skirt | 裙身展开形成较充分的圆弧体积 | 不等同百褶结构，垂坠与运动分别设计 |
| A 字廓形／A-line silhouette | 从较窄上部向下展开 | 可用于不同衣服类别，不只一种连衣裙 |
| 直身、茧形、收腰／straight, cocoon, fitted-waist silhouette | 平行延伸、包覆体积或腰部收束 | 廓形与松紧、厚度、身体比例分开 |
| 落肩、夸张肩／dropped, exaggerated shoulders | 服装肩部位置或体积有意变化 | 不把落肩袖缝当作真实肩关节 |
| 短款、长款、不对称下摆／cropped, longline, asymmetric hem | 衣长与末端组织 | 内外层之间的显露关系可形成主次 |

## 领口、袖、腰与开合

| 名称／英文入口 | 可见结构 | 变化与相近概念 |
|---|---|---|
| 圆领、V 领、方领／round, V, square neckline | 开口的边缘形状 | 开口宽深、包边与身体显露另选 |
| 船领／boat neckline | 横向较宽的领口形状 | 与一字露肩范围区分 |
| 心形领口／sweetheart neckline | 上缘形成双弧与中央凹处 | 是开口形状，不自动指特定服装风格 |
| 挂脖结构／halter neckline | 衣身主要经颈部周围固定 | 后背、系结与肩部显露明确 |
| 露肩、单肩／off-the-shoulder, one-shoulder | 肩部开口与支撑方式 | 单肩须保留左右身份，不因视角变换乱换 |
| 高领、翻折高领／high neck, turtleneck | 领部向颈部延伸 | 竖立与翻折、贴合与松量不同 |
| 堆领／cowl neckline | 领口布料形成垂坠褶量 | 不等于普通高领或另加围巾 |
| 立领／stand collar | 领片从领口向上立起 | 高度、开口和挺度可变 |
| 衬衫领／shirt collar | 领片与领座等结构入口 | 尖端、宽度、开合按款式决定 |
| 彼得潘领／Peter Pan collar | 较平贴、圆角的领片轮廓 | 大小、单双层与对比色可选 |
| 水手领／sailor collar | 前后领片形成特定展开组织 | 背部形状、前部开口与系结需协调 |
| 翻领／lapels | 前襟翻折形成的领部结构 | notch、peak、shawl 等轮廓可具体展开 |
| 泡泡袖／puff sleeve | 某一袖段鼓起并在边界收量 | 鼓起位置、长度、收口和挺度可不同 |
| 羊腿袖／leg-of-mutton, gigot sleeve | 上臂较大体积与下段收窄形成对比 | 不等同所有泡泡袖，过渡位置可变化 |
| 喇叭袖／bell sleeve | 袖段向末端展开 | 展开高度、开口与布料重量另选 |
| 主教袖／bishop sleeve | 长袖体积向腕部收束 | 与羊腿袖的体积分布区别 |
| 插肩袖／raglan sleeve | 袖部接缝向领口区域延伸 | 是袖身连接方式，不是袖口形状 |
| 蝙蝠袖／batwing, dolman sleeve | 腋下较宽的袖身组织 | 精确剪裁有变体，按衣身接合和收束描述 |
| 盖袖／cap sleeve | 较短的袖部覆盖肩上区域 | 与完全无袖、短袖分别考虑 |
| 无袖、挖肩／sleeveless, cold-shoulder cutouts | 缺少袖部或局部露出肩部 | 两者结构不同，不混作同一标签 |
| 袖口／cuff | 袖末端的边缘或独立收口结构 | 纽扣、弹力、翻折与装饰另选 |
| 高腰、低腰、自然腰／high, dropped, natural waistline | 服装结构腰线的落点 | 与人物真实腰部位置分开 |
| 褶、省道、抽褶／pleats, darts, gathers | 折叠、收量和密集褶量的不同组织 | 不能都用随机皱褶代替 |
| 荷叶边／ruffle | 边缘或衣片形成波状体积 | 层数、宽度、方向和固定线另选 |
| 裙撑与结构支撑／petticoat, structural support | 内层支撑外层轮廓 | 内层可不可见分别决定 |
| 纽扣、拉链、系带／buttons, zipper, lacing | 开合位置与连接结构 | 功能性与装饰性分开，数量与方向按设计保持 |
| 门襟、交叠、开衩／placket, overlap, slit | 前开口或局部活动开口 | 衣片前后与接点明确 |
| 腰带、抽绳／belt, drawstring | 收束或固定衣身 | 不自动收成同一紧腰轮廓 |
| 贴袋、嵌线袋、翻盖袋／patch, welt, flap pockets | 不同口袋表面结构 | 袋位、体积、装物状态与活动关系配合 |

## 材料、表面、图案与穿着状态

| 名称／英文入口 | 可见展开 | 组合关系 |
|---|---|---|
| 棉、麻、毛、丝／cotton, linen, wool, silk | 纤维材料入口 | 织法、厚薄、整理不同，不能仅由材料名规定光泽 |
| 针织、梭织／knitted, woven fabric | 组织与纹理方向 | 材料、弹性、厚度和垂坠另选 |
| 牛仔／denim | 织纹、衣片、接缝与洗水组织 | 深浅、挺软与磨损差异可变 |
| 缎面／satin surface | 较连续的表面光泽与折面反射 | 是组织及表面入口，不等同所有丝料 |
| 丝绒／velvet | 绒面、方向性明暗与较深色感 | 不用塑料镜面高光代替 |
| 灯芯绒／corduroy | 成列凸起的纵向绒条 | 条宽、衣片方向与尺度另选 |
| 皮革、麂皮／leather, suede | 表面、厚度与软硬组织 | 光滑或起绒、亮哑、折痕与磨损分别设计 |
| 蕾丝／lace | 镂空网状与图案组织 | 内衬、透显范围、边缘和尺度明确 |
| 薄纱、网眼／tulle, mesh | 轻薄或网状组织 | 不自动规定透明程度、颜色与层数 |
| 毛绒、羽毛／fur-like pile, feathers | 方向、层次和边缘体积 | 来源与材质外观分开，根部连接需成立 |
| 金属、硬质片、护甲／metal, rigid panels, armor | 硬表面与分片连接 | 重量、活动范围、扣接和软层配合 |
| 条纹、格纹、圆点／stripes, checks, polka dots | 重复图形与方向 | 尺度、密度、衣片拼接和褶皱变形另选 |
| 花卉、几何、抽象图案／floral, geometric, abstract print | 图案母题与排列 | 不必每件衣服都有图案 |
| 刺绣、贴花、压纹／embroidery, appliqué, embossing | 不同表面加工的厚度与边缘 | 与印花区分，位置和视觉主次明确 |
| 配色与拼接／color blocking, paneling | 衣片或区域形成色面 | 接缝、材料变化与纯色分区不混写 |
| 贴身、宽松、超大版型／fitted, loose, oversized | 身体与服装之间的余量 | oversized 是相对版型，不自动扩大身体 |
| 挺括、柔软垂坠／structured, softly draped | 形状保持和垂落方式 | 材料、厚度、剪裁与支撑共同决定 |
| 塞衣角、敞穿、卷袖／tucked-in, worn open, rolled sleeves | 穿着动作改变衣身组织 | 指定局部、松紧与内层显露 |
| 层叠／layered clothing | 多件衣服的覆盖与边缘显露 | 领袖下摆的层次不同，不凭空穿插 |
| 磨损、褪色、修补／wear, fading, repairs | 常用部位的表面与结构变化 | 与人物生活和材料相联系，不均匀污染 |
| 湿态、积雪、沾灰／wet, snow-covered, dusty clothing | 环境带来的局部表面变化 | 重量、贴合与动作响应配合 |

## 鞋袜、头饰、首饰与随身物

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 运动鞋／sneakers | 鞋身、鞋底、鞋带与支撑形态 | 厚薄、用途、磨损及袜口配合 |
| 乐福鞋／loafers | 无系带的包覆式低帮鞋形 | 鞋头、装饰带、鞋底另选 |
| 玛丽珍鞋／Mary Jane shoes | 脚背横向鞋带与鞋身组织 | 带数、鞋跟、鞋头及扣接可变 |
| 浅口鞋／pumps, court shoes | 鞋口与鞋头、鞋跟形成整体 | 不把所有有跟鞋都称 pumps |
| 凉鞋／sandals | 鞋带与鞋底的开放组织 | 脚部支撑、固定与受力要清楚 |
| 短靴、长靴／ankle boots, tall boots | 鞋身向踝或腿部延伸 | 筒高、筒宽、开合、鞋跟与裤裙配合 |
| 长短袜、连裤袜／socks, stockings, tights | 覆盖高度、边缘与贴合 | 分段袜和连体结构不混用 |
| 贝雷帽／beret | 较软的圆形帽体与佩戴偏置 | 体积、倾斜和头发压痕另选 |
| 棒球帽／baseball cap | 帽体与前檐 | 佩戴方向、帽檐曲率与露发范围另选 |
| 渔夫帽／bucket hat | 帽冠与周向下展帽檐 | 帽檐宽、软硬与遮脸范围明确 |
| 宽檐帽、针织帽／wide-brim hat, knit cap | 帽檐或贴头包覆结构 | 与风、观察角度和发型配合 |
| 发夹、发箍、发带、簪／clip, headband, ribbon, hairpin | 固定点与装饰轮廓 | 不只是悬浮在头发上的符号 |
| 耳饰／earrings | 耳部连接、长度与体积 | 耳钉、耳环、垂饰与左右差异可选 |
| 项链、颈环／necklace, choker | 颈胸区域的线与体积 | 长度、吊坠、领口和重力关系配合 |
| 戒指、腕饰／rings, bracelets | 手指、腕部的局部结构 | 尺寸与握持接触相容 |
| 眼镜／glasses | 镜框、镜片、鼻托与镜腿 | 与脸形、遮挡、反光及表情共同设计 |
| 围巾、领带／scarf, tie | 颈部绕束或前垂结构 | 结法、端部、厚度和风中响应不同 |
| 手套／gloves | 手部覆盖及开口结构 | 长短、指部结构、材料与操作用途明确 |
| 肩包、背包、腰包／shoulder bag, backpack, belt bag | 包体与背带、固定点 | 负重改变衣物和姿态，包不任意换侧 |
| 工具、武器、携带装备／tools, weapons, carried gear | 握持、收纳、固定及使用关系 | 不自动为普通人物添加装备；重量与行动相容 |
| 制服、礼服、工作服、文化服饰／uniform, formalwear, workwear, cultural dress | 用途或语境入口 | 进一步选具体结构，不以类别词替代整套设计 |

内搭、运动、职业、历史文化与整套穿搭继续调用[服饰语境与穿搭](服饰语境与穿搭.md)。服装设计可深入[FIT 的袖型展览](https://www.fitnyc.edu/museum/exhibitions/statement-sleeves/index.php)与[织物和服装关系展览](https://exhibitions.fitnyc.edu/fabric-in-fashion/)。这里提供语义与结构入口，不规定每种衣服唯一正确的形式；组合与人物关系见[人物设计入口](../12-人物设计与外观组合.md)。
