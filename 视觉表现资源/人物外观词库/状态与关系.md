# 人物状态与关系词库

用于把部位、特征和状态组织成可见描述。稳定外貌、临时表情、行为和观察条件分别处理；情绪名称可以引导设计，但不能代替画面证据。以下表达可自由变化，不规定“某个动作必然代表某种性格或情绪”。

## 比例、位置、程度与轮廓

| 表达／英文入口 | 可见展开 | 组合用法 |
|---|---|---|
| 相对较宽、较窄／relatively wider, narrower | 指定比较对象和区域 | “颧部较宽，下颌逐渐收窄”优于单独写宽脸 |
| 略长、明显偏短／slightly longer, noticeably shorter | 长度差与程度 | 指定相对哪个部位，不用伪精确数字 |
| 上部重、下部轻／upper-heavy, lighter lower silhouette | 体积或视觉重量的分布 | 可用于发型、衣服或整体轮廓，不等同真实重量 |
| 横向展开、纵向延伸／spreading laterally, extending vertically | 形状主要发展的方向 | 与透视、动作方向分别表达 |
| 逐渐收束、突然转折／gradual taper, abrupt turn | 两个区域之间的形状过渡 | 下颌、发梢、裤腿均可使用 |
| 圆润、折角、尖锐／rounded, angular, pointed | 局部轮廓的转折方式 | 同一人物可以分区混合，不必全身统一 |
| 平直、凸起、凹入／flat, convex, concave | 表面或侧面轮廓的走势 | 明确区域，避免只靠阴影判断体积 |
| 平滑过渡、清楚分段／smooth transition, distinct segmentation | 相邻体块或分区的连接方式 | 层次发、面部平面、衣片都可展开 |
| 对称、偏置、轻微不对称／symmetric, off-center, subtly asymmetric | 两侧关系或中心位置 | 区分结构、姿势、视角造成的差别 |
| 靠近、分离、留缝／close, separated, with a gap | 元素间的距离与负形 | 手臂与躯干、发束与脸侧等关系 |
| 内收、外展／drawn inward, spread outward | 形状或动作相对身体的方向 | 要说明是关节姿势还是末端造型 |
| 前伸、后退／projecting forward, set back | 相对参考平面的空间位置 | 鼻尖、下巴、衣服前片分别选择 |
| 贴合、悬离、垂落／fitted against, standing away, hanging | 衣发配件与身体表面的关系 | 指定接触区与离开区 |
| 包覆、显露、半遮／enclosing, exposed, partly covered | 可见范围与遮挡 | 描述参考时不补造遮挡后特征 |
| 前后层、内外层／front/back, inner/outer layers | 空间或叠穿的顺序 | 不在同一局部互相穿插 |
| 稀疏、集中、逐渐密集／sparse, clustered, increasing density | 点、纹理、毛发或装饰的分布 | 给区域和梯度，不均匀撒满 |
| 细碎、成束、成片／fine fragments, grouped strands, broad masses | 细节的组织尺度 | 日漫头发可从大块分到局部发束 |
| 重复、变化、局部中断／repetition, variation, interruption | 图案、配件或轮廓的节律 | 重复元素不必机械等距 |
| 呼应、对照、错位／echo, contrast, offset | 两种形状或色块的关系 | 如圆脸与锐利衣领对照，需落实到形状 |
| 主体、次要、点缀／dominant, supporting, accent | 外貌与服饰的视觉主次 | 不把每个饰品都设成观看焦点 |
| 根部、过渡、末端／root, transition, tip | 发束、角、袖等结构的段落 | 三段可有不同材质、体积与方向 |
| 从正面到侧面的延续／consistent across views | 身份比例在不同视角中成立 | 透视变化不等于重新设计角色 |
| 局部可变、整体保持／local variation, stable overall structure | 状态变化与身份锚点的区分 | 风吹发梢但保留发型主要分区 |

## 视线、眼部与口部状态

| 表达／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 直视、侧看、回望／direct gaze, sidelong glance, looking back | 眼球朝向与观察对象 | 头朝向、眼球方向和镜头位置分别写 |
| 垂眼、抬眼／lowered, raised gaze | 视线相对头部朝向变化 | 不等同整个头部低下或抬起 |
| 焦点明确、视线游移／focused, shifting gaze | 目光落点或转移 | 静态选当下落点，视频可发展转移过程 |
| 半睁、眯眼、睁大／half-lidded, narrowed, widened eyes | 眼睑开合和周围体块变化 | 不自动规定困倦、怀疑或惊恐 |
| 轻闭、紧闭／gently closed, tightly shut eyes | 眼睑压力与眼周挤压 | 与笑、疼痛、集中等情境组合 |
| 眉内侧抬起、眉峰扬起／raised inner brows, lifted brow arch | 局部眉线变化 | 区别整条眉上移，表情强度可细分 |
| 眉间收紧／brows drawn together | 眉与额部向内的局部挤压 | 可微弱或明显，不只画怒眉符号 |
| 唇部放松、抿唇／relaxed lips, pressed lips | 唇部接触与肌肉张力 | 口裂、嘴角、下巴可共同变化 |
| 轻启口、半开口／slightly parted, half-open mouth | 当前开口程度与形状 | 与发音、呼吸、动作阶段配合 |
| 单侧嘴角上提／one corner lifted | 非对称口部变化 | 不自动规定讥讽 |
| 含蓄笑、开口笑／subtle smile, open-mouth smile | 嘴角、眼睑、面颊等共同变化 | 笑意强度、露齿范围和是否对称另选 |
| 牙关紧、下颌放松／set jaw, relaxed jaw | 口周和下颌的张力差 | 不要求所有画风表现全部肌肉线 |
| 泪光、泪痕、落泪／watery eyes, tear tracks, falling tears | 液体所在区域与当前状态 | 三者可相继出现，但静态不同时演完整过程 |
| 吸气前、呼气后／before an inhale, after an exhale | 胸肩、口鼻及姿态的当下组织 | 视频可衔接，图片选明确状态 |

## 姿态、手势与动作倾向

| 表达／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 单腿承重／weight on one leg | 支撑脚、骨盆、躯干与另一腿的关系 | 松弛或紧张由具体姿态决定 |
| 均衡站立／balanced stance | 两脚、身体重心与支撑范围 | 不等于所有部位完全对称 |
| 前倾、后仰／leaning forward, leaning back | 躯干与支撑相对位移 | 需给支撑、接触或动作意图 |
| 含胸、挺胸／rounded upper posture, lifted chest | 胸肩与上背的姿态关系 | 与身体结构、衣服轮廓区分 |
| 抬肩、沉肩／raised, lowered shoulders | 肩部当下位置与张力 | 非永久肩型变化 |
| 头偏侧、下巴抬起／head tilt, lifted chin | 头部旋转和方向 | 与目光、颈部和肩部配合 |
| 躯干扭转／torso twist | 胸廓与骨盆朝向产生差异 | 衣服褶皱和四肢连接应随之成立 |
| 开放、收拢姿态／open, closed-in posture | 四肢距躯干、空间占用与遮挡 | 不将姿态直接当作性格结论 |
| 双臂交叠／crossed arms | 两臂的前后、手部藏露与接触 | 不自动等于防御情绪 |
| 手轻搭、抓握、攥紧／resting hand, grasp, clenched hand | 接触范围与力量差 | 指节、腕部和接触物共同成立 |
| 手指蜷曲、展开／curled, spread fingers | 指部形状与掌部关系 | 接触、动作方向和透视优先 |
| 整理衣角、拨发、摸配件／adjusting clothes, moving hair, touching an accessory | 与身体相关的小动作 | 可成习惯，但不为每镜重复添加 |
| 松坐、端坐、侧坐／relaxed, upright, sideways sitting | 椅面接触、骨盆与腿部关系 | 衣物压叠和负重一起变化 |
| 盘腿、跪坐、蹲姿／cross-legged, kneeling, squatting | 不同支撑面与四肢折叠 | 按身体与场景具体设计，不统一成一个姿势 |
| 小步、大步、拖步／short stride, long stride, dragging steps | 步幅、足部离地与身体推进 | 外观步态不能单独证明健康状况 |
| 快起慢收、迟疑起动／quick initiation with a slow settle, hesitant start | 时间内部的变化方式 | 静态描述关键姿态，动态再给先后与节奏 |
| 紧绷、松弛／tense, relaxed | 多部位的张力组织 | 选择主要证据，不让全身同时夸张 |
| 疲惫感／fatigued appearance | 姿态、目光、动作间隔等组合 | 不固定为黑眼圈与驼背，也不诊断原因 |
| 克制、外放的表演／restrained, expansive performance | 动作幅度、占用空间与表情强度 | 不改变人物身份比例 |

## 组合写法

选择有用的部分，不把句式当成固定格式：**对象或区域＋形态／状态＋程度＋相对关系**。例如“颧部略宽，下颌向圆下巴平缓收束；刘海中央留隙，两侧短层次落在颧部附近”。读者不需要懂全部术语，也能理解最终形状。

状态可以由多个互不重复的证据共同表现：“肩部放松，重心落在后腿，手指轻搭包带，目光停在画外”。不要先写“极度紧张”又无意组合全身松弛；有意克制或反差时，给出具体情境与主要证据。

静态不要求眨眼、转头和开口连续发生；动态需保留先后、转移和余留。表情变化继续深入[安静表演](../../参考资料/表现库/V02-安静表演与保持.md)及[细微表演](../../参考资料/表现库/V09-细微表演与多角色.md)，整体设计回到[人物入口](../12-人物设计与外观组合.md)。
