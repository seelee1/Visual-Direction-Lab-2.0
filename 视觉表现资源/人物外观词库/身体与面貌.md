# 身体与面貌词库

这里的名称与描述是组合素材，不是人体分类标准或美貌排序。选择当前可见、能贡献辨识度的特征，继续使用自身知识。英文表达用于语义检索与描述，不保证是模型标签。年龄、体型、结构和表情分别考虑，不从外貌推断性格、族裔或健康结论。

## 身体与比例

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 高挑／tall stature | 身体在环境或人物对比中显得高 | 单人无参照时用比例与空间关系支持，不只写 tall |
| 小个子／short stature | 相对较低的身高 | 与头身比例、身体体量分开 |
| 修长／elongated proportions | 肢体或躯干长度被强调 | 可是风格化比例，不必全身都纤细 |
| 紧凑／compact build | 身体体块与长度关系紧凑 | 肩、躯干、四肢分别选择 |
| 纤细／slender build | 整体横向体量较窄 | 保留骨架、支撑与局部体积 |
| 丰满／full figure | 身体具有较充分的软组织体量 | 分布可不同，不自动规定腰胸臀比例 |
| 结实／sturdy build | 身体体量与支撑感较强 | 不等于肌肉处处清晰可见 |
| 运动型／athletic build | 身体表现运动相关的肌肉和体态 | 具体运动与个体不同，不统一成健美体型 |
| 肌肉明显／defined musculature | 某些肌群轮廓可辨 | 体积、清晰度、放松与发力分别发展 |
| 柔和体态／soft body contours | 身体轮廓过渡柔和 | 与肥瘦、年龄、性别分开 |
| 宽肩／broad shoulders | 肩部横向跨度较大 | 与颈长、腰部、衣服肩线比较 |
| 窄肩／narrow shoulders | 肩部跨度较小 | 不自动等于柔弱 |
| 平肩、斜肩／level, sloping shoulders | 肩线角度不同 | 姿势和衣服也会改变可见肩线 |
| 腰部收束／defined waist | 躯干中段相对收窄 | 骨架、软组织与束腰造成的形状分开 |
| 较直躯干／straight torso silhouette | 肩腰胯的宽度变化较小 | 仍有前后体积，不画成平板 |
| 胯部宽度／hip width | 骨盆及周围体量影响下身轮廓 | 与裙摆、裤型造成的宽度区分 |
| 长躯干、长腿感／long torso, long-legged proportions | 上下身长度关系 | 镜位、腰线也可改变观感，不混作身体事实 |
| 长颈、短颈感／long, short neck | 头肩之间距离与颈部形态 | 领口和姿态可遮盖或强调 |
| 骨点显露／visible bony landmarks | 锁骨、关节或肩胛的局部结构 | 按姿态、体型和画风选择，不堆满全身 |
| 少年、成年、老年特征／youthful, adult, older features | 比例、体量、皮肤、姿态的组合 | 用具体年龄要求约束，不只靠皱纹或放大眼睛 |
| 风格化头身比例／stylized head-to-body proportions | 头与身体的尺度关系 | 写实、时装拉长、漫画或 Q 版分别设计 |

## 头部与面部结构

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 椭圆脸／oval face | 纵向稍长、侧轮廓连续 | 仍可有不同颧骨、下颌和下巴 |
| 圆脸／round face | 横纵接近、弧形轮廓较明显 | 不等于儿童或固定丰满程度 |
| 长脸／long face | 面部纵向比例较长 | 额头、中面部、下巴长度分别发展 |
| 方形下颌／square jaw | 下颌转角与横向宽度明确 | 可搭配柔和五官，不固定气质 |
| 心形、倒三角轮廓／heart-shaped, inverted-triangle outline | 上部较宽、下部收窄 | 两词常有重叠，额部与下巴具体描述优先 |
| 颧骨突出／prominent cheekbones | 面部中段骨架起伏明确 | 正侧面和光线不同，不只加阴影线 |
| 饱满面颊／full cheeks | 面颊体量较充分 | 与表情挤压、年龄与面部骨架配合 |
| 收窄面颊／lean cheeks | 面颊轮廓较收束 | 不自动等同疲惫或病态 |
| 尖、圆、方下巴／pointed, rounded, square chin | 面部末端形状 | 与下颌宽度和侧面投影协调 |
| 高低额头／high, low forehead | 发际至眉部的可见高度 | 刘海遮挡不改变实际结构 |
| 直、弧、挑眉／straight, arched, angled eyebrows | 眉形走势 | 粗细、疏密、眉峰、眉尾另选 |
| 杏眼、圆眼、狭长眼／almond, round, narrow elongated eyes | 眼裂及上下眼睑的轮廓 | 与开眼程度、表情、动漫夸张分开 |
| 上挑、下垂眼尾／upturned, downturned outer corners | 眼裂外端相对走势 | 不直接推断傲慢或温柔 |
| 眼距／eye spacing | 双眼相对宽度与间隔 | 与鼻梁、脸宽、透视共同成立 |
| 单眼皮、双眼皮／monolid, eyelid crease | 上眼睑褶线的可见组织 | 褶线可被姿态和画法简化，不据此推断身份 |
| 眼睑厚薄／eyelid fullness | 眼周体块与轮廓差别 | 不用固定阴影替代体积 |
| 虹膜颜色与纹理／iris color and pattern | 虹膜本色、边缘与内部组织 | 眼部反光属于照明，不作为本色变化 |
| 长、短、直、翘睫毛／eyelash length and curl | 眼缘线束的密度与走势 | 简化画风可以只留轮廓或局部束 |
| 鼻梁、鼻尖与鼻翼／bridge, tip, nostrils | 鼻部不同区域的结构 | 前视、三分之二侧面与侧面保持关系 |
| 直鼻、凸鼻梁、翘鼻尖／straight bridge, convex bridge, upturned tip | 鼻部侧面与末端变化 | 不把三个不同维度都当作互斥鼻型 |
| 薄、厚唇／thin, full lips | 上下唇体量和宽度 | 上下唇可不同，不自动带出表情 |
| 唇峰与嘴角／Cupid's bow, mouth corners | 唇上缘与口裂端点 | 与口型、表情变化分开 |
| 耳部轮廓／ear shape | 耳廓大小、位置、外翻与耳垂 | 与发型遮挡、耳饰和侧面关系配合 |
| 轻微非对称／subtle asymmetry | 眉形、嘴角或其他稳定差异 | 身份特征与临时表情不对称分别记录 |
| 瞳孔形态／pupil shape | 圆形、狭缝或幻想形状的暗部 | 与虹膜、反光和眼部表情分开 |
| 酒窝、下巴凹处／dimples, chin cleft | 局部凹面与轮廓差异 | 酒窝可随表情显隐，不固定画成黑点 |
| 小虎牙或牙列特征／prominent canine, tooth features | 张口时可见的局部牙形 | 牙齿位置与口型对应，非所有表情都露牙 |

## 皮肤、妆容、手足与身体特征

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 肤色与底色／skin tone, undertone | 明度、色相倾向与局部色彩 | 色词需结合画面；照明、反射和本色分开 |
| 雀斑／freckles | 细小色点的区域与密度 | 鼻梁、面颊或其他位置可不同，不均匀撒满 |
| 痣／mole, beauty mark | 特定位置的色点 | 稳定位置可作身份锚点 |
| 红润、晒痕／rosy areas, tan lines | 局部色差与边界 | 与腮红妆、环境照明、临时脸红区分 |
| 皱纹、细纹／wrinkles, fine lines | 眼周、额部、口周等线面变化 | 静态纹理和表情褶皱分别处理 |
| 疤痕／scar | 位置、形态、色差与表面起伏 | 不自动推断遭遇或故事 |
| 纹身、身体彩绘／tattoo, body paint | 图案、位置、尺度与身体贴合 | 随体表与动作变形，文字与图案交付分开 |
| 皮肤颗粒与毛孔／skin texture, pores | 表面细微组织 | 根据景别与画风选取，不给二维默认加照片毛孔 |
| 哑光、湿润、汗光／matte skin, wet skin, perspiration sheen | 不同表面状态的高光与局部水分 | 皮肤状态、整体曝光和油亮描绘分开 |
| 眼线、眼影／eyeliner, eyeshadow | 眼缘图形、色域与晕染 | 与实际眼型、眼睑结构区分 |
| 腮红、唇色／blush, lip color | 化妆色域与表面效果 | 不默认所有人物带妆 |
| 手指、指节与手掌／fingers, knuckles, palm | 长短、粗细、关节和掌部体量 | 手势、接触与透视优先于孤立形容词 |
| 指甲／nail shape and finish | 长度、甲缘、颜色与修整状态 | 与行动用途、手部姿态配合 |
| 脚部与踝部／foot and ankle shape | 足背、脚趾、踝部及支撑关系 | 鞋内不可见部位不必展开 |
| 身体毛发／body hair | 分布、密度与可见程度 | 景别和角色设计决定是否表现 |
| 缺肢、义肢与辅助器具／limb difference, prosthesis, assistive device | 身体结构与器具的连接、支撑和使用方式 | 不默认赋予悲剧或超能力，功能需具体设计 |
| 幻想耳、角、尾、翼／fantasy ears, horns, tail, wings | 附属结构的根部、轮廓、材质与运动范围 | 与头骨、服装开口、支撑和身份锚点协调 |

## 面貌的细分形态与侧面关系

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 额部倾斜与弧度／forehead slope and curvature | 额头在侧面向上、向后的轮廓走势 | 与发际线、眉骨和头颅体积配合 |
| 眉骨起伏／brow ridge prominence | 额部至眼眶上缘的体积变化 | 不用粗眉或一条黑线代替骨架 |
| 深眼窝、浅眼窝感／deep-set, shallow-set eyes | 眼部相对周围面部结构的位置 | 眉骨、鼻根和颧部共同支持，阴影深浅不能单独证明 |
| 上眼睑遮覆／upper-lid hooding | 上睑皮肤遮住部分褶线 | 与单眼皮、眯眼、镜头俯视分别考虑 |
| 内外眼角轮廓／inner and outer eye-corner shape | 眼裂两端的开合与转折 | 眼尾方向、眼宽和表情可以独立变化 |
| 眼下体积／under-eye volume | 下眼睑附近的局部起伏 | 小尺度画法按需保留，不将所有起伏都解释成疲惫 |
| 上睑至眉间距／brow-to-eye spacing | 眉线和眼缘之间的距离 | 表情抬眉会改变临时距离，身份比例另存 |
| 鼻根位置／nasal root height | 鼻部在双眼之间开始的高度与凹凸 | 与鼻梁全长、额部侧面不同 |
| 鼻背曲线／nasal bridge contour | 侧面直、弧或局部起伏的走势 | 连同鼻尖投影描述，不只写鼻子高 |
| 鼻尖投影／nasal tip projection | 鼻尖相对面部平面的前伸程度 | 与鼻梁高度、鼻翼宽度分开 |
| 鼻翼宽与鼻底／alar width and nose base | 鼻底横向与下缘形状 | 仰俯角改变可见鼻孔范围 |
| 中面部长度／midface length | 眼部至口鼻区域的相对纵向关系 | 与总脸长、镜头透视、动漫简化区分 |
| 面中部饱满度／midface fullness | 鼻旁及颧下区域的体量 | 与面颊下部、颧骨宽度不同 |
| 人中长度与沟形／philtrum length and shape | 鼻底至上唇的区域关系 | 口型和唇部形态会改变可见组织 |
| 口部前突关系／mouth projection | 唇与口周相对鼻尖、下巴的侧面关系 | 不据此推断牙列或医疗问题 |
| 口裂宽度／mouth width | 两侧嘴角间的横向比例 | 开口程度不是嘴宽，微笑可改变轮廓 |
| 下颌转角／jaw angle | 耳下至下巴轮廓的转折 | 角度、宽度和软组织覆盖各自发展 |
| 下巴前伸与后收／chin projection | 下巴相对口部的侧面位置 | 与尖圆形状、纵向长度分开 |
| 面部三分区关系／upper, middle, lower facial proportions | 额部、眼鼻、口颏区域的相对尺度 | 用作设计关系，不强制统一比例标准 |
| 正侧面形状延续／front-to-profile consistency | 额鼻唇颏与颧颌在不同视角中的关联 | 同一人物不能前视圆脸、侧视随意更换骨架 |

## 躯干、四肢与局部体量

| 名称／英文入口 | 可见展开 | 变化与组合 |
|---|---|---|
| 胸廓宽深／rib-cage width and depth | 躯干上部横向和前后体积 | 呼吸、姿态与服装遮挡影响可见轮廓 |
| 胸部体量与轮廓／chest volume and contour | 胸部区域相对躯干的体积与形状 | 身体结构、衣物支撑、压缩与姿态分别设计 |
| 锁骨走势／clavicle contour | 颈根与肩之间的线面组织 | 景别、体型和肩部姿态决定显露程度 |
| 肩胛与背部平面／scapular and back planes | 背部局部体块和转折 | 抬臂、前伸与放松改变形状，不固定画成两块 |
| 腰背弧度／lower-back contour | 躯干侧面及后部的曲线 | 区分身体、姿势和衣服造成的形状 |
| 腹部体量／abdominal volume | 腹部平面、弧度、软组织与肌肉组织 | 坐下、弯曲、呼吸与衣物约束可变化 |
| 骨盆宽度与倾向／pelvic width and tilt | 下躯干体量与方向 | 骨架特征与临时姿势分开 |
| 臀部形态／gluteal contour | 后部体量、曲线与躯干连接 | 与胯宽、服装填量和姿态分别考虑 |
| 上下臂体量／upper-arm and forearm volume | 手臂不同段落的粗细与转折 | 肌肉、软组织、关节与动作共同成立 |
| 肘部形态／elbow contour | 弯伸时的关节与局部皮肤组织 | 不以固定尖角代替所有姿态 |
| 腕掌连接／wrist-to-hand transition | 前臂收束、腕部和手掌体块关系 | 与握拳、伸腕、饰品压力配合 |
| 大腿与小腿体量／thigh and calf volume | 不同段落的宽度、曲线和收束 | 前后侧面及站立、弯曲状态不同 |
| 膝部结构／knee contour | 关节区域与腿部体块的连接 | 受力、弯曲与裤料遮挡分别考虑 |
| 踝部收束／ankle taper | 小腿至足部的轮廓过渡 | 内外踝、足部朝向与鞋口协调 |
| 手足相对尺度／relative hand and foot scale | 手足相对身体与道具的比例 | 可风格化，但不能跨镜无意变大变小 |
| 局部软组织褶叠／soft-tissue folds | 弯曲、坐姿或接触处形成的局部叠压 | 不等同衣服皱褶，也不自动等同年龄特征 |
| 个体体量分布／individual volume distribution | 躯干、四肢和面部的体量差异 | 不把体型词当作全身同比例缩放 |

人物状态与关系表达见[状态与关系](状态与关系.md)，年龄及特殊身体见[特殊人物与非人设计](特殊人物与非人设计.md)。身体描述不必强制变成医学解剖清单。
