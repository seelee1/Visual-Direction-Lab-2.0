# 服饰语境与穿搭词库

补充内搭、运动、职业、礼仪、历史文化与完整穿搭的入口。语境名称不能唯一决定衣服；具体形状仍调用[服装与配件](服装与配件.md)。忠实历史或文化复现要落实地区、时期、场合和实际参考；用户要求幻想时可自主融合，但建立统一的服饰语言。

## 内搭、居家与运动

| 名称／英文入口 | 可见结构或发展 | 变化与组合 |
|---|---|---|
| 打底衫／base-layer top | 贴合或薄层上衣与外层关系 | 领袖露出、保暖、材质和松量另选 |
| 吊带内搭／camisole | 肩带与较轻衣身组织 | 外穿、内搭、领口与衣长不同 |
| 衬裙／slip, underskirt | 裙内层的覆盖或支撑 | 长度、显露、层数与外裙垂坠配合 |
| 内衣结构／underwear structure | 支撑、包覆、接缝、肩带与弹力 | 按可见范围与穿着用途选择，不强制展开不可见部分 |
| 无钢圈内搭／bralette | 较轻支撑的衣片与带部组织 | 不能仅由款式名推断材料或唯一外形 |
| 运动内衣／sports bra | 胸部支撑、覆盖与带部结构 | 松紧、开合、叠穿与运动用途明确 |
| 连体基础衣／bodysuit | 上身与下部连接的基础衣身 | 与舞蹈衣、泳装有重叠但不自动同义 |
| 塑形或束腰衣／shapewear, corset | 不同程度的支撑、收束与结构 | 弹性塑形衣和骨条束腰不可互换 |
| 睡衣／pajamas, sleepwear | 居家衣身、开合与松量 | 两件式、裙式、材料与个人习惯不同 |
| 浴袍、居家袍／bathrobe, dressing gown | 包裹、系带与较宽松衣身 | 吸水材料与轻薄家居材料分别选择 |
| 训练套装／tracksuit | 上下装配合及收口组织 | 运动类型、剪裁和穿着状态不同 |
| 运动紧身裤／leggings | 弹性贴合与接缝组织 | 与普通裤型或裤袜区别 |
| 泳装／swimwear | 支撑、覆盖与水中活动结构 | 连体、分体、长袖等按人物与用途设计 |
| 潜水或冲浪服／wetsuit, surf suit | 贴合衣身与材料、接缝和开合 | 不凭名称认定所有款式有同样厚度与性能 |
| 舞蹈衣／leotard, dancewear | 身体活动、支撑和衣身结构 | 芭蕾、现代舞等造型与鞋类不同 |
| 骑行、跑步、球类服饰／cycling, running, team-sport wear | 运动用途与身体、装备的关系 | 不给所有运动都套宽松球衣 |
| 户外层叠／outdoor layering | 内层、中层、外层的可见组织 | 环境需求、厚度、收纳和行动空间配合 |

## 职业、制服与礼仪

| 名称／英文入口 | 可见结构或发展 | 变化与组合 |
|---|---|---|
| 商务套装／business suit | 外套、内搭、裤裙与鞋的整体关系 | 剪裁、正式程度与个人穿法不同 |
| 工装连体服／work coveralls | 上下连接、开合、口袋及工作余量 | 材料、污染、工具与工种具体选择 |
| 围裙／apron | 前覆或包覆区域、固定带与口袋 | 厨房、手工、服务用途可有不同形态 |
| 医疗工作服／scrubs, clinical workwear | 上下衣身、口袋与活动空间 | 不把现代护理人员都画成旧式帽裙制服 |
| 实验或工作罩衣／lab coat, work coat | 外覆衣身、开合与衣长 | 场景用途、内搭与个人习惯配合 |
| 服务制服／service uniform | 衣身、配件与机构识别 | 不默认所有服务人员同一种裙装或性别 |
| 学校制服／school uniform | 上下装、内搭、标识与个人穿法 | 地区、时期、季节与学校设定不同 |
| 制服标识／insignia, uniform markings | 徽章、肩部、胸部或袖部识别 | 有真实机构要求时核对，不随意组合现实等级 |
| 防护衣／protective clothing | 外覆、密封、头手足装备与活动范围 | 视觉设计与实际防护性能分开 |
| 晚礼服／eveningwear | 场合、轮廓、材料与装饰的整体设计 | 不唯一等于曳地裙 |
| 燕尾服、晚宴礼服／tailcoat, dinner suit | 不同正式套装的衣身与尾部结构 | 不把所有黑西装都当同一礼服 |
| 婚礼服饰／wedding attire | 仪式、人物与文化相关的整套衣着 | 不默认只有白色裙装，具体语境另选 |
| 丧礼或纪念仪式服饰／mourning, memorial attire | 场合与个人的服饰关系 | 颜色、覆盖和装饰随具体文化与时期变化 |
| 舞台、演出服／stage costume | 远距辨识、动作与灯光下的材料关系 | 舞台效果和日常穿着可以有不同设计规则 |

## 历史、文化与幻想服饰入口

| 名称／英文入口 | 可见结构或发展 | 变化与组合 |
|---|---|---|
| 束腰、裙撑与后撑／corset, crinoline, bustle | 躯干收束、裙体展开与后部体积的不同支撑 | 时期与结构有变化，不将三者都塞进每套历史裙装 |
| 高腰历史裙装方向／high-waisted historical dress | 腰线、胸部下方与裙体的关系 | 时期、袖领、材料按参考发展，非所有高腰裙都同一历史款 |
| 宽侧裙体方向／side-expanded historical skirt | 两侧展开及上身、裙体的相对形状 | 支撑结构和年代另核对，不与所有圆裙混同 |
| 长袍、外袍／robe, long outer garment | 身体覆盖、前襟、袖身、系束与衣长 | 名称跨文化范围广，需要具体结构 |
| 斗篷与兜帽方向／cloak and hood ensemble | 包覆、固定、头部与手臂活动 | 不是所有历史或奇幻角色的默认装备 |
| 和服／kimono | T 形衣身方向、领襟、袖与系束的组合 | 时期、场合、穿法与袖长另选，不只写 floral robe |
| 浴衣／yukata | 与和服方向相关的衣身与穿着入口 | 按季节、场合、材料和层叠发展，不自动同义于所有和服 |
| 羽织、袴／haori, hakama | 外层衣身或下装结构入口 | 两种不同部件，与内外层配合 |
| 汉服方向／hanfu-inspired clothing | 通过具体上衣、下装、领襟、袖、系束和层叠落实 | 历史复现明确时期与形制；泛化幻想不能冒充定式 |
| 旗袍／qipao, cheongsam | 领襟、开合、衣身与下摆关系 | 长短、宽松程度、袖、开衩与时期不同 |
| 韩服／hanbok | 上衣、裙裤及系结的组合入口 | 具体部件、比例、时期和用途明确，不固定一个现代造型 |
| 纱丽／sari | 布料的裹覆、褶量和肩部垂披组织 | 穿法和配套衣物多样，不能与所有披布长裙同义 |
| 包头、头巾服饰／headwrap, headscarf ensemble | 头部包覆、折叠、固定与衣身关系 | 具体款式、用途和文化语境按任务选择，不自动推断身份 |
| 洛丽塔服饰／Lolita fashion | 裙体、上衣、装饰、鞋袜与头饰形成整套语言 | 甜系、古典、哥特等可发展，不把术语当年龄或人物性格 |
| 哥特方向／gothic-inspired styling | 轮廓、材料、色块与装饰的整体选择 | 服饰亚文化、历史建筑意象和幻想方向并非同义 |
| 朋克方向／punk-inspired styling | 剪裁、拼接、材质、标识与个人改造 | 不以固定铆钉套餐代替人物设计 |
| 蒸汽幻想／steampunk-inspired costume | 时代意象、机械材料与穿着用途的关系 | 齿轮、护目镜并非必选，机械连接可具体发展 |
| 科幻服饰／science-fiction costume | 世界设定、材料、功能与身体轮廓 | 不统一成黑色紧身衣或霓虹灯条 |
| 法师、战士等幻想职业／fantasy-role costume | 行动、携带、世界制度与个人穿法 | 职业名称打开方向，不固定长袍、巨甲或裸露程度 |

## 完整穿搭的关系

| 表达／英文入口 | 可见发展 | 组合用法 |
|---|---|---|
| 上宽下窄、上窄下宽／wide-top/narrow-bottom, narrow-top/wide-bottom | 上下身衣物的体量对比 | 与身体真实比例分开 |
| 同色层次／tonal outfit | 相近色在明度、材料和层次上的差别 | 不只给所有衣服同一色词 |
| 单点强调／single focal accent | 一个色块、配件或结构获得主次 | 其他区域形成支撑而非全部抢眼 |
| 内长外短、外长内短／length contrast between layers | 领、袖、下摆的显露组织 | 明确覆盖顺序和连接 |
| 软硬对照／soft/structured contrast | 挺括外层与柔软内层等关系 | 体积与褶量各自成立 |
| 正式与日常混穿／formal/casual mixing | 不同衣物语言在同一人物上的组织 | 用色、比例、材料或生活理由连接，不随意拼贴 |
| 成套、拆套、重复单品／coordinated set, separated pieces, recurring garment | 多套服装之间的共同点和差异 | 换装仍保留人物审美与身份锚点 |
| 不合身、借穿、改造／ill-fitting, borrowed, altered clothing | 肩袖、腰裤、衣长等具体偏差 | 对人物生活有贡献时发展，不把偏差等同坏设计 |
| 整理程度／degree of grooming and clothing arrangement | 扣合、卷折、塞衣角、皱褶与保养 | 同一类别可以表现不同人，避免只写整洁或凌乱 |
