# 发型与毛发词库

从整体发形、剪裁层次、局部分区、扎束、发质和颜色选择。发型可以组合，但同一部位的长度、遮挡与方向要相容；英文是语义入口，不保证为模型标签。流行名称常随地区和作品改变，用关键可见结构确定当前设计。

## 整体剪裁与发形

| 名称／英文入口 | 可见结构 | 变化与相近概念 |
|---|---|---|
| 寸头／buzz cut | 头发整体贴近头部、长度较短 | 长度、发际线与局部渐变另选 |
| 精灵短发／pixie cut | 短轮廓与较明确的头顶、前额组织 | 刘海、侧部与后颈长度可不同 |
| 波波头／bob | 下缘在脸侧或颈部形成整体轮廓 | 齐切、内扣、层次与不对称是可选变化 |
| 长波波／lob, long bob | 较长的 bob 方向轮廓 | 实际落点按肩颈描述，不锁死长度 |
| 齐切／blunt cut | 末端形成较明确的齐整边界 | 不要求头发绝对平直或没有内部层次 |
| 渐层剪裁／graduated cut | 分区长度形成体积与重量变化 | 与普通 layered cut 不简单互换 |
| 层次发／layered haircut | 不同长度的层次组织 | 可柔和或明显，不自动凌乱 |
| 羽毛感层次／feathered layers | 发梢与层间呈较轻的分离走势 | 强调末端组织，不等于羽毛材质 |
| 碎层／choppy layers | 长度与末端分区差异较明显 | 仍需要整体体积和轮廓 |
| Shag／shag haircut | 多层次、纹理与较松的轮廓 | 与 wolf cut 有重叠，按具体长度关系区别 |
| 狼剪／wolf cut | 头顶较短且有体积的碎层，向较长末端过渡 | 可短、长、直或卷；不能只写凌乱长发 |
| 鲻鱼头／mullet | 前侧较短、后部较长的长度对比 | 可以规整、卷曲或夸张，不必等同狼剪 |
| 蝴蝶层次／butterfly cut | 较短的脸侧层次与较长下层形成展开 | 与狼剪区别落实为层次、末端及体积，不只写气质 |
| 姬发式／hime cut | 刘海、较短脸侧分区与较长后部有明显分段 | 分段落点与刘海可变化，不默认固定历史服饰 |
| 剃短下层／undercut | 某个下层区域显著短于上层 | 位置与范围明确，放下上层时可被遮挡 |
| 侧剃／side shave | 一侧或局部贴短形成不对称 | 与整体 undercut 范围区别 |
| 不对称剪裁／asymmetric haircut | 两侧长度或体积有意不同 | 非镜头透视造成的假不对称 |
| 莫霍克／mohawk | 中央发区突出，两侧相对短 | 软、硬、宽窄与高度可选 |
| 非洲卷整体发形／afro hairstyle | 卷曲头发形成较充分的整体体积 | 形状、密度与长度可不同，不用发型推断人物身份 |
| 长直发／long straight hair | 长度与相对直的发束走势 | 仍可有根部体积、层次和发梢弯曲 |
| 大波浪／loose waves | 发束形成较宽缓的波形 | 卷曲幅度、周期、重量与长度配合 |
| 紧卷／tight curls | 较小且连续的卷曲组织 | 分区体积与卷束尺寸各自发展 |

## 刘海、分缝与脸侧

| 名称／英文入口 | 可见结构 | 变化与组合 |
|---|---|---|
| 齐刘海／blunt bangs | 前额下缘较齐整 | 厚度、长度、弧度与间隙另选 |
| 空气感刘海／wispy bangs | 稀疏或细束形成透隙 | 不是完全透明头发 |
| 帘式刘海／curtain bangs | 中央或近中央分开，向两侧展开 | 可短长、弯直，接脸侧层次 |
| 侧扫刘海／side-swept bangs | 前额发束主要向一侧组织 | 分缝位置与遮眼程度明确 |
| 短刘海／micro bangs, baby bangs | 前额较高处形成短下缘 | 齐切、碎切与弧形不同 |
| 锯齿或碎刘海／choppy bangs | 前缘长短错落 | 避免把每束都做同样三角形 |
| 八字形前额分束／outward-parted fringe | 前额两侧发束向外形成轮廓 | 日常称呼有弹性，按可见形状描述 |
| 中分、侧分、偏分／middle, side, off-center part | 发根分区的位置 | 不等于所有末端都对称或同向 |
| 无明显分缝／no distinct part | 发根组织不强调连续分缝线 | 仍有生长与梳理方向 |
| 脸侧修饰层次／face-framing layers | 沿脸侧形成不同长度的发束 | 颧部、下颌和颈部落点另选 |
| 侧发、鬓发／side locks, sideburns | 耳前或脸侧的局部分区 | 中文使用有重叠，写清位置与长度 |
| 耳后收发／hair tucked behind ear | 发束从耳前移到耳后 | 可露一耳或双耳，卷束与配件关系明确 |
| 遮眼发束／hair covering one eye | 发束遮住部分面部证据 | 不同时要求该眼完整可见，除非指定画法 |
| 呆毛／ahoge | 局部独立翘起的风格化发束 | 大小、根部与朝向服务角色轮廓 |
| 发旋与翘发／cowlick | 发根生长方向造成局部起伏 | 与刻意造型或风格化呆毛区别 |
| 外翻发梢／flipped-out ends | 发段末端向外卷或翘起 | 与整段卷曲、风吹方向分开 |
| 内扣末端／inward-curled ends | 发梢向颈或脸侧收回 | 长度、弧度与头颈接触配合 |
| 螺旋卷、纵卷／ringlets | 发束形成较连续的螺旋轮廓 | 单束粗细、松紧、方向与重量可不同 |
| 钻头卷双束／twin drill curls | 成对大束螺旋卷形成夸张轮廓 | 常见于风格化角色，不等同所有卷发双马尾 |
| 球状双髻／double round buns, odango-style buns | 两处圆团发髻形成整体发形 | 与下垂长发、辫子或无尾髻组合，连接要明确 |
| 独立头顶双翘束／paired antenna-like hair tufts | 两束翘起的头顶发束 | 是角色造型入口，不必当作生物触角 |

## 扎束、编发与盘发

| 名称／英文入口 | 可见结构 | 变化与组合 |
|---|---|---|
| 马尾／ponytail | 一处束点与下垂发段 | 高低、偏侧、紧松、束点周围体积另选 |
| 双马尾／twin ponytails | 左右两处束点 | 不自动完全对称，长度与位置可不同 |
| 半扎发／half-up hairstyle | 部分上层收束、部分保持披发 | 收取比例与束点位置明确 |
| 发髻／bun | 头发在束点附近盘成体积 | 高低、单或双、松紧与散发另选 |
| 低盘髻／chignon | 后颈附近较集中的盘发体积 | 可光滑或松散，不固定一种盘绕法 |
| 法式扭转盘发／French twist | 后部头发沿纵向卷收 | 顶部与末端处理另选 |
| 三股辫／three-strand braid | 三组发束交错 | 单双、粗细、紧松与起始位置明确 |
| 法式辫／French braid | 编织途中逐步加入周围头发 | 与普通从束点开始的辫子区别 |
| 荷兰辫／Dutch braid | 编织体积较突出地显于表面 | 与 French braid 的交织方向区别 |
| 鱼骨辫／fishtail braid | 细束形成密集交错纹理 | 不用普通粗三股结构代替 |
| 冠状编发／crown braid | 编发围绕头部形成环绕组织 | 起止与固定方式按设计决定 |
| 泡泡辫／bubble ponytail | 多处束扎形成分节膨起 | 不是连续编织 |
| 贴头编发／cornrows | 辫列沿头皮分区组织 | 列向、间隔、粗细与延伸长度明确 |
| 锁状发束／locs | 头发形成相对凝聚的束体 | 不当作普通编发，粗细与整理方式可变 |
| 扭转发束／twists | 分组发束相互扭绕 | 与 braid、locs 分别考虑 |

## 质感、颜色与状态

| 名称／英文入口 | 可见展开 | 组合关系 |
|---|---|---|
| 细软、粗硬感／fine, coarse hair texture | 单束尺度与整体服帖或支撑感 | 发丝直径、发量与蓬松不等同 |
| 浓密、稀疏／dense, sparse hair | 发区覆盖与发量观感 | 与束的粗细、风格简化分开 |
| 顺滑、毛躁／sleek, frizzy hair | 束内组织与边缘散丝 | 不仅依靠亮暗对比 |
| 蓬松、贴服／voluminous, flat-lying hair | 根部与整体体积 | 与湿态、束扎、头饰压力相容 |
| 散丝／flyaway hairs | 整体发束之外的小尺度发丝 | 选择性使用，不让每条轮廓都毛躁 |
| 湿发／wet hair | 分束、贴合、重量与反光变化 | 保留原剪裁和身份结构 |
| 梳向后方／slicked-back styling | 发束朝后梳理，前额显露 | 可以有体积或贴头，不等于剃短 |
| 黑、棕、金、红、灰白及幻想发色／hair color | 本色与局部色差 | 环境光与本色区分，非每束随机渐变 |
| 挑染／highlights | 选定发束或区域颜色不同 | 分布、宽度与对比另选 |
| 内层染／underlayer color | 不同颜色主要位于下层 | 何时显露由发型与姿态决定 |
| 分区双色／split-dyed hair | 头发分区采用不同本色 | 指定分区边界，不只写 multicolored |
| 渐染／ombré hair | 发长方向有较明确色彩过渡 | 本色设计，不是照明渐变 |
| 根部色差／visible roots | 发根区域与其余发色不同 | 边界软硬、范围与整理状态可选 |
| 胡须、络腮胡、短茬／mustache, beard, stubble | 毛发生长区域、长度与轮廓 | 与面部骨架、年龄和整理习惯共同设计 |

## 含糊名称的处理

“狼鬃发型”“狼尾”“狼剪”在日常与创作语境中可能重叠，但不能声明都是唯一标准译名。按 wolf cut 理解时，写出头顶碎层、体积与较长末端之间的关系；按 mullet 理解时，突出前侧与后部的长度对比；按兽化鬃毛理解时，另设计生长区域与毛发轮廓。用户语境足够时直接选择，忠实复现任务才核对关键歧义。

结构参考：[L’Oréal Paris 的 wolf cut 说明](https://www.lorealparisusa.com/beauty-magazine/hair-style/hairstyle-trends/wolf-haircut-ideas)、[Dyson 的 wolf cut 造型说明](https://www.dyson.com/discover/news/latest/how-to-style-a-wolf-cut)。名称帮助检索，具体角色仍由[人物组合设计](../12-人物设计与外观组合.md)决定。
