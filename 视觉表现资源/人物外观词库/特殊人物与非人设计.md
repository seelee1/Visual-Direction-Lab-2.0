# 特殊人物与非人设计词库

用于扩展人物类型、年龄、身体特征与幻想结构。类型名称只打开设计方向，不能代替具体形态，也不能规定人物的性格与命运。现实人物按参考与实际可见特征描述；幻想人物可建立自主结构与形式规则。

## 年龄、身体差异与人物类型

| 入口／英文表达 | 可见发展 | 组合关系 |
|---|---|---|
| 婴幼儿比例／infant, toddler proportions | 头身、四肢、脸部体量与支撑能力的年龄差异 | 按具体年龄发展，不把缩小成人当儿童 |
| 儿童体态／child proportions | 身体成长阶段与活动姿态 | 个体差异可大，不统一放大眼睛 |
| 少年成长感／adolescent proportions | 面貌、四肢与整体比例的阶段差异 | 不要求全身同时表现所有成长特征 |
| 中年人物／middle-aged character | 面部、身体、衣着与生活状态的个体组合 | 年龄不必由皱纹数量证明 |
| 老年人物／older character | 皮肤、面部体量、毛发及姿态的可选变化 | 活跃、挺拔、结实、柔和等均可成立 |
| 高龄人物／advanced-age character | 个体面貌、动作和生活细节更充分的发展 | 不自动套用衰弱、驼背与拐杖 |
| 不同体量分布／varied body-volume distribution | 躯干、面部、四肢的独立差异 | 衣物贴合与身体结构分别处理 |
| 高大或矮小的个体／very tall, very short stature | 环境参照、比例与行动尺度 | 极端身高不必极端肌肉或儿童面貌 |
| 不对称身体结构／asymmetric body structure | 局部长度、体量或连接的稳定差异 | 姿势形成的临时不对称另存 |
| 肢体差异／limb difference | 缺失、长度或结构差异的具体范围 | 衣服、支撑和器具设计相互协调 |
| 义肢使用者／prosthesis user | 接受腔或接口、连接、外形与活动结构 | 写可见组件，不凭空指定医学适配性能 |
| 轮椅使用者／wheelchair user | 座姿、椅体、手部操作与场景关系 | 轮椅结构与人物身体分别设计，不固定一种轮椅或姿态 |
| 手杖、助行器使用者／cane, walker user | 器具接触、支撑与行动方式 | 不单靠道具推断病因或人物能力 |
| 中性、柔和、刚毅等外观倾向／androgynous, soft, angular appearance | 身体、面貌、衣发与表演的组合 | 气质词不是固定性别或骨架配方 |
| 生活型普通人物／everyday character | 个人衣着、整理、年龄与细节差异 | 不必为辨识度添加奇特伤疤或标志装备 |

## 人与动物特征的不同整合

| 入口／英文表达 | 可见发展 | 组合关系 |
|---|---|---|
| 兽耳型人物／human character with animal ears | 人形面貌与局部动物耳结构 | 是否保留人耳、耳根位置和发区连接需明确 |
| 兽人／anthropomorphic animal | 头部、身体、毛皮、四肢与人形姿态的整合 | 狼、猫、鸟等不能只换耳朵与尾巴 |
| 人兽混合面部／hybrid facial structure | 口鼻前伸、牙齿、鼻部、眼眶和毛发的比例 | 选择人形与动物形的整合程度，保持正侧面关联 |
| 吻部／muzzle, snout | 鼻口区域向前发展的体积 | 与人的鼻梁、嘴唇形态不无意叠加 |
| 趾行腿／digitigrade legs | 足部与腿段形成趾部支撑轮廓 | 不把后抬的足跟画成反向膝盖 |
| 蹄足／hooved feet | 末端硬质结构、分瓣与支撑 | 物种方向与腿部连接配合 |
| 膜翼／membranous wings | 支撑结构与翼膜范围 | 根部、收展、衣服避让和身体平衡明确 |
| 羽翼／feathered wings | 翼体与不同羽区的组织 | 大轮廓、羽列和根部可有层级 |
| 尾部／tail | 根部、长度、体量、末端与运动范围 | 作为附属器官而非随意漂浮线条 |
| 鳞片、甲壳、毛皮／scales, shell plates, fur | 表面分区、方向和接缝 | 硬软部位及关节活动范围分别设计 |
| 角、鹿角、触角／horns, antlers, antennae | 不同生长结构、分叉和表面 | 根部位置、重量与头部轮廓配合，不随意互换 |
| 长耳精灵型／long-eared fantasy character | 耳部长度、形状和连接 | 面貌、身体和文化设计不只依靠尖耳 |
| 水生混合人物／aquatic hybrid character | 鳍、尾、鳃状结构和水中姿态 | 人形与游动结构的过渡、衣物和浮力分别处理 |
| 多臂、多眼或多头／multiple arms, eyes or heads | 附加结构的根部、间距与组织 | 同镜与跨镜数量稳定，动作注意与接触有分工 |
| 巨人与微型人物／giant, miniature character | 相对尺度、环境接触与行动空间 | 体型比例、材料尺度和观看距离自主选择 |

## 机械、人工与非实体身体

| 入口／英文表达 | 可见发展 | 组合关系 |
|---|---|---|
| 人形机器人／humanoid robot | 躯体分段、关节、表面与移动结构 | 不只将皮肤涂成金属色 |
| 仿生人／android | 人形外观与人工结构的显露程度 | 外表与内部设定分开，不可见内部不必全部描述 |
| 人机混合／cyborg | 生物与机械区域的边界、接口和活动范围 | 部位选择、连接和材料差异清楚 |
| 外骨骼／exoskeleton | 身体外部的支撑与动力结构 | 与护甲外观、人体关节和服装穿着区分 |
| 装甲身体／armored body | 保护板、软连接和关节空间 | 身体本体与穿戴甲片不混为一层 |
| 球节人偶／ball-jointed doll | 球状关节、分段和表面材料 | 体态、线条与活动范围形成统一造型 |
| 布偶、软体人偶／fabric, soft-bodied puppet | 缝线、填充体量、软连接和挤压 | 不用人体肌肉形态解释全部变化 |
| 石、木、陶瓷构体／stone, wooden, ceramic figure | 材料组织、断面、接点和运动规则 | 表面变化与关节连接要对应材料或幻想规则 |
| 植物人物／plant-like character | 茎叶、根部、纤维和生长分区 | 肢体与植物结构如何整合需具体决定 |
| 菌类或群体构体／fungal, collective body | 局部个体、聚集形态和整体轮廓 | 可有形体变化，但身份锚点另选 |
| 流体人物／fluid-bodied character | 表面、体积保持、分离和重组 | 不能同时要求全身刚性关节与任意流动，除非分区 |
| 幽灵、半透明体／ghostly, translucent body | 可见表面、透显、遮挡与边缘规则 | 半透明不自动等于完全无体积 |
| 光体、粒子体／luminous, particle body | 核心轮廓、密度、散出和聚合 | 人物本色、发光、照明作用分别决定 |
| 几何、拼贴人物／geometric, collage character | 平面块、拼接、线条与层间组织 | 可依图形规则成立，不强制人体写实结构 |
| 可变形身体／transforming body | 原形、变化方向、局部过渡与目标形态 | 静态选一个可见状态，视频再发展连续过程 |

## 整合要求

确定根部与连接、支撑与接触、材料分区、活动范围、衣物避让和可延续的身份特征。只选择与当前作品有价值的部分，不为每个幻想角色完成工程说明。写实结构与有意图形夸张分别自洽，不把所有非人形都纠正成人体。

义肢的组件关系可参考[Ottobock 的下肢义肢说明](https://www.ottobock.com/en-gb/prosthetics/back-to-mobility/prosthetic-fitting)，这里用于视觉结构设计，不提供选型或医疗指导。生物和机械运动可深入[既有模块](../../参考资料/表现库/V10-生物与机械.md)，整体形态仍由[人物组合设计](../12-人物设计与外观组合.md)决定。
