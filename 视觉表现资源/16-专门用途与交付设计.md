# 专门用途与交付设计

用于产品与商业画面、文字版式、信息图和建筑表达。不是额外流程清单：用途改变艺术判断、可见重点与交付责任，已有光影、风格、人物和场景知识继续按需调用。只读取相关完整章节，不默认发展所有用途。

用户给定的产品、文字、数据、图纸和用途是设计条件；美化与表达选择不能暗中改变这些事实。创意虚构可自主发展，但要与已有材料区分。没有明确精确要求的概念探索可以继续，不要求用户先填写专业制作问卷。

## 产品与商业画面

调用静物摄影、材质照明、品牌视觉、陈列、使用场景与广告叙事知识。先决定是外观展示、材料观察、使用说明、主视觉还是系列推广；相同产品可以有不同任务，不统一成中心悬浮加光环。

| 发展方向 | 可见设计 | 用途判断 |
|---|---|---|
| 外形与比例 | 关键轮廓、开合、尺度、可辨部位与观察角度 | 真实产品保留结构，不能为了漂亮改形 |
| 材料与照明 | 高光形状、反射环境、边缘、透射、粗糙与局部对比 | 看见材料区别，不所有产品同一种光泽 |
| 背景与接触 | 支撑、接触影、反光、环境色与留空 | 悬浮可以是主动创意，不与落地状态混写 |
| 使用与尺度 | 人物、手、环境及操作的关系 | 不让道具或使用动作遮住必须展示的部位 |
| 重点与细节 | 主视角、局部、结构、包装或成组陈列 | 单图与多图分别分配观看，不每张都讲全部信息 |
| 动态展示 | 旋转、开合、取用、材质变化与镜头揭示 | 动作让观众看见有用差异，不只无目的环绕 |
| 品牌语言 | 色彩、比例、构图、材料、文字和节奏的共同选择 | 系列保持语言，各幅可承担不同功能 |
| 商业叙事 | 产品、使用者、场景或图形形成短段落 | 创意意象与实际性能描述分开，不凭特效证明功效 |

真实文字、标识、规格与包装参考按提供内容保存；未给定品牌内容不随意编造为真实事实。广告气质不自动要求写标语、加价签或音乐。多尺寸传播先明确各幅用途，再考虑主体位置、留字区与裁切；不同画幅可以重新构图，不把关键物裁掉后声称只是等比适配。

默认交付：一句视觉方向＋画面或镜头方案＋必要的主体保留项和文字区域。要生成提示词时用既有 Anima/H3 格式；要系列时另写各幅／镜的用途与共同锚点。产品素材、精确文字、照明与构图、合成或排字职责分别交接，不能只写“品牌高级感”。

摄影入口：[Adobe 的产品摄影说明](https://www.adobe.com/creativecloud/photography/type/product-photography.html)。本文的广告组织与交付约定是项目设计，不是统一商业规范。

## 文字版式与图像组织

调用平面设计、字体、网格、信息层级、图底、留白、节奏与媒介知识。用于海报、封面、标题卡、广告、漫画对白和字幕等；根据用途组织，不强制每张插画都有文字。

| 发展方向 | 可见设计 | 用途判断 |
|---|---|---|
| 内容职责 | 标题、副标题、正文、说明、标识和装饰文字 | 先决定读什么及顺序，不所有文字同级 |
| 网格与对齐 | 列、区域、边距、共同基准与有意偏离 | 精确版面按实际尺寸，不假设统一安全区数值 |
| 字形与字重 | 衬线、无衬线、书写、展示性字形及粗细 | 与语言、用途、时代和阅读尺度配合 |
| 字距、行距与长度 | 行内和行间的密度、换行与文本块形状 | 不为了排版默改用户原文 |
| 图文关系 | 遮挡、环绕、叠印、独立区域或空间嵌入 | 美感和可读性共同决定，不随意盖住关键面部或信息 |
| 色彩与对比 | 文字、底色、材料或局部图形的主次 | 不仅靠颜色表达分类，小尺寸要有可辨证据 |
| 留白与节律 | 文本块、图像和空处形成观看路径 | 不是将所有空处填上解释 |
| 动态文字 | 显露、停留、退出、与镜头或动作同步 | 读完所需时间和装饰运动分别判断，不能无限快闪 |

默认交付：准确文字清单及职责＋位置、层级和图文关系＋必要尺寸或阅读条件。用户要提示词时，图像表现按模型格式，精确文字与排字要求另保存；不把所有字变成图像标签。生成、真实字体、后期排字和最终检查的职责根据工具明确，不能凭一张示意图承诺文字完全准确。

没有真实文字时可提出明确标为创作选择的文案；忠实排版任务保留原文。字体名称与使用条件只有需要精确制作时核对，描述字形气质并不等于指定已取得的字体资产。视觉层级入口：[NN/G 的视觉层级说明](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/)。

## 信息图、解释图与动态说明

先分辨要表达的是数量、结构、流程、空间、因果、概念关系还是步骤。没有数据的概念图不能伪装成量化证据；已有数据、单位与关系必须保留。信息图可以简洁、艺术化或叙事化，但不能用视觉华丽替代理解。

| 表达任务 | 可调用的形式 | 保留要求 |
|---|---|---|
| 数量比较 | 长度、位置、点、分组与小多图 | 数值、单位、基准与比较范围明确 |
| 时间变化 | 线、顺序、阶段与动画推进 | 时间间隔、缺失项与数值不随意平滑 |
| 结构与层级 | 分层、树形、剖面、局部放大与分解 | 部件、包含关系及相对位置成立 |
| 流程与操作 | 步骤、路径、箭头与状态变化 | 顺序、分支、输入输出明确，箭头不自动代表因果 |
| 空间关系 | 地图、平面、轴测、透视与示意 | 真实比例与概念示意分别标明 |
| 机制与因果 | 参与对象、驱动、响应和结果的图形组织 | 原因、相关、顺序和假说分别表达 |
| 多条件对照 | 并置、重复布局、差异标示 | 比较对象使用相容尺度和语义，不让画法制造假差异 |
| 动态解释 | 分阶段出现、局部强调、回看锚点与持续参照 | 新信息加入时保留理解线索，不每镜重置图例 |

设计编码时考虑位置、尺寸、形状、颜色、线型与标注之间的分工；数量图和装饰图分别对待。图例、轴、注释、来源和不确定性按实际需要提供，不能省掉解释尺度后用“直观”代替。准确图表不依赖生成模型随意绘制点位，按数据与可编辑绘图方式交接。

默认交付：要解释的关系＋选定视觉编码或组织＋准确数据／标签清单＋构图和阅读顺序。缺少必需数据时先做明确的结构方案，不捏造数值作为成品；可以用已标明的占位展示布局，最终数据交付前保持待填状态。需要动画时再写阶段、持续参照和解释节奏，不直接套剧情高潮。

图表选择与轴线参考 [ONS 的图表选择](https://service-manual.ons.gov.uk/data-visualisation/chart-types/choosing-a-chart-type)及[轴线与网格指南](https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines)，具体编码依据当前关系选择，不把某种图形作为所有解释的默认模板。

## 建筑与空间表达

调用建筑可视化、场景美术、空间组织、材料与环境知识。先判断用途：气氛概念、空间体验、设计沟通、构件说明还是已有建筑展示。概念美图可以自主设计，忠实表达必须继承已有平面、结构、尺度与材料条件。

| 发展方向 | 可见设计 | 用途判断 |
|---|---|---|
| 视图职责 | 透视、正投影、平面、立面、剖面、轴测、局部与分解 | 选择能解释当前关系的视图，不只是最戏剧化镜位 |
| 空间体验 | 入口、路线、围合、层高、尺度、室内外与活动 | 观看序列展示不同关系，不重复环绕外观 |
| 材料与细部 | 构件、接缝、表面、厚度及光影 | 与建筑整体语言一致，不只贴材质纹理 |
| 环境与时间 | 地形、相邻建筑、植被、气候、季节与光照状态 | 场景艺术与实际地点条件分别表达 |
| 多视图连续 | 同一空间在外观、内部、平面与剖面中的对应 | 开口、层数、楼梯和相邻关系不能无意改变 |
| 人物与使用 | 行动、尺度参照、家具和通路 | 人物不是随机装饰，不能堵住要求展示的关键结构 |
| 分层与图示 | 结构、围护、设备、使用区或材料分别展示 | 分类来自当前设计，不擅自编造真实构造 |
| 动态漫游 | 观察高度、路线、停留、揭示与光区转换 | 运动路径与实际连通关系相容，避免穿墙充当运镜 |

默认交付：表达目标＋视图或观看序列＋主要空间与材料关系＋必须保留的已有条件。需要精确尺寸或施工意义的内容从真实图纸和数据取得，不能从气氛渲染图反推保证；这是视觉交付责任，而非额外专业问卷。

现成建筑的连续表达可先保存简短空间锚点，再逐图、逐镜解释当前视点，避免每次重新生成楼梯和门窗。建筑素材、模型或图纸、艺术渲染、精确标注和后期合成分别交接。不同视图类型参考 [Autodesk 的项目视图说明](https://help.autodesk.com/cloudhelp/2026/ENU/Revit-DocumentPresent/files/GUID-8B1294DC-617E-48F9-AC18-A998F43384C9.htm)，场景表现继续调用[场景资源](13-场景设计与背景组合.md)。

## 用途之间的协作

漫画封面可以结合人物、版式与系列语言；产品短片可以结合商业方向、分镜和连续状态；建筑解释视频可以结合空间、信息图与时间揭示。只结合实际有贡献的部分，不因用途多就叠加全部交付表。

艺术设计与实现方案分别维护。文字、数据、精确尺寸、身份、品牌及已给定结构作为交接重点；生成提示词保持 Anima/H3 的既有格式，准确内容与后期职责另存。用途约定是本项目的交付设计，不声称为这些模型的官方新增字段。
