# 维护工具

当前创作来源为 `助手指令/核心指令.md`、`助手指令/输出适配/`、`助手指令/创作规范/` 和 `视觉表现资源/`。专业支撑在 `参考资料/`。本目录的历史修订文件描述当时状态，不作为使用说明。

## 当前构建与检查

修改当前来源后，从项目根运行：

```powershell
pwsh -File ./项目记录/版本与工具/构建输出适配包.ps1
pwsh -File ./项目记录/版本与工具/检查项目.ps1
```

构建程序将当前来源汇编到 `助手指令/使用版本/`，生成通用创作、Anima 和 MiniMax-H3 三份复制版。通用版不绑定模型，专用版不加载另一模型规则或项目记录正文。分镜等专项模块仍按需提供。不要直接修改生成版本；先修改来源，再重建并检查。

检查本地 Markdown 链接、编码、JSON、资源编号、当前适配包及现行来源哈希、历史包、旧冻结请求和实际试验记录。历史路径按[迁移映射](历史路径映射.json)解析；冻结来源清单描述过去，不要求今天的源码保持过去的内容。通过表示结构与保存完整，不证明艺术效果。

## 冻结与历史工具

`构建使用包.ps1` 是旧通用包的构建工具，日常维护不运行：它会覆盖冻结包及清单。需要新通用版本时，应先调整版本和输出目标，保留旧快照。

案例目录的准备和记录程序用于建立新批次、保存实际获得的回答，不是自动联网测试客户端。旧研究过程中的实验程序只服务原实验。不得为重跑而覆盖冻结目录或伪造输出。

仓库禁用自动换行转换，因为冻结内容按原始字节校验。非冻结入口可编辑；冻结原文保持不变。密钥、环境与缓存不进仓库。
