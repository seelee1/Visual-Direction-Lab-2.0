# 当前状态

更新：2026-10-27。

## 可以怎样使用

统一读取[创作入口](../创作系统/入口.md)，之后直接描述作品需求。所有任务共用同一套核心、能力和材料；指定模型只影响最后的交付格式。需要在其他 Agent 中使用时，解压[唯一导出包](../导出/README.md)并使用同一入口。

## 当前结构与覆盖

当前 v0.8 将运行内容统一到“创作系统”：入口、任务、能力、材料、交付。旧的助手指令、视觉表现资源、人类视觉语言库和参考资料目录已迁移移除，重复启动与路由说明合并到入口。专业卡、词库和关系条目保留有用正文与编号，更新内部引用，不保留旧结构的兼容副本。

共享能力包含构图、运镜及[剪辑与时空组织](../创作系统/能力/剪辑与时空组织.md)：先组织观看、并置、省略、重复、联想与节奏，再用切镜、连续调度、图形或分层变化承载。分镜负责实际镜头与阶段交付。相关例子是创作提案，未做新一轮生成或成片验证。

首批 8 条关系材料覆盖身体接触、衣发柔性材料、空间光影，依据既有资料整理及表达设计。当前结构与导出已同步；尚未完成新版 Agent 自主调用或生成效果对照，不能用结构检查证明知识利用或生成改善。

入口支持先定位章节、再按具体问题取得正文，静态、动态和修改转换分别使用阅读停止条件；压缩时将核心关系与必要条件共同保留。实际调用的记录方法见[案例与验证](创作案例与验证/README.md)，要求保存真实读取轨迹与完整原始结果。这些约定已纳入当前系统，尚不代表完成了新一轮调用效果测试。

## 已知限制

资源能够唤起具体的视觉关系，但更多资料不一定带来更好的设计。模型仍可能在支撑、连接、方向、空间与可见性上自相矛盾；转换提示词也可能继承构思中的错误。

文本测试不是独立盲评，后台模型版本未知，重复样本有限；不能据此保证跨模型、跨风格或长期创作的稳定效果。Anima、GPT Image 与 H3 的输出约定已整理，但未完成系统的实际生成验证，本项目直接执行的 GPT Image 生图与 H3 视频运行数均为 0。GPT Image 另保存一项用户成图观察，不计入受控测试；手工格式示范也不计入模型测试。

本项目专注设计内容，执行与生成按用户选用的工具完成。后续以实际作品暴露的问题为依据修订，不再维护未执行的大规模实验计划或逐次修改日志。
