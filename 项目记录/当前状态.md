# 当前状态

更新：2026-10-26。

## 可以怎样使用

从[启动入口](../助手指令/启动入口.md)使用项目，让 LLM 按创意调用自己的视觉知识，并按需参考表现资源。没有输出格式要求时，直接做设计；需要生成提示词时，再选 Anima、GPT Image 或 MiniMax-H3 适配。

现有内容覆盖人物、场景、风格、构图与深度、运动与物理表现、光影、分镜、漫画、系列作品及专门用途。它们提供构思方向，不是必用清单，也不代表穷尽所有艺术知识。只能复制文本时，使用[当前使用版本](../助手指令/使用版本/README.md)；专项资源按需另附。

## 当前结构与覆盖

新增[人类视觉语言库](../人类视觉语言库/README.md)，以日常经验索引连接条件、可见过程与表达示例；首批 8 条关系覆盖身体接触、衣发柔性材料、空间光影。艺术资源与专业卡保持原位，由语言库链接复用。核心 v0.6 加入这一职责，各使用版同步构建。新增条目为既有资料整理及表达设计，尚未完成新一轮模型或实拍验证，不能用结构检查证明生成改善。

## 已验证什么

- DeepSeek 网页进行了四轮文本测试，共 40 项有效回答，另有 1 项模式偏差记录排除。详见[案例与验证](创作案例与验证/README.md)。
- 已保存 Anima 成图观察与 [GPT Image 会话中的朋克成图观察](创作案例与验证/GPT-Image-朋克风格观察/README.md)，均为用户提供的单例，没有控制对照；后者实际模型与生成设置未知。
- 分镜、连续作品和专门用途有人工演练，不算独立模型或成片验证。
- 当前维护检查可核验链接、使用版与来源是否一致，以及已保存测试输入和回答的完整性；不能证明创作质量。

## 已知限制

资源能够唤起具体的视觉关系，但更多资料不一定带来更好的设计。模型仍可能在支撑、连接、方向、空间与可见性上自相矛盾；转换提示词也可能继承构思中的错误。

文本测试不是独立盲评，后台模型版本未知，重复样本有限；不能据此保证跨模型、跨风格或长期创作的稳定效果。Anima、GPT Image 与 H3 的输出约定已整理，但未完成系统的实际生成验证，本项目直接执行的 GPT Image 生图与 H3 视频运行数均为 0。GPT Image 另保存一项用户成图观察，不计入受控测试；手工格式示范也不计入模型测试。

本项目专注设计内容，执行与生成按用户选用的工具完成。后续以实际作品暴露的问题为依据修订，不再维护未执行的大规模实验计划或逐次修改日志。
