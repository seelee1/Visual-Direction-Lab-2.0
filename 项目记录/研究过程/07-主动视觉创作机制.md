# 主动视觉创作机制 v0.1

日期：2026-10-10 · 阶段 2 原型 · 项目推导 D，经过本轮公开文本演练与边界审查，尚未独立模型/成片验证。

## 1. 能力目标与知识接口

面对简单创意，主动发现具体表现可能性，把合适的可能性发展成可观察、协调、有取舍的作品。用户不需要先给出摄影或动画术语。

三层知识分别维护：[基础知识](../../参考资料/知识体系导读.md)、[表现库](../../参考资料/表现库/00-表现库导读.md)、本文件中的艺术判断。短系统指令只规定调用责任，不代替整个知识体系。知识文件实际不可用时，不能假装已检索或援引条目。

流程是组织工具；实际探索可往返，也可一次直接完成。最终回答的长度与表现库规模无绑定关系。

## 2. 把创意表示为有自由度的场景

只维护与任务有关的信息，避免填空表。最小创作表示包含：

| 项 | 要记录什么 | 用处 |
|---|---|---|
| 用户硬要求 | 必须保留的主体、事件、风格、时长、镜头与禁用项 | 防止丰富设计改写任务 |
| 开放变量 | 未指定的场所、照明、观察位置、情绪和道具 | 给主动创作留下空间；补充是选择，非用户事实 |
| 表现目标 | 想让观众辨认/感受什么，或纯形式目标 | 可由输入直接给定，也可提出温和的创作方向 |
| 参与关系 | 驱动/连接、光/材质、遮挡/显露、时间/参照 | 发现机会与核对条件 |
| 主变化与保留 | 哪些变、哪些保持；起始/终止状态 | 避免“停住”同时要求所有层继续主位移 |
| 可见证据 | 画面何处、何时看见什么 | 排除景别下无法辨认的专业细节 |
| 风格规则 | 体积/空间/形/线/色/曝光的保留与有意改写 | 允许创造，限制无意漂移 |

不用要求用户先指定全部开放变量。一般创作选择直接补全；会使任务互斥或根本改变要求的缺失信息才追问。没有指定情绪时，不固定为悲伤/孤独。

## 3. 双向探索与场景机会

### 从目标寻找证据

“急停要有力度”可探索接触与上身迟滞、镜头相对停止、空间余地突变、短过渡形与清晰落姿。它们不是都必须加入。用户要求脚部可见时，镜头方向不能删除接触证据。

### 从现象发现表达

输入“雨中站立”未给明确情绪，可以从本体/倒影的不同状态、雨层空间、局部界面事件或二维线色关系发现方向。先看见一种有价值的关系，再判断它是否值得成为表达重点。

### 发现新组合

表现库外仍允许创造。通过改变观察证据、信息揭示、时间重心、材料联系或形式规则发展新方案；说清楚可见变化与成立条件。纯形式美感可成为充分理由，不强行附会剧情。

当一个领域是主角而知识不足时，定位需要补的参考。背景细节可简化；主导现象不能用自信术语掩盖理解空缺。

## 4. 相关触发，避免每次全领域遍历

以下是按关系查找机会的入口，不是每轮检查清单：

| 场景线索 | 首先值得考虑的关系 | 可能的选择 |
|---|---|---|
| 突然停止、碰撞、解除接触 | 支撑、惯性参考、连接、恢复 | E001/E004/E005/E006 |
| 保持、等待、未回应 | 预期、一次局部改变、空处、外界错位 | E007–E012 |
| 遮挡、接近、未知目标 | 观察位置、显露、尺度参照 | E013/E015/E017/E018 |
| 移动灯/影、反光 | 谁移动、受影响面、观察依赖 | E019–E024 |
| 湿、软、透明、头发与布料 | 接触、轮廓、材质动态与光学 | E025–E036 |
| 风雨烟火雪植物 | 源、空间、材料差异、接触、结束状态 | E037–E042 |
| 二维/绘画/抽象/奇幻 | 线色、图底、采样与保留规则 | E043–E048 |

同一线索有多个不同方向；未触及的领域不强制调用。探索也可从跨域的新关系开始，不局限本表。

## 5. 选择依据与主动省略

候选只有在改变作品的可见表现时才值得发展。判断相互竞争的方向：

1. 满足用户要求和基本可见性，是进入候选的条件。
2. 看它为意图或形式增加了什么，是否与已有细节重复。
3. 看依赖条件是否能在当前场景内成立；新增设定是否改变了用户目标。
4. 看主事件与支持层的时间/空间是否相容；可同时发生多事，但需有组织。
5. 看采用后的收益与代价，例如从全身切到特写会失去脚部证据。

这些判断不使用固定权重或“每次选三项”。不确定时可比较实质不同方向；不默认让用户从多方案菜单中选。

用删除/替换检查发现无效细节：若删掉“4K、极致、细腻”而设计没有变化，优先删；若删掉“主体保持、倒影受扰动”就失去主机制，保留。纯形式纹理可能很重要，不统一删背景细节。

不预设克制永远更好。高密度场景可以把同时爆发作为形式目标，需明确各层如何汇聚到核心事件并留出辨认状态。

## 6. 把机制发展到作品需要的程度

### 时间展开

记录起始、转折、持续与结束，或有意不结束的状态。相对先后通常比任意毫秒/角度更有用。用户给定 5 秒时，阶段分配须容纳主事件，不能要求每个滴/发/影都独立走完整周期。

### 空间展开

确定主体、重要接触/界面、观察目标与参照关系。特写和全景展示不同证据；不能要求微观挂滴与全身制动在同一远景同时清晰。

### 形式展开

确定哪些变化用轮廓、线、色面、影、姿态或采样表现。写“日漫”不足以指定画法；也无需每镜规定所有线色参数。按当前关键表现选择。

### 关系展开

多项效果有共同驱动、共同观察目标或有意对比时才形成组合。例如手松开布料，同时主褶与影形改变；两者帮助看懂同一接触解除。任意追加路灯闪烁可能只是在争夺注意。

对核心关系保留短标识：如 D1“主位移停止后发束延续”、D2“回头目标在来路侧后方”。标识用于后续转换审计，最终用户输出无需编号。

## 7. 按相关风险检查，允许有意偏离

| 风险 | 检查与修订 |
|---|---|
| 空间与目标矛盾 | 核对朝向、目标和观察位置；不把回头自动改直视镜头 |
| 状态层级矛盾 | 根位移、主体姿态、附属、环境、镜头分别说清楚保持/变化 |
| 光影驱动混淆 | 区分光源、遮挡物、受光物和视点；镜面反射与漫反射不共用任意变化 |
| 连续/接触丢失 | 明确流入流出、接触解除、持有者和结束状态 |
| 可见性失败 | 改观察方式或减细节；不能只用“细腻”声称远景微观已表达 |
| 模板化丰富 | 检查是否默认雨+伞+夜灯+悲伤、动作+白闪+速度线、安静+风+粒子 |
| 风格化被误杀 | 先判断是否有意形式改写；只修无意矛盾，不强迫全部写实 |
| 技术边界提前删创意 | 先保留艺术母版，再标控制/分层与损失；没有环境不编节点能力 |

遇到冲突先改场景条件或艺术选择；不要自动添加一条永久禁令。无法在当前篇幅展开全部现象时，保留主机制与支持条件。

## 8. 输出与交接原型

默认直接给一份完整、连贯、可独立理解的视频生成提示词，使用用户语言或其指定语言。主体/环境、观察关系、主事件、重要材料/光影联系、时序和形式处理在连续文本中协调表达。不要先输出全套内部分析。

用户要概念探索、分镜、静态图、设计解释或制作交接时，按其目标改变输出；静态不强加时间序列。系统不绑定某视频模型。

此阶段的最小转换责任：核心可见机制及成立条件进入成稿；研究解释可省略。重要项若只进入关键帧/分层控制，明确提示词本身的不足。完整压缩/模型适配规范留待阶段 3。

可选设计说明只解释实质选择和必要创作假设，不展示长清单、思维过程或知识命中率。

## 9. 原型的失败归因

输出贫乏：检查未发现机会、资料不够具体、未理解条件或过早自我删减。输出繁杂：检查艺术取舍与主事件。文本自洽但不好看：回到形式/表演与真实观看，而非假定逻辑检查足够。成稿丢关系：修转换。成片失真：核对实现，再决定是否修艺术母版。
