# 输出结构固定 · 适配 v0.3

日期：2026-10-10。重新核对 Anima 官方模型卡和 MiniMax-H3 两份官方提示指南，改写输出适配及两个实际助手。创作核心 v0.5、静态表现资源 v0.1 与旧试验保持原版本。

Anima：官方标签分组顺序保留；项目固定为 Positive 与 Negative 两个可复制代码块。正向为标签首行，随后依次组织主体姿态、构图空间、光色材质、绘制细节。不适用内容省略，不为结构添加效果；负向仅一行逗号分隔标签。Base、Aesthetic 与未知版本分别处理评分标签。官方允许混合提示自由排列，自然语言段序是项目约定，不能声称官方强制四段。

H3：基础模式固定三字段，全参考模式固定六字段；首末帧模式直接采用对应官方对齐句，镜号与时长填实际值。补全参考任务类型前缀、定义与保留关系、全参考正文的风格起句、声音段落分工等要求。输出一个代码块，不默认附解释报告或自创字段。

当前输出结构优先于通用核心的连续自然段默认交付。更新只限定成稿组织，不将视觉表现资源变成必做项目。结构检查与保存完整性验证不等于 LLM 已稳定遵循格式，也不证明生成质量；需后续用独立实际回答验证。
