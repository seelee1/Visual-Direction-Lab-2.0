# v0.5 相关资源对照报告

2026-10-10，已完成 12 项 DeepSeek 网页请求。相关资源确实能唤起更多具体关系，但尚未稳定解决连接、轴向与空间衔接问题。专用场景入口有时让目标更明确，也会被压缩为缺少画面条件的概念句。本轮不支持“更多入口即更好设计”，也不能区分模型内部究竟是知识激活还是示例模仿。

## 条件与范围

同一轮比较四个已公开任务：钥匙、两人搬板过窄门、抽象形状显现、少女跑停回头。统一输出为一份 300–500 字符提示词；新会话、深度思考开启、搜索关闭，未提供评审答案。后台模型版本未公开，不承诺每次路由到的后台版本一致。

| 条件 | 实际装载 |
|---|---|
| K | 完整 v0.5 核心 |
| R | K 加按预定规则提取的相关通用资源行与过程段落 |
| E | R 加对应的 S-V 场景变体段落 |

R 没有专用场景变体段落，但其通用入口仍有简短举例，不能称“完全无例子”。E 还增加构思方向、条件提醒与篇幅，因此不是纯粹的例子有无实验。没有长度匹配，也未加入无关材料作控制。相关选段是开发者预选，不能据此断言模型自行检索路由成功。

钥匙没有专用 S-V 段，T002/R 与 T003/E 的实际请求逐字相同，作为同文重复参照，不能把它们的差别归因于条件。其余独特输入各一次：共 11 种独特请求、12 次实际完成。该规模不足以评价稳定性或统计效果。此次为开发者知条件审查，条件隐藏材料已建立，尚未做独立盲评。

材料和输入在运行前冻结，随机顺序执行；[管理清单](管理清单.json)保存选取规则、来源哈希、请求哈希与装载指纹，[运行顺序](运行顺序.json)保存实际进度。发送前检查模式及完整输入正文，长文本恢复为原文后逐字核对。原始输出同名 JSON 保存会话地址、最终文本哈希及采集时间；不保存思考展开文本。准备快照的状态保留不改，完成情况见[运行状态](运行状态.json)。

没有装载完整包、输出约定全文或评审意见，没有进行艺术母版到提示词的独立转换，更没有视频生成。

## 四组实际比较

### 钥匙：连接错误在资源提醒下仍复现

- [K/T001](原始输出/T001.md)：共挂三把钥匙，又加入链条；以大小直接分配摆幅，接触、摆动、高光与投影较常规。新增链条本身可以是创作选择，但结构没有进一步说明。
- [R/T002](原始输出/T002.md)：挂钩、共挂五把、接触点、相碰改向、高光扫过齿槽更具体；仍安排依次错峰和固定的安定先后，没有充分建立连接与运动条件。
- [同文重复/T003](原始输出/T003.md)：改为压住最长钥匙、钥匙微弯弹开，又明确写“因环扣串联先后响应”。共挂设置与串联解释未统一，局部弯曲的材料和尺度条件也不足。

同文重复一方面展示输出波动，另一方面说明资源里写了区分，不等于模型在生成中落实了区分。这里批评的是当前文字没有支持其断言，不宣称所有特殊钥匙或连接都不可能出现这些行为。不能用更多“真实惯性”或“条件正确”提醒替代实际空间和连接表达。

### 搬运：协作丰富，但转向关系没有完全成立

- [K/T004](原始输出/T004.md)：仍采用碰门、调整、斜过门洞；门框阴影在板面滑动，但两手支点、抬压端与旋转轴关系含糊。
- [R/T005](原始输出/T005.md)：不碰门，换握、前人倒退引导、两端分段显露、门框负形重组更具体；一端抬高、板身倾斜和长轴对准门洞之间仍缺少明确转向过程。
- [E/T006](原始输出/T006.md)：分工、持续支撑、补位、遮挡及出入影区展开；同时写“沿自身长轴缓慢转向，从横向变为纵向”。翻转板面与改变长轴朝向没有区分，专用入口未解决核心空间问题。

R、E 中的无碰撞协作是值得保留的候选表现，但不是稳定改善证据。E 在支撑、换握、分段显露等方面更可审查，不能因一个轴向问题把所有艺术贡献抹去；也不能因贡献增加忽略该问题。

### 抽象：具体形式发展存在，但仍集中于收拢闭合

- [K/T007](原始输出/T007.md)：分叉、绕行、分色、覆盖与重新显露已较具体，不是只有核心就退回泛泛描述；结尾为闭合环状形与缺口填入。
- [R/T008](原始输出/T008.md)：线条密度、负形变化、色块吞没轮廓、线变内部纹理和图底反转形成不同形式过程；最后的偏心圆与斜线怎样从前段主形演变仍较概括。初始写闭合轮廓的“局部”，未证明完整闭合后又无过渡打开，不能机械沿用上一轮判错。
- [E/T009](原始输出/T009.md)：散线与方块聚拢，空隙先排列出环形，邻接与负形比从头画外轮廓更突出；仍回到补线闭合与完整形静止收尾。“按明确图形规则翻转”只是规则名称，翻转对象、方向或时序没有充分写明。

R、E 唤起了资源中相关的形式关系，但不能据此说纯形式方案范围已被全面打开。四周聚向中央、闭合与静止依然占主导；还未验证持续变化、局部显现、非中心构图等不同目标的主动选择。

### 跑停回头：目标改善伴随概念复述风险

- [K/T010](原始输出/T010.md)：已明确“视线越过肩头看向身后”，接点全程保留；无需场景入口也能完成这一选择。投影随姿态变化有所涉及，但光影协同仍较简单。
- [R/T011](原始输出/T011.md)：机位、参照、地面余量和足部状态更具体；头转向镜头方向、眼看向来路，二者在侧后机位可能兼容，但没有把来路与镜头方位进一步说明。“镜头因惯性略向前冲”可理解为摄影过冲设计，不能自动判成主体惯性错误；其驱动与观看效果仍需更清楚。
- [E/T012](原始输出/T012.md)：中全景与接点、回望来路明确；却将“前方运动留白”直接称为回望空间，没有交代前后方、人物位置与取景怎样重组。属于缺少成立证据的空间关系，不应只因复述了资源概念而判成功。

场景入口中的关系被直接保留，有利于目标明确，也可能被误压缩成口号。本轮无法仅凭词句相近认定它是模仿或没有调用知识。艺术母版与成稿的转换尚未独立测量。

## 长度与交付

按最终可见文本 UTF-16 长度计算，含标点、数字和内部换行，去除文件末尾换行，非 token 数。11/12 在 300–500 范围内。T012 为 299，属于边界合规失败；不据这一字符差异降低其艺术评价，也不删除样本。各项成稿未输出分析列表，部分使用段落。

| 比较记录 | 最终长度 |
|---|---|
| 钥匙 K / R / 同文重复 | 332 / 300 / 357 |
| 搬运 K / R / E | 308 / 318 / 307 |
| 抽象 K / R / E | 391 / 309 / 381 |
| 跑停 K / R / E | 329 / 354 / 299 |

K 平均 340；R 平均 320.25；三个有新增场景入口的 E 平均 329。没有按长度判胜，也不把同文钥匙重复合并成新增场景入口的效果统计。原始记录足以复算，不用平均长度证明质量。

## 结论与下一步

1. 保留通用与场景入口两种用法，不把整包设成唯一默认。部分资源有可见贡献，核心条件也有具体设计，尚无最佳加载方法的稳定证据。
2. 不继续为每个失败补禁令。下一轮将“概念关系是否真正落实”作为诊断：连接部件、转向前后的位置和可见形必须在简短艺术设计中可审查，专业词与关联标签不算落实证据。
3. 把艺术构思与转换分开测一次。保存简短艺术母版中的核心关系，再压缩成连续提示词，检查轴向、朝向、空间用途等是否在构思时已错，还是转换时丢失；不索取或保存隐藏思考过程。
4. 加入真正不同的任务与条件迁移。安静场景、移动光影、流体界面和自然过程应优先补测；不要只在四个公开任务上持续调词，避免对案例过度拟合。该组目前未执行。
5. 需要可靠比较时补重复与长度/相关性控制，再安排不了解条件的评审。本轮建立了条件隐藏材料，但不能冒充已经完成盲评。

保持 v0.5 源码与发布包不变；本轮反馈进入评估记录。下一次修订应围绕泛化的关系表达与转换，不写“钥匙必须怎样摆、木板必须怎样转”的答案模板。
