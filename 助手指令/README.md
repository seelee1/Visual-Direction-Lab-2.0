# 助手指令

日常使用见[接入说明](接入说明.md)，agent 从[启动入口](启动入口.md)按任务加载。

- [核心指令](共用内容/核心指令.md)：主动构思与艺术判断。
- [Anima 格式](共用内容/输出适配/Anima-生图.md)／[H3 格式](共用内容/输出适配/MiniMax-H3-视频.md)：只读当前目标的适配。
- [表现资源](../视觉表现资源/README.md)：按需要展开，不默认全文装载。
- [转换与信息保留](共用内容/输出与信息保留.md)：复杂成稿和制作交接时深入。

不能读取项目、只能复制文本时，使用 [Anima 完整助手](Anima.md)或 [H3 完整助手](MiniMax-H3.md)，无需再叠加核心。完整助手包含广域激活与艺术风格资源，Anima 另含静态表现；它们是复制载体，不是所有 agent 的默认加载量。
