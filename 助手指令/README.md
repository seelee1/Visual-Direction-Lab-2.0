# 助手指令

日常使用见[接入说明](接入说明.md)，agent 从[启动入口](启动入口.md)按任务加载。

- 日常创作：[启动入口](启动入口.md) → [核心指令](核心指令.md)，按创意取用[表现资源](../视觉表现资源/README.md)。
- 指定生成模型时：[输出适配](输出适配/README.md)提供 Anima 与 H3 的格式。
- 需要深入交付、长期保存或协作时：[创作规范](创作规范/README.md)提供可选支持。
- 只能复制或上传整份文本时：[使用版本](使用版本/README.md)提供通用版和模型专用版。

核心、适配与规范是维护来源；使用版本由它们汇编，供不同接入方式选择。能读取项目的 agent 使用入口即可，无需重复装载整份复制版。
