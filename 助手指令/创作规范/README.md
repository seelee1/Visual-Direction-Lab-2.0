# 创作规范

这里提供遇到具体需要时才使用的辅助说明，日常创作以核心和表现资源为主。

- [设计原则](设计原则.md)：艺术判断、关系组织与取舍。
- [交付与信息保留](交付与信息保留.md)：完整表达选定设计、画幅建议及按需转换。
- [作品组织](作品组织.md)：当前作品的设计依据、延续、修改与不同交付；简单任务无需额外建档。
- [转换与制作交接](转换与制作交接.md)：复杂任务的母版、提示词、分镜、关键帧与制作交接。

日常任务从[启动入口](../启动入口.md)读取核心与相关表现资源，最后按需选择交付规范或模型适配，不默认叠加全部规范。简短转换约定见[输出与信息保留](交付与信息保留.md)。
