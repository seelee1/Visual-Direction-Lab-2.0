## 给创作模型的当前配置

当用户请求可用的生成提示词时，根据交付对象自动选择：静态图片、角色设定图、场景图或单张关键帧采用 [Anima](Anima-生图.md)；视频或动画采用 [MiniMax-H3](MiniMax-H3-视频.md)。用户只说“设计”时保持核心默认视频交付，输出 H3 格式；用户指定静态则输出 Anima 格式。艺术构思、分镜、解释等任务仍按用户要求交付，不强制变成生成格式。

已指定“先生图再动画”时，两部分分别交付：Anima 负责选定静态时刻，H3 负责从实际输入画面发展的时间关系。不能把全部动作阶段塞进一张图，也不能把尚未生成或未提供的图假装为已看过的参考。没有要求两个阶段时，只输出当前需要的模型分支。

本层是对通用输出约定的特定格式补充：模型提示词主体按对应指南使用英文；说明仍用用户语言，台词和画面内文字保持原文。不固定 300–500 中文字符，那是旧实验控制条件；也不为填长度添加装饰。用户明确要求其他语言时遵从，并说明与当前格式的区别，不声称英文是所有模型的唯一能力边界。

默认不猜测 Anima 权重变体、采样器、LoRA、H3 输入模式或未提供参考资产。未知但不阻碍成稿的条件以通用版本处理；条件决定关键帧角色、人物身份或参考含义且无法合理选择时，简短澄清。没有参考的 H3 请求默认 T2VA；一张图片若角色不明确，不自动判为首帧。

保留母版中的重点、必要条件与艺术选择，再做标签、字段、参考和音画表达。格式正确不等于实际效果已验证。已查看一张用户提供的 Anima 成图，用户表示满意，观察见[案例记录](../../../创作案例与验证/Anima-夏日玻璃花房观察.md)；未进行控制对照，H3 视频仍未运行。

生图使用[Anima 生图使用版](../../Anima.md)，视频使用[MiniMax-H3 视频使用版](../../MiniMax-H3.md)。每包含共用基础版和对应模型适配；Anima 另含静态表现资源 v0.1，不包含另一模型规则。旧合并包从当前目录撤下，原文由 Git 历史保留。

模块化时使用一个通用包或核心，再只提供所需的模型适配。需要先生图再视频时分别在两个任务中装载；共享母版和实际图像，不必共享两个完整适配。构思资源与模型格式独立选择，扩展/深化版也只配当前需要的一个适配文件。

只读本页的链接不会自动取得规则；必须提供对应正文、文件或实际可用的检索。两个适配文件都区分“官方摘记”和“项目转换约定”，未引用第三方聚合站规则。
