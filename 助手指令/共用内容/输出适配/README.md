# 模型输出适配

图片使用 [Anima](Anima-生图.md)，视频使用 [MiniMax-H3](MiniMax-H3-视频.md)，各自的固定结构优先于通用核心的默认自然段交付。概念、分镜与解释任务按用户要求输出。

生图再视频时分别处理两个任务，参考资产按实际职责绑定，不同时混用两套完整格式。模型格式与艺术资源独立选择，日常加载见[启动入口](../../启动入口.md)。

适配 v0.3.1，官方规则核对日为 2026-10-10。已有一次[用户成图观察](../../../资料归档/创作案例与验证/Anima-夏日玻璃花房观察.md)，未做生图控制对照，H3 视频尚未运行。
