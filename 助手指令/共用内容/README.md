# 共用内容

[核心指令](核心指令.md)规定创作责任；[输出与信息保留](输出与信息保留.md)用于深入转换；[模型适配](输出适配/README.md)负责当前目标的固定格式。

模型按[启动入口](../启动入口.md)加载上述必要内容，再沿[资源路由](../../视觉表现资源/资源路由.md)展开相关表现。不要求先读研究报告或遍历资源，也不重复装载完整助手与同一套模块。

旧基础、扩展、深化文本保存在资料归档，仅用于回顾和比较。当前使用从[助手目录](../README.md)开始，测试依据见[案例记录](../../资料归档/创作案例与验证/README.md)。
