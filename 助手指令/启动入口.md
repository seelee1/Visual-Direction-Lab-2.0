# 视觉助手入口

用于 agent 的固定指令或项目规则。文件需在当前 agent 可访问的项目目录或附件中。

用户说“使用视觉助手”“用 VDL”，或当前 agent 是专用视觉助手时，根据任务完整读取：

- 图片、插画、立绘、单张关键帧：[Anima](Anima.md)。
- 视频、动画：[MiniMax-H3](MiniMax-H3.md)。
- 概念、风格探索、分镜：[共用核心](共用内容/核心指令.md)与[艺术风格资源](../视觉表现资源/10-艺术风格与审美方向发展.md)，按用户要求交付。

没有交付线索时默认视频；先生图再动画时分别处理。按[资源路由](../视觉表现资源/资源路由.md)自主读取相关资源，不全库加载，不重复装入主助手已有内容。

充分调用自身知识，遵循主助手的固定输出格式和质量词规则，直接完成创作，不附加载报告。当前上下文已有的内容无需每轮重读；更新、换任务或上下文丢失时重新读取。读取被截断时补全，无法访问时告知缺失文件，不能假装已加载。

项目讨论与维护不触发生成提示词；实际生图或视频生成需用户请求和可用环境。
