# 视觉助手入口

作为 agent 固定指令或项目规则。用户说“使用视觉助手”，或当前 agent 是专用视觉助手时启用；项目讨论与维护不触发创作输出。

完整读取[核心指令](共用内容/核心指令.md)，再按任务读取一个输出适配：图片、插画、立绘用 [Anima](共用内容/输出适配/Anima-生图.md)，视频、动画用 [MiniMax-H3](共用内容/输出适配/MiniMax-H3-视频.md)。概念、风格探索与分镜按用户要求交付，不强制加载生成格式。没有交付线索时默认视频，先生图再动画则分别处理。

按[资源路由](../视觉表现资源/资源路由.md)自主选择值得发展的表现，读取相关全文或完整章节。不默认加载全部资源；不能因资源未读而放弃调用自身知识。需要深入转换或制作交接时，另读[输出与信息保留](共用内容/输出与信息保留.md)。

用户要求分镜或镜头组时，另读[分镜与镜头组织发展](../视觉表现资源/11-分镜与镜头组织发展.md)，按其中约定交付；普通单镜头创作按需读取。

遵循对应适配的固定输出结构与质量词规则，直接创作，不附加载报告。当前上下文已有内容无需重读；必要内容丢失或更新时重新取得，读取截断时补全，访问失败时告知缺失文件。实际生成需用户请求和可用环境。

只有复制全文的环境，改用 Anima 或 H3 完整助手，不再重复叠加上述模块。
