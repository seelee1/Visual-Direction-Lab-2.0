# 配置一次，直接创作

本项目提供启动入口与创作资料。其他 agent 是否自动读取项目规则、保留固定指令或检索附件，取决于它实际支持的功能；本入口没有新增跨平台运行程序。

## 能访问本地目录或仓库的 agent

让 agent 的项目／工作目录指向本项目。项目根目录的 [AGENTS.md](../AGENTS.md) 为支持该文件约定的 agent 提供入口，触发后读取[启动指令](启动入口.md)和实际助手。此处不修改电脑上其他 agent 的全局配置。

若该 agent 不自动读取 AGENTS.md，在其持久项目规则或固定指令中配置一次：

```text
视觉创作任务使用 Visual Direction Lab。项目根目录为你可访问的 Visual-Direction-Lab-2.0 目录。收到“使用视觉助手”或“用 VDL”时，完整读取该目录中的“助手指令/启动入口.md”，按入口读取实际助手和相关资源，再完成创作。普通非视觉任务不启用。
```

这段需要把“项目根目录”绑定到该 agent 真正可访问的目录，不能只留下仓库名或私有 GitHub 链接。本电脑当前根目录为 `C:\Users\Sakura\Dev\python-dev\艺术设计助手`；其他设备使用其实际路径。私有仓库需要该设备已有的授权访问，下载后从本地读取即可。

之后只发送：

```text
使用视觉助手，设计一张花房人物插画，输出 Anima 提示词。
```

## 专用视觉 agent

在 agent 的固定指令中放入启动入口正文，把它设为专用视觉助手，提供本项目的文件访问。之后不需要触发词，直接输入创意。若只做生图，也可直接用 [Anima 助手](Anima.md)全文作为固定指令；只做视频则用 [H3 助手](MiniMax-H3.md)全文。

## 只有附件与固定指令的 agent

一次性提供启动入口、当前需要的完整助手、资源路由，以及希望可选读取的表现资源；将启动入口正文设为固定指令，并要求通过实际附件读取正文。没有文件读取能力时，直接把对应完整助手正文放入固定指令。不能仅上传入口并期待它取得本地链接的内容。

持久项目／agent 配置保存成功后，新的创作请求只发创意。若平台仅支持普通会话，没有持久配置，新会话仍需一次性加载完整助手；同一会话后续无需反复粘贴。

## 首次检查与后续更新

第一次可以单独要求：“确认你实际能读取启动入口和对应完整助手，列出文件名，然后按它设计一张插画。”确认访问后，日常创作不附读取报告。不能仅凭“我已加载”的自述证明文件完整进入上下文；文件工具的读取结果与实际输出结构可用于诊断。

从仓库读取的 agent 在文件更新后重新取得内容；使用上传附件或复制指令的 agent 需要替换旧文件／正文。升级内容不会自动同步到已复制到其他平台的配置。
