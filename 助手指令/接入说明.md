# 在其他 agent 中使用

## 能读取项目目录

将本项目提供给 agent。支持 `AGENTS.md` 的 agent 从根目录规则进入；不支持时，在其固定指令中配置一次：

```text
视觉创作时，读取 Visual Direction Lab 项目中的“助手指令/启动入口.md”并按它工作。收到“使用视觉助手”即可启用。
```

将项目位置设为该 agent 实际可访问的目录。之后只发“使用视觉助手，……”和创意；专用视觉 agent 可省略触发词。

## 只能用固定指令或附件

默认将[通用创作版](使用版本/通用创作.md)设为固定指令，之后直接发创意，无须先指定输出形式。若 agent 可读附件，也可使用启动入口、核心和相关表现资源；模型适配作为可选附件，交付时按需求加载。

通用版含基本的作品延续规则；持续保存、跨 agent 交接或复杂修订需要深入组织时，另提供[作品组织](创作规范/作品组织.md)。只做一幅画或一个短镜头不必额外提供。作品当前设计与助手资源分开交给 agent，不把作品设定当作所有创作的永久规则。

明确专用于 Anima 生成时可使用 [Anima](使用版本/Anima.md)；明确专用于 H3 生成时可使用 [MiniMax-H3](使用版本/MiniMax-H3.md)。图片或视频设计本身不要求选择这些模型。必须能实际读取附件，链接不会自动取得本地正文。

## 只有普通聊天

会话开始时粘贴通用创作版，后续直接发创意；需要某个模型提示词时，再提供对应适配。专用模型会话也可直接粘贴相应完整助手。没有持久配置的新会话需要重新加载一次。

配置完成后先确认文件可读。复制或上传的文件在项目更新后需手动替换；本项目不会自动修改其他 agent 的配置。
