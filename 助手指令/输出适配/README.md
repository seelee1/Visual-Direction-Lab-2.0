# 模型输出适配

这里是艺术设计完成后的可选交付层。明确要求 Anima 提示词时使用 [Anima](Anima-生图.md)，明确要求 GPT Image（gptimage）提示词时使用 [GPT Image](GPT-Image-生图.md)，明确要求 MiniMax-H3 提示词时使用 [H3](MiniMax-H3-视频.md)。只说图片、视频或动画不自动指定模型；没有输出要求时按核心交付视觉设计，未指定模型的提示词采用通用画面或镜头描述。其他模型按实际提供或核验过的规则适配。

生图再视频时分别处理两个任务，参考资产按实际职责绑定，不同时混用两套完整格式。模型格式与艺术资源独立选择，日常加载见[启动入口](../启动入口.md)。

Anima 与 H3 适配 v0.3.1，官方规则核对日为 2026-10-10；GPT Image 适配 v0.1，核对日为 2026-10-26。各适配的语言、格式和参数边界分别定义，不互相套用。验证范围统一记录于[项目状态](../../项目记录/当前状态.md)。
