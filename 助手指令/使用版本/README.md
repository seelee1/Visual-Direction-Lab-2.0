# 整份复制使用

只有需要粘贴完整指令或上传单个附件时使用。能读取项目目录的 agent 从[启动入口](../启动入口.md)进入即可。

| 需要 | 使用版 |
|---|---|
| 自由创作，不绑定模型 | [通用创作](通用创作.md) |
| 已明确专用于 Anima 提示词 | [Anima](Anima.md) |
| 已明确专用于 GPT Image 提示词 | [GPT Image](GPT-Image.md) |
| 已明确专用于 MiniMax-H3 提示词 | [MiniMax-H3](MiniMax-H3.md) |

选择一份，不叠加核心或其他完整版本。各使用版包含视觉语言的表达方法；通用创作与 H3 版另含首批关系条目，静态版按需要另附条目。日常经验索引和专项资源按创意另行提供，复制版不包含全部资源。项目更新后，需要手动替换其他 agent 中的副本。

本目录内容由当前来源汇编生成；修改应回到核心、资源或对应适配，再运行项目记录中的构建工具。
