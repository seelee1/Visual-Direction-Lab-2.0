# 跨域组合深化：G07–G18

承接原 G01–G06，增加十二个艺术组织草案。它们是 D，既不是事实卡，也不是每镜必须执行的技巧。探索时先选作品希望观众感到的形式关系，再决定过程；可以采用、省略、反转或提出新组织。

| 编号 | 组织思路 | 可发展的例子 | 适用边界与反转 |
|---|---|---|---|
| G07 | **把过程转为关系变化** | 两人交杯时，杯尚在两手间，承重转交和负形关闭共用一个拍点；松手后空隙再次出现 | 快速日常交接不必长暂停；亲密也可通过顺畅无停顿表达。E050/E079 |
| G08 | **让颜色承担空间回应** | 两处小暖色因开门或转身同时可见，先无故事地建立形式押韵，后续再决定角色关系 | 不把同色自动解释成命运；也可用不匹配色块产生冲突。E081/E086 |
| G09 | **保留不可逆的后果** | 裂纹、雪压痕、湿迹、空椅改变场景，动作结束后由后果接管观看 | 弹性材质不能任意永久凹陷；结尾可悬置而非全恢复。E069/E071/E058 |
| G10 | **重新分配谁有权改变画面** | 少女保持，云影经过；下一段环境保持，少女姿态改动；再让二者会合 | 不机械交替，不强加角色心理；密集同步高潮也可成立。E109/E095 |
| G11 | **让结构替代表情符号** | 无脸机器人通过连接轴、朝向与距离回应；动物以适合物种的主动附肢显出目标 | 不是任何耳/尾姿态都有固定含义；纯机械任务可无拟人。E060/E068 |
| G12 | **近似图形连接不同尺度** | 薄膜孔缘转为月边/水岸；保留轮廓桥梁，改变尺度和质地 | 形似不能保证意义；如需要真实连续时间，明确这是剪辑/形式跳跃。E076/E091 |
| G13 | **把可见性作为行动** | 草簇、竹帘、雾或色区使对象局部丢失再显露，核心动作是“看见关系改变” | 不自动套隐藏/揭示悬念；关键接触需要清楚时保持无遮挡。E080/E088/E112 |
| G14 | **表现不足以说出口的变化** | 原任务继续，脸上的笑只形成一半；手收尾后身体才转向，不加心理独白 | 不把任何犹豫诊断为复杂创伤；突发反应可全身同步。E049/E051 |
| G15 | **让高密度同时有一个方向** | 雪团、粗线、光形和布弧共同横扫画面，动作顶点短暂失读，再从一个接点重获辨认 | 写实层不能所有物体违背驱动同速；不是少细节才高级。E107/Y10 |
| G16 | **以材料状态替代旁白时间** | 冷杯外结珠、融液汇流、湿沙边界或植物形态变化显示时间，机位参照维持 | 若过程很慢要标加速/省略；不将物理时间硬塞进五秒。E073/E074/E120 |
| G17 | **同一因果，换一种视觉证据** | 写实按压看皮肤/反光，平涂看主轮廓和接触影，剪纸看片层间距 | 保留关系而非整套细节；不只换风格名。E108/Y09 |
| G18 | **有意拒绝常见套餐** | 雨景不用路灯、孤独、发丝飘动，改为日光中水片和颜色邻接；停止不用振荡，改主动稳定与背景相对运动 | 禁用只为诊断和探索，不建立新强制套餐；若常见技巧最合适仍可采用。E028/E067/H06 |

## 判断方案是否实质不同

比较变化中心、主要观看证据、时间组织和形式规则。只把蓝光改成红光、固定镜头改成“电影感”、同样动作再增加颗粒，通常没有改变核心表现。相反，交杯可以以承重与手势为中心，也可以以前后空隙和色块为中心；两者都可能包含同一个动作，却具有不同观看目标。

一次方案允许局部混合，但不能简单把所有方向叠满。组合值得保留的理由可以是清楚、张力、形态美、持续观察、奇观、歧义或节奏，不限定为叙事解释。若方案需要违背常态，应明确艺术规则和保留的锚点，而不把常态描述与违背描述写成同时成立。

## 创造性候选的批判方法

先看其画面效果是否可说清：删除该组织后损失什么。再换一项条件，如远景、无对白、硬材质、真实时间或竖画幅，观察原组织是否失效、需要重译或仍成立。能指出失效条件并不证明艺术上优秀，最终还要通过作品、模型与观众测试。反例检查服务于创意，不以消灭所有风险为唯一创作目标。
