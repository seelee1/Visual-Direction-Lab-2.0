# 漫画分格与页面组织

## 调用说明

- **层级**：任务组织模块。共同职责与调用规则统一见[入口](../入口.md)。
- **何时读取**：漫画需要分格、页面、翻页、条漫或对白组织。
- **解决什么**：决定阅读顺序、格间省略、页面关系及文字位置。
- **何时深入**：单格造型与空间调用[共享能力](../入口.md)，长篇连续性查系列模块。
- **何时停止**：页面可读且格间信息明确，不额外套视频时间线。

用于单页漫画、跨页、条漫、连载与漫画转视频。调用漫画演出、页面设计、分格、文字与读者参与的知识。漫画不是视频分镜截图集：读者可以提前扫到页面、回看、自主停留；格间的省略与整页组织共同产生时间。

## 阅读载体与顺序

先根据用户要求决定页漫、跨页或条漫，以及左至右、右至左或纵向阅读。日式画风不自动意味着右至左。没有方向线索时可采用用户语言常见方向并简短注明，不以此阻止构思；忠实匹配已有作品时依实际布局。

纸页的翻页、跨页中缝，手机条漫的屏幕与滚动空间，都是演出条件。画面比例、文字和重要信息不能只以完整画布缩略图判断；需要精确印刷或平台规格时取得真实尺寸和要求，不自称统一官方规范。

## 技法与表现入口

| 方向 | 具体展开 | 创作判断 |
|---|---|---|
| 整页与局部主次 | 页面的黑白、色块、轮廓、密度与最大画格 | 一格漂亮但破坏阅读时重组，不默认大格就是高潮 |
| 阅读路径 | 格位、人物朝向、视线、文字与留空共同引导 | 非常规结构也要有可读路径，编号不能替代视觉引导 |
| 格间关系 | 同一动作不同阶段、行动与反应、不同人物、不同场所、环境片段或联想 | 前后图共同产生关系，不只连续换景别 |
| 时间省略 | 接触前后、动作后果、等待、停顿与被跳过的阶段 | 单格表现关键时刻；多阶段需可辨安排，不写成视频运动指令 |
| 分解与压缩 | 多格拆细一个变化，或一格概括持续状态 | 更多格不一定更慢，文字量和细节也改变阅读体验 |
| 重复与差异 | 相同机位、同一物件或表情多次出现 | 微小变化可有贡献，不把重复全部当冗余 |
| 无声与环境格 | 人物保持、物件、空间或自然变化 | 可以组织观看与感受，不强加旁白解释 |
| 格间距与边框 | 空隙、边线、无框与边界变化 | 可形成分段与形式关系，不给格距固定秒数 |
| 出格、叠格、满页图 | 人物或图形跨边界，局部压在另一格上 | 维持阅读、空间或明确图形规则，不仅装饰 |
| 翻页与跨页 | 当前页末的期待、翻后显露与整幅展开 | 同页可预见的信息不冒充翻页后才揭示；重要内容避开实际中缝 |
| 纵向滚动 | 屏内信息、空白、延迟显露与纵向运动 | 不能把纸页等比拉成长条代替条漫设计 |
| 场景与身份延续 | 地标、持物、朝向、服装与当前状态 | 格间省略不让物件无意换手、人物换脸 |
| 漫画动作语言 | 关键姿态、残像、速度线、冲击与象征图形 | 按风格具体组织，不每次动作都加全套特效 |
| 黑白与网点语言 | 大黑白、线密度、纹理与灰阶组织 | 人物、背景、文字可读性与印刷尺度一起考虑 |
| 色彩漫画 | 场景配色、画格色块与连续对比 | 情绪与时空变化可不同，不全页统一滤镜 |

镜位、调度与镜间观看可调用[分镜](分镜.md)，连载与人物发展可调用[长篇资源](系列.md)。借用知识，但保持页与格的阅读逻辑。

## 对白、旁白与拟声

用文字职责决定位置：谁说、对谁说、何时读到、与当前画面是什么关系。气泡、尾巴、旁白框、拟声和无字画面分开，文字量与画格面积共同安排。多个气泡的顺序要与阅读路径一致，避免尾巴穿过重要面部或误指说话者。

对白可揭示未画出的信息，也可与画面形成对照，但不要复述每个已看见的动作。用户给定台词保持内容；不得为了排版偷偷删改关键意义。内心、旁白、实际对白与屏内文字有明确角色，不无意把角色心声变成别人可听到的话。

字形、字重、间距、气泡形状与拟声可以参与演出，不要只增大所有文字表达强烈。文字语言、阅读尺寸与最终排字另按用途安排。生成图里的文字若未实测可靠，保留准确文字清单与预留区域，交给实际排字环节核对，不把拼错的文本当作完成。

## 默认漫画交付

用户要漫画设计且未指定格式时，先简短说明载体、阅读方向和页面策略，再按页与格给出下表。页面布局用简短位置说明或有必要的布局草图表达，不默认另造复杂文件格式。

| 页／格或条漫单元 | 布局与画面 | 关键时刻或状态 | 文字与阅读连接 |
|---|---|---|---|
| 页码、格号及位置 | 格形、主要构图、人物与环境关系 | 当前可见状态及与前格的变化 | 准确对白／旁白／拟声，或明确无字；下一格接续或省略什么 |

需要文字时标明说话者与顺序，不要求每格都有文字。关键画格、漫画格、视频镜头和生成图片分别编号理解；一格可能用多层素材完成，一镜也可能改成多格，不能机械一一对应。

生图逐格或整页按实际生成方式提供构图与状态说明，准确文字与版面要求另交接；不把一段连续动作当成一张图必然完成的画面。需要单格提示词时按 Anima 的现有 Positive／Negative 格式，不增加自创模型字段。漫画方案默认不强制输出生成提示词。

## 漫画与视频的相互转译

同一事件转换时保护可见关系，再重新组织载体：漫画的留白和翻页可转换为保持、切镜或延迟揭示；视频的连续动作可拆成关键状态与格间省略。是否需要重画、补中间动作、重排文字或改变镜头，应具体记录，不承诺直接拼接图片就是有效视频。

例如“少女发现门口来人”：视频可以持续跟随她抬眼并移动揭示；漫画可以用人物目光、空门口的一部分和翻页后的身影组织。若用户限定门口无人，则两种媒介都不能为揭示擅自加人。技巧不改变用户事实。
