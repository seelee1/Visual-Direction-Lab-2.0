# 专业知识体系 v0.2：导读与覆盖地图

## 在调用结构中的位置

本库属于依据材料层。在当前设计的连接、运动、空间、材料或光学等关键条件存疑时，定位对应卡及来源；解决疑问后返回作品。卡内设计建议不覆盖[核心职责](../../入口.md)，也不要求先学习整个知识体系。需要艺术方向选择时进入[能力目录](../../入口.md)，需要局部可见过程时进入[表现卡](../表现/README.md)。

日期：2026-10-10 · 阶段 1 基础与阶段 2 深化 · 性质：研究基础与设计建议，尚未经过独立系统或成片验证。

## 1. 如何使用这套知识

本知识库研究视觉艺术、角色动画、摄影、构图、时间、光影、材料、自然现象、特效和日式二维制作。它提供可选择的机制、条件和反例，不要求每个场景把所有领域都写一遍。

知识条目分为十三个模块，共 150 张卡：原六模块 80 卡，本轮七模块 70 卡。每张卡包括概念或观察、适用条件、反例、跨域联系、设计选择与依据。卡内“设计选择”是本项目的建议，不代表来源作者作出同样建议，也不表示已证明能提升成片质量。

|---|---|---|

## 2. 证据标记

| 标记 | 含义 | 使用边界 |
|---|---|---|
| P | 物理/光学教材或科学机构资料 | 在其假设与尺度下成立；不能自动推出艺术上必须写实 |
| R | 知觉研究、研究综述或明确提出的理论 | 保留实验/理论条件；不能自动预测每位观众的情绪 |
| C | 制作者经验、制作方说明或专业教学 | 作为有条件的制作知识；不能当作日漫或所有动画的统一规定 |
| D | 本项目的设计推导与建议 | 可批评、可替换；必须经案例与观看验证 |
| O-static | 实际查看作品静帧 | 仅支持直接可见的静态特征；不推出动作、曝光或作者意图 |
| U | 未读取正文、仅定位入口或缺少证据 | 不作为已核验事实；列入待研究清单 |

卡片的依据只支持相应基础概念。卡中的场景例子、取舍和跨域关系一般是 D，不扩大来源结论。S 编号可在来源登记查到标题、链接和支持范围；U 编号专门记录未核验入口。

原基础研究没有作品直接观察；本轮深化新增[六张官方静帧观察](../依据/观察/01-官方二维静帧观察.md)，使用 O-static，仍未逐镜观看连续影像、分析原画/时间表或读取真实摄影素材。制作者对作品的说明继续属于 C，不冒充亲自观察。v0.2 深化范围与专项欠项见[深化导读](../依据/研究范围.md)和[当前验证边界](../../../项目记录/当前状态.md)。

## 3. 什么叫覆盖全面

全面包括四个维度：领域覆盖、对象覆盖、关系覆盖和边界覆盖。只多列技法不构成全面。

| 维度 | 已纳入内容 | 限制 |
|---|---|---|
| 领域 | 原计划十个领域均有条目、来源与反例 | 是创作基础覆盖，不是各学科的百科全书 |
| 对象 | 人物、头发与布料、刚体、透明/反射表面、水、气体、火、植物、降水、粒子 | 具体生物步态、材料参数与复杂现象需专项参考 |
| 尺度 | 微小表演、局部材质、全身运动、环境变化、单镜头与多镜头 | 不能将杯中水的时空尺度直接移到海浪 |
| 风格 | 日式二维重点；写实、绘画、图形化、定格与二维/三维结合 | 不假定同一技法在不同风格中效果相同 |
| 场景状态 | 静止、周期、突然变化、传播、碰撞、消散、显露与遮蔽 | 安静不等于无设计，热闹不等于表现力强 |
| 输出 | 理想设计、可观察表现、关键关系、后续转换所需信息 | 生成表现仍需在实际工具中核验 |

## 4. 以关系组织知识

同一对象在不同关系中需要不同知识。头发可以是重量证据、风的可见载体、脸部遮挡、轮廓构成或高光形状；并非每次都需要“发丝飘动”。

建立七类关系：

1. **驱动与响应**：角色施力、风、重力、接触如何导致运动或形变。
2. **空间与可见性**：观察位置、景别、遮挡与对象布局决定哪些证据被看到。
3. **光与材料**：光源、表面/介质和观察方向共同决定明暗、高光与透明感。
4. **时间与注意力**：事件先后、停顿、运动密度如何支持或干扰重点。
5. **行为与意图**：动作目标、犹豫、恢复平衡与情绪之间的联系。
6. **风格与保留项**：哪些关系需要保留，哪些可改写为图形、持帧、夸张或省略。
7. **设计与实现**：决定表现的关系如何进入文字、关键帧、分层与后期。

这些是知识组织方式，不要求创作时逐项执行。

## 5. 避免机械调用的研究准则

一个细节值得采用，至少应能回答：它改变了观众可见的什么，为什么适合当前意图，以及删除它会损失什么。也可以因纯形式美感采用细节，但应明确形式目标，不编造叙事或物理理由。

多个有效方案可能分别依靠表演、空间、光影或时间。知识库不要求一律给三方案、不固定每次选三项，也不规定情绪必须对应某种颜色。

## 6. 后续修订方式

每项修订保留条目编号，记录触发案例、失败类型、修改理由和反向场景回测。若一个局部案例失败，先判断是条件缺失、艺术选择不合适、转换损失或实现失真，再决定是否更改知识。

覆盖地图用于发现遗漏；实际有效性需由作品与对照观察判断。两者不得混用。
