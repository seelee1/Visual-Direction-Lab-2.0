# 空间状态与特殊背景词库

用于把地点与物件组织成场景，也用于非叙事背景和特殊空间。结构、当前状态、观察条件和绘画形式分别选择。词条是可组合的语义入口，不是每幅画的检查清单，也不保证为模型标签。

## 布局、边界与观看关系

| 表达／英文入口 | 可见发展 | 组合用法 |
|---|---|---|
| 开敞、围合／open, enclosed | 空间边界与外部连接 | 可部分围合，非简单室内外二分 |
| 紧凑、宽阔／compact, spacious | 体量、间距与可活动范围 | 相对人物和用途支持，不只写形容词 |
| 密集、疏散／dense, sparse arrangement | 建筑、植物或陈设的群体分布 | 密度可分区，不全画面均匀堆积 |
| 聚集、分散／clustered, dispersed | 局部群体与空隙组织 | 与整体密度分别发展 |
| 中央、偏侧、边缘／central, off-center, peripheral | 场景元素相对画面或空间的位置 | 指明是物理布局还是取景关系 |
| 轴向、放射、自由布局／axial, radial, irregular layout | 主体、路线与重复元素的组织 | 不同区域可有不同规则 |
| 高差、坡度、台地／level change, slope, terrace | 地面位置与连接 | 路径、支撑、排水与观察一起成立 |
| 前后层、层间空隙／depth layers, gaps between layers | 物件和空间的距离组织 | 前中后景需要连接，不是三张背景贴片 |
| 嵌套空间／nested spaces | 房间、院落、门窗等逐层显露 | 每层的边界与可见范围明确 |
| 转角、折返、岔路／corner, turnback, branching route | 行进与视线分开 | 画外路线可存在，不必全部交代 |
| 连通、隔断、封闭／connected, partitioned, closed off | 地点之间的通行关系 | 门窗的视觉透通不自动等于可走通 |
| 入口、出口、过渡区／entrance, exit, transitional space | 内外或区域间的交接 | 活动方向与开合范围明确 |
| 动线与停留点／circulation route, stopping point | 活动路线和驻足区域 | 不能用陈设堵住指定行动却不解释 |
| 主视线、侧向显露／main sightline, lateral reveal | 观察通路与部分显露 | 运镜、走位、遮挡可以改变所见 |
| 框景／framed view | 门窗、枝叶或构件组织可见区域 | 形状与取景有具体作用，不自动加一圈边框 |
| 遮挡、透隙、显露／occlusion, gaps, reveal | 各层前后及可见范围 | 看不见的局部不必补满细节 |
| 近处参照、远处地标／near reference, distant landmark | 尺度与方向的锚点 | 人物、构件或地形皆可承担 |
| 视野展开、远景压缩／expansive view, compressed distance | 取景与距离观感 | 透视、层叠和画法具体支持 |
| 留空与负形／open space, negative shape | 未被物件占据的区域组织 | 空处可以有贡献，不默认补满 |
| 连续背景、局部切片／continuous setting, selected fragment | 环境呈现范围 | 一处窗角可足够，不必每镜重建全景 |

## 时间、天气与环境状态

| 表达／英文入口 | 可见发展 | 组合用法 |
|---|---|---|
| 清晨、正午、傍晚、深夜／morning, midday, evening, late night | 天色、光源、使用活动的组合 | 人工光与遮蔽可以改变局部，不统一整片色温 |
| 季相／seasonal appearance | 植被、地表、衣物和使用状态 | 按地区与具体时间发展，非四季固定色卡 |
| 雨前、雨中、雨后／before, during, after rain | 空气、地表、落水与残留的阶段差异 | 雨后不必继续满屏落雨 |
| 风中、避风处／wind-exposed, sheltered areas | 植被、衣物、尘水及局部响应 | 遮蔽与尺度导致不同区域不同运动 |
| 雾区、清晰区／foggy, clear zones | 空气与视距的分布 | 雾不只是模糊滤镜，也不均匀遮掉所有层 |
| 晴光、阴影、云影／sunlit, shaded, cloud-shadowed | 地面与构件的照明分区 | 稳定几何与变化遮光分别描述 |
| 室内外光差／interior/exterior light contrast | 开口、亮暗与适应范围 | 人物和背景共享合理或明确风格化的照明规则 |
| 潮湿、干燥／damp, dry | 局部材料、色差与反射状态 | 檐下、风面、低洼处可不同 |
| 积水、退水、水位变化／standing water, receding water, changing water level | 水边、露出表面和残留 | 当前状态与变化过程分开 |
| 积雪、融雪、结冰／snow buildup, thaw, freezing | 不同位置的覆盖与材料状态 | 向阳、遮蔽、接触和时间配合 |
| 空置、有人使用／vacant, in use | 开合、灯、物件与活动证据 | 无人镜头仍可有使用痕迹，不自动废弃 |
| 拥挤、稀疏活动／crowded, lightly occupied | 人物、活动空间与观看障碍 | 用户要求无人时不新增人群 |
| 繁忙后、刚整理／after activity, recently arranged | 陈设与当前活动的余留 | 不通过随机破坏表达所有过去事件 |

## 材料、使用与生活痕迹

| 表达／英文入口 | 可见发展 | 组合用法 |
|---|---|---|
| 新、旧、修复／new, aged, restored | 表面、接点与更新区域的差异 | 材料和维护状态共同决定，不只统一降饱和 |
| 磨损、抛光痕／wear, polished contact areas | 常用接触处的表面变化 | 位置与活动对应 |
| 褪色、风化／fading, weathering | 表面在不同暴露区域的变化 | 不是所有旧物都同一脏色 |
| 裂纹、剥落、缺损／cracks, peeling, missing portions | 材料与结构的局部变化 | 大结构和碎细节有层级 |
| 修补、替换、加建／patching, replacement, additions | 不同时期的材料与连接 | 新旧部分可以呼应或对照 |
| 水渍、锈迹、沉积／water marks, rust, deposits | 流路、接点和局部材料变化 | 不给木、石、金属都套同一锈层 |
| 尘、落叶、砂粒／dust, fallen leaves, grit | 表面覆盖与聚集 | 风、路径、边角、清理形成不均匀分布 |
| 踩踏、车辙、取用痕迹／footpaths, wheel tracks, handling traces | 活动与地表、物件关系 | 与通行路线、尺度和当前状态配合 |
| 整理、堆放、临时摆置／arranged, stacked, temporarily placed | 物件用途与秩序 | 不默认生活痕迹就是杂乱 |
| 个人化布置／personal arrangement | 喜好、习惯和生活用途的陈设选择 | 不把所有细节强加象征或故事 |
| 存量、缺口、余留／stored quantity, gaps, remnants | 使用前后留下的组织差异 | 通过少量证据发展，不把所有状态同时展示 |
| 声源与环境响应／sound source, environmental response | 可见声源、回应和空间关联 | 有声音任务再组织声画，不默认加音乐对白 |

## 特殊空间与非叙事背景

| 名称／英文入口 | 可见发展 | 组合关系 |
|---|---|---|
| 纯色背景／solid-color background | 色面、角色轮廓与留空 | 可无地平线与投影，不自动等于未完成 |
| 渐变背景／gradient background | 色彩方向、范围与主体关系 | 可为平面设计，不强制解释为真实光源 |
| 装饰图案／decorative pattern | 母题、尺度、密度与节奏 | 与主体主次和服装纹样配合 |
| 几何背景／geometric backdrop | 形块、线向、重复与空间错觉 | 纯平面或暗示深度均可 |
| 拼贴背景／collage background | 材料、边缘、层次与拼接 | 可有意不共享真实透视，但要有形式规则 |
| 图形、文字与版面／graphic, typographic layout | 画面空间与信息组织 | 文字内容与生成能力分别交接，不以乱码填版 |
| 舞台式空间／stage-like setting | 有限布景、边界与观看方向 | 可以明确保留人工搭建感 |
| 梦境、不可能空间／dreamlike, impossible space | 尺度、连接、重力或循环的有意改变 | 选择哪些规则改变，不把所有矛盾都归为梦境 |
| 悬浮岛、倒置空间／floating island, inverted space | 地形、建筑、支撑与重力的自主关系 | 视觉连接与行动规则仍可清楚 |
| 水下聚落／underwater settlement | 水体、围护、地形与生物或居民活动 | 干区湿区、材料和观察介质分别决定 |
| 巨型与微型环境／gigantic, miniature environment | 相对人物的尺度与接触 | 小世界不必只用景深模拟，尺度证据可具体 |
| 空间站、舱室／space station, habitat module | 功能、连通、材料与活动方式 | 不是普通房间加几块发光屏幕 |
| 机械城市／mechanical city | 建筑、设施、运动与维护系统 | 世界用途、连接和群体形状共同设计 |
| 生长式建筑／organic, grown architecture | 生物形态与空间用途整合 | 入口、支撑、材料分区和变化规则 |
| 晶体、光或流体环境／crystalline, luminous, fluid environment | 材料、体量、表面与变化 | 不只给普通场景加颗粒和辉光 |
| 虚空、无限平面／void, infinite plane | 空处、参照、尺度与边界缺失 | 非必须有天空地面，观看规则可自主设定 |
| 记忆片段式空间／fragmented memory setting | 局部物件、缺失区域与选择性显露 | 有意省略和随机不完整分开 |
| 纯形式环境／abstract formal setting | 光色、形态、节律与变化成为主体 | 不强行添加人物情节或自然解释 |

将空间布局与地形、植被、用途一起考虑，可深入[NPS 的文化景观组织资料](https://www.nps.gov/articles/cultural-landscapes-101.htm)；不将历史保护的分类框架当作所有创作的必填项目。画面形式与场景连续性分别调用[静态表现](../../能力/静态画面.md)、[分镜](../../任务/分镜.md)，总体取舍见[场景入口](../../能力/场景设计.md)。
