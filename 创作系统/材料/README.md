# 材料目录

统一运行入口是[入口](../入口.md)。本目录提供具体表达、局部方案与依据，不定义另一套创作流程。知道缺口后直达相应正文，解决后回到当前作品。

| 当前需要 | 材料 | 职责 |
|---|---|---|
| 把普通动作说具体 | [关系索引](关系/索引.md)、[表达方法](关系/表达方法.md) | 对象、成立条件、可见过程与表达 |
| 决定人物具体外观 | [人物设计](../能力/人物设计.md)内的外观词库链接 | 形态、服装、发型及状态素材 |
| 决定场所具体构成 | [场景设计](../能力/场景设计.md)内的场景词库链接 | 地点、环境、空间与陈设素材 |
| 现象缺少观察或过程方案 | [表现卡索引](表现/README.md) | 有条件的局部设计提案 |
| 连接、运动、光学或材料条件存疑 | [知识卡索引](知识/README.md) | 成立条件、反例与基础概念 |
| 核对研究或观察依据 | [来源登记](依据/来源登记.md)、[静帧观察](依据/观察/01-官方二维静帧观察.md) | 事实与设计推导分别记录 |

深入论述见[关系与设计原则](依据/关系与设计原则.md)，研究覆盖见[研究范围](依据/研究范围.md)。它们供有具体研究问题时查阅，不是额外启动入口。

表现卡中的组合建议服务于当前选定现象，不再次从头构思；知识卡中的建议不覆盖用户要求。来源支持的自然关系与生成模型的实际执行分开判断。实际效果证据在[案例与验证](../../项目记录/创作案例与验证/README.md)，不默认进入每次创作。
