# 视觉表现库 v0.2

## 在调用结构中的位置

本库属于材料层。上层[能力模块](../../入口.md)帮助选择整体表现，本库仅在某个已选现象缺少具体过程、观察方案或变体时读取对应卡。卡内“展现与发展”“组合与机会”提供局部提案，不要求重新执行整体创作；整合所需内容后返回当前作品。条件存疑再沿依据查知识卡，不重复阅读两套领域目录。

日期：2026-10-10 · 阶段 2 · 120 个表现条目，15 个模块。状态：有条件的设计草案，尚未经过独立模型或成片验证。原 E001–E048 加新 E049–E120；八条既有卡深化不重复计数。

## 使用与证据

基础知识说明为什么与何时；本库展开具体看见什么、怎样呈现、如何发展。每条包含可见过程、条件与观察、展现与发展、组合与机会、省略与反例、变体、依据与状态七组信息，对应定位修订中的九项建库要求。

所有镜头安排、时序、组合和艺术机会为项目推导 D；P/R/C 来源仅支持注明的基础概念。没有逐镜作品观察或实验结果的条目，不得标为已验证技法。来源编号见[来源登记](../依据/来源登记.md)；基础卡编号见[知识导读](../知识/README.md)。

## 调用入口

从用户意图找可见证据，也可以从场景中的界面、连接、遮挡、反射或时间差发现表达方向。跨模块选择以关系为依据；不规定每次使用几个条目。

例如雨中人物可选择 E034 的本体/倒影对比，E040 的雨层空间，E007 的未完成动作，或 E045/E047 的图形语言。它们是替代或组合机会，不是一个雨景套餐。T09 的 E-R 草案仍是历史诊断入口，不与 E001–E120 混号。

查不到合适条目时，允许提出新的有条件设计，标出参考需求；不得声称知识库已包含它。既有条目可以只用一部分，不能为了命中编号强加不相关过程。

## 表现程度与覆盖

对每次调用分别核对：现象具体性、过程展开、关系成立、镜头可见性与风格画法。远景的几笔雨幕与近景的挂滴过程承担不同目标，不按细节量排序。

| 维度 | 当前覆盖 | 仍需扩展 |
|---|---|---|
| 动态状态 | 保持、启动、停止、接触、恢复、传播、显露、消散、状态变化、重复、循环与时间压缩 | 真实复杂循环、长程演变和交互证据 |
| 观察尺度 | 微小界面、局部表演、全身、环境、二维图形 | 巨大地理尺度、天文尺度、显微现象 |
| 视觉关系 | 驱动/响应、遮挡、反射、透射、影、时间差、图底、多主体、跨镜色形与声画入口 | 更多知觉错觉、多主体实演与视听研究 |
| 风格 | 日式二维为重点，同时提供写实/绘画/图形化变体 | 定格材料的具体表现、非日漫作品证据 |
| 对象 | 人物、道具、头发与布料、玻璃、刚柔物、水、烟火、天气、植物、动物/机械入口、破裂与相变 | 具体物种/机构、皮肤组织、复杂材料与相变细过程 |

120 条说明当前建库规模，不说明穷尽表现手段。具体物种、材料、地理尺度与媒介仍缺专项深度；详细范围见[当前验证边界](../../../项目记录/当前状态.md)。全面性需继续通过未示范场景、禁用常见技巧、尺度/风格迁移以及实际观看检查。

## 修订与扩展

编号固定；修订记录触发案例、改变的条件与反向检查。新条目至少带一个不采用情形和一个条件变体。把有效组合写入案例，避免把每个组合拆成新的同义卡。

表现库负责提供机会，不强迫最终回答展示索引、专业依据或内部选择步骤。[跨域组合与创作跃迁](跨域组合与创作跃迁.md)补充六个整体探索草案，含纯形式与高密度方向；不是额外六张事实卡。机制见[当前核心指令](../../入口.md)。
