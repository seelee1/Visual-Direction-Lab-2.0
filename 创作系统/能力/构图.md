# 构图：设计画框中的关系

## 调用说明

- **层级**：共享能力，统一职责见[入口](../入口.md)。
- **何时读取**：单幅创作、关键画格或镜头布局；尤其是主体加背景、居中或三分位置之外缺乏具体组织时。
- **解决什么**：确定画框取舍、观看位置、大形分布与空间关系，让构图参与作品表达。
- **何时深入**：形体、光色和细节组织查[静态画面](静态画面.md)，镜头中构图如何变化查[运镜](运镜.md)。
- **何时停止**：主要形块、主体尺度、边界取舍和关键空间关系已经明确，能说明它们对当前作品的贡献。

## 先构成画面，再填充物件

画面需要同时呈现不同状态、对应形或多条行动时，结合[剪辑与时空组织](剪辑与时空组织.md)确定并置与对照关系，再安排区域、层次和观看联系。静态画面可以建立时间暗示或状态对照，不要求它执行动态变化。

面对创意，先确定画面中值得建立的关系：人物与巨大空间、两人之间的间隙、近处物体与远处目标、密集形群与孤立形、框内主体与画外行动。关系也可以纯粹来自线、色面与轮廓，不强制补剧情。

在描述服装纹理和环境小物之前，把画面想成少数主要形块：它们占在哪里、大小怎样相对、接近还是分离、朝向怎样交叉，画框截去了什么。这里的形块是设计草图，不要求固定数量，不必另交一份构图分析。

人物所在三分点、对角线、前中后景是定位工具，不能单独作为构图方案。最终要落实到具体对象与边界。例如“少女在右侧，背景有楼梯”仍很宽泛；“楼梯的暗色侧壁横压画面上半部，少女只出现在右下方的狭长亮口，扶手斜线在她视线前方中断”才形成可审查的形与空间关系。是否采用取决于作品，不把这种压迫安排变成默认。

## 改变构图时，改变结构变量

以下是可比较的方向，不是每次遍历的清单。先从当前作品最有潜力的变量发展，必要时比较不同结构；不要只换背景和颜色。

| 结构变量 | 可以怎样发展 | 要落实的画面证据 |
|---|---|---|
| 主体尺度与空间比例 | 人物近到局部越界，或小到由环境关系承载辨认；也可让道具成为最大形 | 哪个对象主导画幅，人物哪些部分仍需看清 |
| 画框的裁切 | 留下关键局部、切断延伸中的物件、让画外方向持续存在 | 哪条轮廓越过哪条边，裁切后事件和身份怎样读出 |
| 观看位置与朝向 | 从台面、坡下、门内、楼梯间等具体位置观看；正面平视也可形成有力结构 | 看到哪些面，哪些物体因此重叠、分离或遮住目标 |
| 深度组织 | 贴近的前景与远端人物形成尺度落差；平行层压缩；深处通道与平面色块交错 | 真实空间连接或有意的平面规则，不能只写“纵深强烈” |
| 负形 | 两人之间的缝、身体与道具围出的空处、建筑开口成为主要形 | 空处的边由什么组成，与主体动作或图形秩序怎样关联 |
| 方向与平衡 | 稳定中轴、偏置重量、相反斜向、曲线包围、横纵阻断 | 哪些大形共享方向，哪一处偏差打破或维持秩序 |
| 对比与分布 | 大面积低变化形中集中细节；多个同等重点；规则重复中出现差异 | 对比落在哪里，哪些区域保持完整，不把全图同时强化 |

不把对称、平视、居中视为普通，也不把歪斜、广角与巨大前景自动视为大胆。关键是选定结构是否建立了这幅作品独有的关系。清楚的平视构图可以靠间隔、裁切、重复和行为位置形成鲜明表达。

## 空间布置与构图一起设计

机位不是人物、道具、环境安排完之后附上的角度标签。允许为构图重新安排角色朝向、物件尺度、通道开口、明暗大形与画外延续，同时保留用户事实和关键动作条件。

例如需要看清手与工具的接点，先安排身体与桌面的夹角、手的位置和可见轮廓，再决定观察高度。若巨大前景挡住必要动作，应调整前景、角色或机位，而不是同时声称“强遮挡”和“所有细节清楚”。

静态插画可以主动改变透视、尺度或装饰层次。明确哪些关系按实体空间成立，哪些属于图形组织；不能用“艺术化”掩盖无意矛盾。

## 用结构差异打开同一题材

以下是创作提案，未经过生成验证。以“站台上等车的人”为例：

- **秩序中的偏差**：平视，柱列、座椅与顶棚形成规整横纵关系；人物位于其中一个空档，身体转向与其余线向不同。辨识来自重复间隔中的偏差，不依赖倾斜机位。
- **近远尺度落差**：视点靠近长椅一端，椅面从画框下缘伸向深处；人物在另一端，脚、座面和地面保持可读。近处椅面承担最大形，远处人物成为尺度参照。
- **画外期待**：人物靠近一侧，视线指向较大的空站台；轨道、棚沿或光带向画外延伸。空处有明确空间和等待对象的方向，不能只写“高级留白”。

这些方案可以平静、热闹或纯形式化，具体气氛由造型、光色与行为共同决定。用户要一版时自主选定，不把比较过程交给用户。

## 成稿与复核

### 镜头之间的构图也一起设计

视频中的末端构图可以为下一镜建立条件。设计连接时，将前镜离开的画面与后镜进入的画面并看：主体或关键形的位置、尺度、方向、负形和明暗面积，哪些要承接，哪些要改变。沿用一项清楚的联系即可发展其余差异，不必把两张图做成相同构图。

例如前镜移动到近处圆形开口占据画幅，后镜以相近位置的另一圆形结构起镜，再拉远显露不同场所；也可以只接住一条人物运动方向，让新场景在稳定的运动趋势中展开。匹配与有意不匹配均可形成连接，具体运动与空间规则见[运镜](运镜.md)。

关键画格不仅选单镜最漂亮的一刻，也应考虑进入、经过和离开的状态。不要为了末端转场而让整镜主体难以辨认；过渡完成后的构图应足以支撑下一段观看，而不是只为下一次转场作准备。

成稿至少让读者理解当前设计中有作用的主体尺度、画框位置、观看方向、主要形块和遮挡关系；并非每次填固定字段。画幅依据构图选择，用户指定时反过来适配。

复核时暂时忽略装饰与材质：主要关系是否仍然清楚？换成普通平视中景后会失去什么？如果没有明确差别，检查当前角度是否只剩标签；若平视本来最适合，就强化它真正承担的形与间隔关系，不为求新硬换机位。
