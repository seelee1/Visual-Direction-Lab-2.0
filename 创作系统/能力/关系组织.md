# 跨域关系与艺术发展 v0.5

## 调用说明

- **层级**：能力模块。共同职责与调用规则统一见[入口](../入口.md)。
- **何时读取**：细节各自丰富，但组合松散或争抢重点。
- **解决什么**：确定共同驱动、对比、呼应或信息关系，组织整体。
- **何时深入**：局部现象说不清时查[表现卡](../材料/表现/README.md)，不另起整套创作。
- **何时停止**：各部分的联系与取舍已明确。

用途：把被唤起的知识发展为整体设计。以下是可尝试的组织方式，不是必用公式。关系的价值可以是表演、清晰、空间感、形态美、节奏、歧义或奇观，不必一律解释为心理象征。例子是可继续发展的创作种子。

| ID | 关系入口 | 怎样打开新的表现方向 |
|---|---|---|
| R-A01 | 一个驱动，相关响应 | 同一接触、阵风或照明影响多个对象。按位置、连接与材料发展同步、差异或局部保持；这些都是选择，不规定所有层必须错峰，也不只凭材料名决定快慢。 |
| R-A02 | 接点改变，画面重组 | 承重、松手、开门、离地或牵引解除，同时改变姿态、负形、影形或观看关系。挑选真正关联的层，不额外配无关闪光。 |
| R-A03 | 主体结束，后果继续 | 动作停住后，由环境响应、残留、痕迹或仍在变化的材料接管观看。也可反过来让环境结束而主体行动继续。 |
| R-A04 | 保持与变化相互衬托 | 一层稳定，让另一层的变化更可见：本体与倒影、人物与云影、持帧与背景。稳定可以有价值，不强行给每层添加运动。 |
| R-A05 | 动作改变可见性 | 转向、越过边界或遮挡开合改变轮廓、受光区和目标。先建立人物、光源与遮挡物的位置，再选共同显露或分段显露；动作可简单，观看关系可以充分发展。关键接点需清楚时保留观察余量。 |
| R-A06 | 改变证据，不改事件 | 同一事件可以由实体、影、倒影、局部接触或环境反应表现。间接证据需有成立条件，不能替代用户要求看清的动作。 |
| R-A07 | 空间用途发生变化 | 留白先是运动余地，后是视线目标或无回应的空处；物体离开使原构图改变。空间关系不自动对应某种固定情绪。 |
| R-A08 | 峰值会合或有意分离 | 动作、光、形、颜色和镜头的重心可以共同形成高潮，也可以错峰展开。密集场景可以允许短暂失读，再选择锚点恢复理解。 |
| R-A09 | 轮廓与节奏形成呼应 | 布弧、水线、建筑边缘或色块在形式上联系。呼应可连接不同对象或镜头，但形似不构成物理因果，也不必讲成命运象征。 |
| R-A10 | 材料记录时间 | 压痕、湿迹、破损、沉积或状态变化让事件的后果留下。依据材料区分恢复与不可逆；时间压缩需与真实时间区分。 |
| R-A11 | 信息顺序重写体验 | 先看结果再知原因，先看局部再知空间，重复中一次变化被突出。单镜头可通过观察与显露实现，不暗中依赖剪辑。 |
| R-A12 | 任务与反应不同步 | 角色继续一件事而另一层回应环境或他人。可以表达克制，也可以只是动作分工；不默认眼、头、躯干永远依次启动。 |
| R-A13 | 形式规则承担非现实变化 | 线、色面、影形或背景可以按明确图形规则变化，与实体物理区别。保留身份、方向、接点或事件锚点，让观众知道作品怎样成立。 |
| R-A14 | 尺度改变，关系保留 | 从近景到全景，或跨镜、跨媒介时保留重要关系，改变表达证据。微观机制不可辨时重新翻译，不把细节原封不动带到远景。 |
| R-A15 | 对照材料或行动策略 | 同一外力下两种材料、同一目标下两种行动形成差异。可以只保留最有辨认价值的对照，不把每个对象都独立演完全过程。 |
| R-A16 | 环境具有自己的主体性 | 风、光、水或植物不只是配合人物，它们可独立决定画面节奏。人物可以成为参照、局部扰动甚至缺席，而非永远是所有层的中心。 |

## 从组合到艺术判断

先找到实际改变观看体验的关系，再选择表现程度。判断“组合”时问：这些层为什么在同一作品中？共同驱动、观察目标、时间对比、图形联系或有意冲突是什么？如果没有关系，仍可保留独立背景，但不要声称它们已经协同。

创作不是所有领域开会。可以从一个关键姿态、一处材料变化、一组色面或一次遮挡开始，让相关层加入；也可以先构想总体节奏，再决定各层职责。允许往返，不固定执行顺序。

## 让能力共同修改同一设计

能力分工用于找到需要的知识，作品中的选择则相互作用。先抓住已经有价值的对象、形态、关系或体验，再发展它需要的条件和它带来的机会。这个起点可以来自任何能力，也可以有多个并存的重点，不要求先写主题句或逐项填写协同表。

例如角色的宽袖既是身份与造型选择，也会改变手部可见性、接触方式、轮廓和负形；场景里桌面的高度又会改变袖口与桌面的关系。此时人物、场景、材料、动作、构图和风格应共同决定最终姿态，而不是服装写完后才要求镜头想办法看清。若手部操作是用户重点，可以调整袖形、姿态、桌面或观察方向；若衣物形态才是重点，则允许接点退居次要。没有一种能力永远优先。

创意展开与艺术变体也应改变这些关系，而非只在原方案上叠加效果。艺术语言和二维转译可以从一开始影响形状、空间和过程；知识与物理检查负责判断实际条件，不能把有意的艺术规则自动改回写实。任务模块组织整幅、整段或系列，交付适配继续保留已选关系。适配中发现真实限制时返回受影响的设计决定，明确必要取舍，不暗中换成另一作品。

协同时关注三件事：某项选择给其他部分提供了什么条件或机会；各部分是否争抢空间、时间或相互否定；改变它后哪些部分需要跟着调整。已成立的局部不反复重做，未发现新问题就停止扩展。无需为证明协同而读取所有模块，也无需让每个细节承担多重意义；独立纹理、空间气氛和纯形式趣味可以保留。

静态作品也可这样设计：例如服饰的大色面与建筑开口共同形成形块节律，材料处理控制局部密度，人物姿态使轮廓在开口处清楚分离。各部分共同塑造观看，而非分别添加“服装精美、背景丰富、构图高级”。这些是方法示例，尚不代表生成效果已验证。

### 协同也产生新的构思

协同从构思开始，不只用于完成后的检查。材料的透明性可以启发重叠观看，重复开口可以启发人物相遇，粗糙线条可以启发断续动作，声音间隔也可以启发空间显露。任何能力的发现都能反过来改变原先的对象、场景、媒介或组织方式；在用户保留范围内选择值得发展的机会，不固定先有情节再配形式，也不要求每个发现继续扩展。

遇到取舍时沿用[入口的冲突判断](../入口.md#原则冲突时的取舍)。比较具体得失：增加遮挡可能加强空间层次，也可能遮住必要接触；延长材质变化可能增强触感，也可能挤掉后续辨认。按当前作品选择，而非机械要求各能力贡献相同。感官价值和有意歧义本身可以支撑选择，不能将删减一律当作优化。

## 让艺术规则在作品中可见

有意偏离现实可以涉及形体、光影、尺度、空间、时间、材料或声音。先区分它是作品世界中真实发生的奇幻事件、角色感受的主观呈现，还是独立的图形表达；允许有意保持歧义，但不能一边要求观众确定它只是想象，一边只给出实体异动的证据。

根据当前表达落实必要条件：变化发生在哪个对象或画面区域，怎样被触发或从一开始持续，按什么可见方式发展，哪些身份或关系保持，以及它最终继续、消退还是转入另一规则。动态作品需要时设计进入与退出；静态作品用轮廓、色面、空间并置或材料差异表达关系，不强加动态阶段。始终处于同一非现实语言的作品也不必增加写实开场和恢复段。

例如要把猫影变形读作女孩的恐惧，可以在她凝视时让墙面细节一同退成平涂色域，猫影沿同一纸片般的轮廓拉长，真实小猫仍保持原来比例；哈欠出现时，墙面细节与正常影形一起恢复。这里主观感受通过画面语言的共同变化获得依据，而不只写“这不是怪物”。这是一种可选提案，不能保证观众一定作同样理解，也不应固化为所有主观段的模板。

检查艺术规则时保留有意的不可能，修正无意的互相否定。例如某一段允许影子脱离实体动作，就不能同时要求该段投影逐帧严格遵守光路。用范围与转换条件划清边界，不靠更多否定词掩盖冲突。各相关能力沿用同一规则，避免构图采用平面变形、动作却要求真实空间连续而未说明转换。

## 避免新模板

不要将“静止主体＋运动环境”“动作后残留”“高密度同方向”变成新的默认套餐。顺畅协调、持续发展、直接完成或未完成处也可有充分表现，不必先制造阻碍。改变观看重点、条件、时序或形式，检验关系是否有贡献；不合适就换。常见技法若最合适仍可使用，新奇不是唯一价值。

删除一个细节后若观看重点没变，它可能是装饰而非核心；装饰也可以有形式价值，应按作品判断。反过来，不能因某层不承担故事信息就删除其色彩、纹理或空间贡献。

## 一个创意的不同发展方向

“雨中站立”可以以人物和倒影的不同状态为中心，可以以雨层与遮挡形成空间，可以以一次局部界面事件形成时间，也可以主要发展线色和图形密度。不要把四种方向自动全部叠加，也不要固定每次给这四种答案。使用自身知识继续发现其他机会，并选择适合当前要求的组织。
