# 注意与观看组织

## 调用说明

- **层级**：共享能力，共同职责与调用规则见[入口](../入口.md)。
- **何时读取**：需要让重要关系被发现、持续观看、在多处往返、主动寻找、延迟理解，或处理声画与文字之间的注意竞争。静态、多镜头、单镜头、漫画及纯形式作品均可使用。
- **解决什么**：选择希望观众注意和理解的内容，安排可见、可听或可读的线索，以及停留、转移、返回和自由探索的条件。
- **何时深入**：空间布局查[构图](构图.md)，边缘与光色查[静态画面](静态画面.md)，观察路径查[运镜](运镜.md)，呈现顺序查[剪辑与时空组织](剪辑与时空组织.md)；研究边界见下方依据。
- **何时停止**：当前作品需要的观看关系已落实到对象、位置、状态和必要时序；重要信息有被发现与理解的机会。无需预测每次眼动或给所有细节排优先级。

这里组织观看机会，不把所有作品变成单一焦点、快速抓眼或固定视线路线。多中心、漫游、迟迟未被发现、长久保持和有意失读均可成立。以下创作方法与例子是项目设计建议 D，不是眼动实验已经验证的通用配方。

## 分清想让观看发生什么

根据当前任务区分几个问题：对象是否进入可见范围，是否被注意，能否辨认，是否理解关系，以及后来是否记得。它们可能同时发生，也可能分离，不是每份作品都要填写的五级流程。注视一个物件不证明理解它的用途；记住鲜艳配角不等于理解主角的决定；观看位置相近也不代表观众作出相同推断。

从作品目的选择需要保护的信息。教学操作可能需要看清接点，悬疑可以让动作可见而动机未知，抒情或纯形式作品可以只要求感受间隔、纹理和色面变化。感兴趣、感动或觉得美，不能由注视时长或视线集中程度直接代替。观看也可以没有待解谜题。

### 研究依据与适用范围

来源编号、访问日期和实际读取范围见[来源登记](../材料/依据/来源登记.md#注意与观看组织补充来源)。以下是有限条件下的研究结论；后续方法是据此及既有艺术知识提出的设计选择。

| 依据 | 可以据此考虑什么 | 不可直接推出什么 |
|---|---|---|
| S09 注意引导综述；S54 静态与动态场景任务实验 | 图像差异、观看任务、场景知识和经验共同参与注意；同一动态场景在不同任务下可以有不同观看分布 | 只要亮、动或居中就必然先被看见；给任何作品写一句目标就能控制视线 |
| S55 场景意义图与眼动研究 | 在所测照片与模型比较中，语义信息对注视分布有解释力；对象对当前观看意味着什么值得设计 | 语义永远压过颜色、所有抽象艺术都要补剧情，或该相关结果证明唯一因果机制 |
| S56 对话场景声画实验 | 原对话声音可加强对说话轮替的跟随；所测无关声轨类型间未发现同样的差异 | 任意突响都能把人从错误处引开；静音版也会获得相同效果 |
| S57 影片上下文与理解实验 | 同一片段的理解可以明显不同，而眼动仍较相似 | 看向同处等于理解一致，或前情与叙事无需设计 |
| S58 杯球魔术中的社会与物理线索实验 | 在该编排中视线、脸部与物体事件能影响注意和误导；重复观看会改变结果 | 魔术实验等于电影、插画或 AI 遮瑕验证；照抄侧瞥就能稳定误导 |
| S59 动态事件中的非注意盲视实验 | 执行选择性观看任务时可能漏掉意外事件，不能只凭“它很明显”判断会被注意 | 观众必然看不见次要区域，或可以用固定漏看比例预测新作品 |
| S60 变化盲视与保留表征实验 | 未报告变化不必然意味着没有记住原对象，也可能没有比较前后信息 | 观众没有视觉记忆、连续性错误无所谓，或所有遗漏只有同一种机制 |

非注意盲视关注意外对象或事件没有被觉察，变化盲视关注前后差异没有被发现；二者不能互换名称，也不等于对象被物理遮住、画得太小或视力不足。创作中的“没看懂”还可能来自上下文缺失，先定位现象，再判断这些研究是否相关。

## 从观看目的选择组织方式

这些方式可以结合或改写；先发展当前有价值的关系，不遍历表格，也不强制都经历吸引、保持、转移和回收。

| 希望形成的观看 | 可以怎样组织 | 需要落实的内容 |
|---|---|---|
| 迅速发现 | 稳定区域中出现一处变化，或让形、色、尺度和语义共同指向目标 | 被发现的具体对象及周边关系；避免只有光效醒目而对象仍难辨 |
| 持续关注 | 保留可跟随的过程、逐渐发展的质感、关系悬而未决，或允许安静凝视 | 什么值得继续看，哪些变化可辨；不为维持注意机械加事件 |
| 从一处交给另一处 | 递物、视线、声音、路径、遮挡打开或镜头运动形成联系 | 原对象状态、转移线索、接收对象，以及转移后需要理解什么 |
| 返回并重新比较 | 先建立对象，再离开，返回时保留参照而出现有意义的差异 | 比较所需的旧状态怎样建立，新状态哪里改变；不只重复同一特写 |
| 多点往返 | 多个人物、区域或图形保留各自身份，通过回应或形色关系相互牵引 | 各点的联系、变化和重新定位依据；不必轮流平均分配时间 |
| 主动寻找 | 提供可辨的目标特征、环境线索或局部异常，让发现本身有趣 | 观众在找什么或察觉何种缺口，哪里有有效线索；寻找不必靠对白说明 |
| 期待与延迟 | 先建立来向、结果可能或重复模式，保留尚未发生的空间与时间 | 期待由什么建立，等待期间有什么可看；可以兑现、改变或一直悬置 |
| 暂时误认与重新理解 | 同一形或行为先支持一种解释，随后出现第二种解释所需的证据 | 原先为何合理，后来多了什么；区分认错对象与对象真的变形 |
| 第二眼发现 | 同框保存主关系与可回访的细部，或让重看时旧线索获得新意义 | 初看不发现是否仍成立，细节是否真实存在且足以复查 |
| 分布式体验 | 通过重复、纹理、色域、群体变化与局部差异支持漫游 | 整体如何成立、局部如何有差别；允许没有唯一终点或共同路线 |

## 让线索与作品内容一起成立

| 可调用的线索 | 具体选择 | 需要协调的关系 |
|---|---|---|
| 尺度、位置、方向与负形 | 门洞中的小人物、两只手之间的空隙、重复柱列里不同的朝向 | 大并不必然重要，线的延伸也不等于视线必沿线走；让方向实际连到有价值的对象或空处 |
| 明暗、色彩、边缘与密度 | 局部色差、轮廓分离、清晰与融入、密集中的疏处 | 不默认压暗全背景或让眼睛发光；多处同时增强可能改变原有主次 |
| 运动、起止与相对变化 | 大范围运动中的保持、先后响应、速度差、局部形变 | 区分对象运动、相机运动和背景流动；大幅动作不能无意夺走必要的细微表演 |
| 遮挡、开口与画外 | 人群间隙显出道具、窗帘移开、角色看向未出现的方向 | 线索可辨与信息隐藏分别设计；要看清的动作不能只剩遮挡物 |
| 脸、视线、手与共同对象 | 说话者和倾听者的反应、递物、停在物件旁的手 | 不把所有人都转向镜头；视线目标、身体朝向及空间需相容 |
| 语义、经验与上下文 | 建立某物的用途、缺失、风险、承诺或形式重复后再呈现它 | 用户未给动机时作明确创作选择；不能假定所有观众都熟悉某符号 |
| 声音与静默 | 声源接近、对话轮替、画外提示、持续声的中断、音乐与动作的呼应 | 哪个声音属于场景、哪个属于配乐；声画同向还是有意分离，静音时哪些信息仍成立 |
| 文字与图形标记 | 标题、对话气泡、字幕、箭头、标注及页面阅读方向 | 读取文字与看动作各需要什么条件；不为普通插画默认加字或指示箭头 |

线索可以汇合，也可以彼此冲突形成张力。例如声音从画外传来，人物仍望着桌面；这可以让观众在声源与表情之间选择，不必马上切到声源。根据作品决定哪些关系需要清楚，哪些允许竞争，而非把所有通道同时指向一点。

也可以先组织哪些元素被当作一组：接近、相似、共同方向、连续轮廓、同一边界或共同变化，都可成为设计依据。群体先作为整体被辨认，再让内部差异出现；文字与它说明的对象可以用位置或连接关系相联。分组应符合本作需要，不把相似自动等同于同类、同时运动自动等同于共同原因，也不只靠突出孤立对象引导观看。

## 持续关注与安静观看

持续关注可以来自过程的累积、材料变化、动作将成未成、关系的微调或观看本身的触感。长镜头可让观察对象稳定，而它与周围的距离、遮挡或响应逐渐改变；静态图可让大形成立后，局部线、色和痕迹继续提供探索。保持并不要求人物一直动，也不必安排谜底或高潮。

如果需要让微小变化被看见，先建立能比较的状态，再决定变化的尺度、位置和观察距离；背景可继续活动，只需避免它无意覆盖本次要读的差异。需要密集或压倒性感受时，多个变化也可以同时发生，不预设越克制越好。

不要把“每几秒必须刺激一次”“静止必然无聊”当作规则。持续注意不是单靠技法数量控制；完整观看能否成立，还涉及题材兴趣、熟悉程度、呈现条件与作品目的。相关心理效应需要实验时再专项核验，不把经验写成统一阈值。

## 转移、追踪与返回

需要转移时，把当前关注对象、引出下一对象的线索、目的地的辨认依据共同设计。例如手递出一枚钥匙，接收者接住后转向门，机位随门的开启显出内部；每一步的动作和空间承接让关注变化有内容。也可直接跳转、突切或故意打断；作品要求突兀时不强求平顺。

跨镜、离画或遮挡后再出现，要根据需要留下重新识别的依据：身份、位置关系、运动趋势、持物状态、轮廓或声音。屏幕位置可以延续，也可以改变；不要把“观众容易找到”改成所有镜头都锁在同一坐标。追踪多个对象时，身份差异和相遇后的去向应足够表达本次关系，不规定通用可追踪数量。

返回不只是镜头转回来。若观众要比较前后，先前状态需要有被认识的机会，后来的差异也需能定位；如果只要感受“已经不同”，可以保留整体色域、群体密度或空间用途的变化，而无需逐件清点。原对象在注意离开期间仍按[环境与事件状态](场景设计.md#环境状态如何延续)继续存在。

## 多中心、主动寻找与第二眼

多中心作品可以是同时比较，也可以让不同观众自由探索。为同时比较安排可关联的姿态、尺度、位置或重复形，为往返观看保留重新定位的线索；不要把所有局部都做成同强度的闪动来代表丰富。若多个独立细节都必须精确理解，考虑错开、持续保留、再呈现或改变取景，具体取舍依据任务，不自动删减。

主动寻找需要有寻找的依据。可以先给局部特征再让它进入群体，先呈现缺席的位置，或让规律中的异常引出探索；也可以从没有明确目标的游览中渐渐发现规律。纯粹把对象缩小、藏暗而不给辨认条件，只增加困难，不必然产生趣味。目标特征还需与干扰项有可利用的区别；隐藏到什么程度由作品选择。

第二眼细节可以补充人物关系、空间历史、形式呼应或幽默，不必全部成为伏笔。决定哪些信息属于首次理解所必需，哪些只是重看奖励；如果关键因果只在短暂角落出现，不能默认所有人都已发现。复杂构图可以保留初看不尽的层次，不强迫一遍看完等于好作品。

## 期待、误导与重新理解

先区分空间上的转移、解释上的误导，以及真正发生的物理或图形变化。角色望向门外可以引导注意方向；观众把树影误认成人影属于解释；树影真的变成人则是作品规则的改变。分别写清画面证据，不用一个“反转”概括三者。

悬念可以来自观众比人物先知道，也可以来自共同发现或人物知道而观众未知。决定保留哪种信息差，以及声画如何维持它；不默认任何反应都必须立刻给出对象镜头。误导需要在前后证据之间成立：揭示可以补出全貌、改变观察角度、呈现此前未见的关系，而不能靠临时替换既定事实伪造解释。

误导不是每次都要纠正；歧义、梦境和可逆图底也可持续存在。需要回看成立时，保留前面确实存在的线索，而非揭示后再宣称观众本该知道。首次观看与带答案重看是不同条件，创作者已经知道结果时容易高估线索清晰度；这属于需要观看检查的问题，不能用自己多看几遍代替陌生观众的第一次理解。

## 声音、文字与画面怎样分配观看

声音可以预告画外对象、把注意交给说话者、延续已经离画的事件，或让画面与声音形成两条不同的信息。用声源、出现先后、远近或持续变化来表达，不只写“音效吸引注意”。音乐可以参与节奏或情绪，但不能假定一个重拍会让所有人看向同一位置。静默也只有在先前声音关系中才有具体意义，不必每次突然抽掉全部声音。

对白与反应可以分开组织：说话者继续说，画面停留在听者手上的动作；是否成立取决于需要理解的内容和声源是否明确。两人轮流说话不必逐句切镜。关键台词、字幕、口型与同时发生的细微动作需要一起检查，避免要求观众在同一瞬间读完长句并看清多个局部。可通过位置关联、持续保留、前后安排或复现结果协调，不按统一字数或秒数裁剪。

文字语言、阅读方向和文化符号的熟悉程度来自实际受众或用户要求，不能当作普遍相同。交付本来包含静音版、小屏、裁切版或不同语言时，复查关键关系是否仍能被辨认；必要时采用形、位置、动作等补充线索，不能只依赖声音或一种颜色。没有这些交付要求时，不强制生成全套变体。

## 同一观看目的在不同媒介中怎样成立

| 媒介或任务 | 适合明确的关系 | 容易误用的方式 |
|---|---|---|
| 单幅插画、摄影、绘画、纯图形 | 同时存在的大形与局部、入口和回访机会、自由探索或整体场 | 声称所有观众必然先左后右，或要求静态图实际播放先后变化 |
| 漫画、条漫、图文页面 | 格间顺序、气泡与人物的对应、跨格呼应、翻页或滚动后的信息 | 默认所有页面左到右；重要揭示已经在同一屏里显眼出现，却仍按未见设计 |
| 单镜头、动画与循环 | 调度、局部运动、声画交接、状态持续、循环中的偏差与再次辨认 | 为每次注意转移增加切镜，或循环重置抹掉应当留下的结果 |
| 多镜头、剪辑与转场 | 离开前建立什么、进入后接住什么、重新定位及信息增量 | 只匹配颜色或运动而丢失行动关系，或把平滑切换等同于理解成立 |
| 广告、说明、信息图与操作演示 | 用户需要读到的主体、文字、数据或动作，与艺术表现如何共存 | 让装饰抢走指定信息，或以审美理由省略必须看清的操作 |

## 可继续发展的设计例子

以下都是 D 创作提案，没有新增观众实验、眼动记录或生成验证；用来展示组织差异，不是默认题材。

- **安静保持**：固定视点下，缝补者持续对齐两片布边；手的位置基本稳定，接缝逐步闭合，旁边未缝部分的间隙仍清楚。过程本身提供继续观察的内容，不需要突然声响或回头。
- **群像往返**：餐桌两端的人各自维持话题，中间一只空盘被不同的人顺手递过；共享物的路线建立联系，各处的表情与动作仍可独立发现。若需要明确谁拿走最后一块食物，再为该事件安排辨认机会，不把整桌变成均匀轮流表演。
- **主动寻找**：先让观众认识一枚缺角的叶形徽记，再在集市旗帜、衣饰与摊位图案中保留相近形；目标的缺角与颜色组合能被核对。是否必须找到、多久揭示由作品决定，不把搜索实验阈值当成镜头时长。
- **返回比较**：镜头离开窗边未动的杯子，跟随人物取书；回来时窗影已越过杯沿，杯的位置仍旧。差异来自照明与时间，不能为了增强变化暗中挪杯。
- **重新理解**：墙上两个人影似乎相互靠近，机位移过门框后显出一个人和挂着外套的衣架；前后投影与遮挡需支持误认。如果选择超现实变化，则另写实体如何改变，不冒充同一个空间揭示。
- **纯形式漫游**：纸面上的线群密度逐渐重排，多个空隙在不同位置短暂组成相似的弧；观看可以跟随其中一处，也可以停留在整体疏密，不指定唯一目标，也不补人物故事来证明其价值。

## 交付与观看检查

提示词表达具体对象、位置、动作、声源和先后关系；“引导注意”“维持兴趣”“让观众忽略瑕疵”不能替代这些内容。单镜号内可安排注意交接和阶段时间，真实切镜再新增镜号；按对应模型适配，不新增模型字段或通用时长限制。声音、图形或参考的能力不确定时按[官方核验规则](../交付/README.md#从用户意图判断能力)处理。

转换时共同保留目标、有效线索、可见条件及必要的前后状态。静态作品保留并置关系，动态作品保留时序；不要把“猫叫后人物望向门边”压成“温馨氛围”，或把“先建立缺角徽记再进入群像”缩成“复杂集市”。简单作品直接成稿，无需附一份注意力报告。

诊断时根据实际问题区分：没有注意到、注意到但辨认不清、辨认出却缺上下文、理解后未记住，以及只是个人偏好不同。可比较线索位置、清晰度、时长、声音或前情，但不要一次改掉所有因素后把改善归功于某一技法。热图或显著性模型只能提供线索，不能代替理解与审美评价；没有真实眼动数据不伪造观看轨迹。

需要验证时先以实际交付条件正常完整观看，再局部回看。首次观看尽量不提前点明要找的细节，先取得自由描述，再核对必要信息；预告了目标的搜索测试另行标明。小窗、全屏、有声、静音、初看和重看的结果不能混为同一条件；单人反馈可用于诊断，不冒充普遍效果。实际执行才按[案例记录方法](../../项目记录/创作案例与验证/README.md#实际调用验证的记录方法)保存输入、完整结果、条件和反馈。

注意转移用于处理生成风险时，另见[制作阶段的安排](剪辑与时空组织.md#在生成前安排注意转移)。它不能替代必须被看清的关键动作，也不保证遮住错误；可以探索其作用，但研究中的漏看现象不等于本项目已经验证了遮瑕策略。
