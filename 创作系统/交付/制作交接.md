# 艺术设计到提示词与制作交接规范

用于复杂作品的母版、提示词与制作交接。与[最小输出约定](信息保留.md)配合；简单任务仍直接成稿，不要求向用户展示两阶段报告。

当前特定输出采用[Anima / MiniMax-H3 适配](README.md)，完成艺术设计后再按其标签、字段和资产角色转换。格式规则不改变本规范的信息保留责任；具体工作流仍需实际核验。

## 转换对象与交付形式

艺术母版是选定作品的可见设计，不是隐藏思考、知识命中列表或待选技法集合。简单任务可以在创作中形成短母版并直接成稿；复杂设计、压缩比较或制作协作时，保存母版便于交接和修订。

同一作品的设定、单元、修订与交付版本按[作品组织](../任务/作品延续.md)维护；本规范只负责把当前选定设计转成需要的内容，不接管作品创意，也不要求先选择制作环境。

| 目标交付 | 需要承载什么 | 可省略什么 |
|---|---|---|
| 连续视频提示词 | 可独立理解的主体、布局、事件、关键变化、关系、时间和形式 | 探索过程、章节分析、反复修饰 |
| 静态画面 | 同一时刻的空间、受光、材料、构图与观看重点 | 动作时间线和未发生的后续事件 |
| 分镜 | 各镜的观看职责、画面状态、衔接与时长关系 | 全片重复说明；不能暗中增镜解决单镜头约束 |
| 漫画页面与分格 | 载体、阅读方向、页格布局、关键状态、文字及格间关系 | 视频秒数和镜头字段不自动适用；按漫画资源组织 |
| 长篇或系列 | 全局必要设定、段落职责、连续状态与整片或幅间关系 | 不为每段重复全库；当前生成片段仍需可独立理解 |
| 专门用途 | 产品、文字、数据或建筑关系等必须保留项，以及用途对应的阅读与展示 | 艺术描述不能替代准确事实、标注或后期职责 |
| 关键帧说明 | 可辨的起始、关键和结束状态以及帧间联系 | 与状态无关的研究解释；关键帧不是完整运动保证 |
| 分层或制作交接 | 对象职责、遮挡顺序、控制依赖、合成关系及损失 | 未核验的节点名称、工具能力和自动保证 |
| 具体模型适配版 | 经核验环境能接受的文本与控制材料 | 超出该环境的无依据承诺；母版另存 |

## 母版的最小信息

根据作品保留以下内容，允许自然段、分镜或简短表格；不是固定字段配额，也不要求普通用户填写。

- 用户明确要求及所选的合理创作条件。
- 观看重点与画面布局：重要对象、目标与空间关系在哪里可见。
- 关键状态或持续关系：开始怎样，哪些变化重要，结束或持续状态怎样。
- 决定表现的联系：参与对象、驱动或图形规则、可见结果以及必要条件。
- 风格与节奏：哪些线、色、影形、姿态或时间组织决定作品身份。
- 仅在实际制作时记录环境、控制分工、版本及允许的损失。

母版没有必要列遍专业领域。对安静或纯形式作品，保持、间隔与图底关系同样可以承担核心表现。

连续作品的段落、镜头、漫画格、关键画格、生成片段和最终剪辑段分别对应，不机械一一换算。具体组织见[长篇与系列](../任务/系列.md)、[漫画](../任务/漫画.md)与[用途约定](../任务/专门用途.md)。跨场景的身份、空间、持物、环境状态及已揭示信息需要延续；文字、数据、图纸与真实产品条件分别保存，不能在压缩时改成模糊效果词。

分段交接时从对应事件时刻提取[环境状态](../能力/场景设计.md#环境状态如何延续)：必要空间关系、片段开始状态、片段内变化及接续所需的结束状态。后段独立使用时展开这些必要信息，不只写“同上一段”；参考图若早于物件移动、破损或光源变化，应说明哪些内容已过时。文本、参考与关键状态冲突时先核对当前选定设计，不默认最新生成画面正确。保留状态只是交付依据，不保证生成工具自动实现连续性。

## 参考图也可以描述状态

参考不限于角色身份和场景风格。一张图也能提供人物与道具的位置、动作阶段、接触关系、朝向、受光及环境状态。按当前需要明确该图保留什么、允许改变什么；不要把同一组素材全部视为同一种约束。

普通参考图提供内容或状态依据；首帧、尾帧和带时间位置的中间关键帧属于具体环境的控制输入。只有实际核验对应接口后才按其能力交接，不用“把这张当首帧”的文字冒充严格首帧输入，也不把同名模型在某工作流中的能力推广到其他 API。

实际交接时，按需保存图的来源、原视频时间、编辑内容、目标用途及目标时间；来源时间与新视频的目标时间分开。雨势、表面湿态、灯是否打开等连续状态，应在画面和文字中相互支持，不只写“保持一致”。

两种可探索的方法需明确效果未验证：一是抽取错误状态、编辑图片后重新生成整段，允许前后画面变化，以整段可用性为目标，不误解为原视频其余部分必须精确保留；二是用少量抽帧或专门制作的状态图描述动态。后者需保留顺序和时间关系，不能把非均匀选帧默认排成等间隔，也不能把几张图片等同于唯一运动路径或真实光流输入。

这些方法用于用户需要的尝试，不自动发起实验或生成任务。保留原始素材和编辑版本，最终检查整个动作及剪辑用途，而不只看模型是否出现目标图片。

### 注意转移的声画交接

需要用场景事件组织观看时，保留“原本看什么—哪个事件出现—关注怎样转移—原动作留下什么结果”的关系。按[注意转移](../能力/剪辑与时空组织.md#在生成前安排注意转移)写成具体声画内容；声音注明由生成还是后期承担，不因视频接口不支持音频就丢失这项设计。时间先后可以先按动作阶段描述，实际素材确定后再落实切点，不编造精确同步能力。

## 保留优先级

| 信息层 | 转换处理 |
|---|---|
| 用户约束 | 原样保留其意义；冲突先明确处理，不能以压缩为由改变 |
| 核心事件与关系 | 表达成画面句，保留对象、变化与联系，不只留术语 |
| 核心成立条件 | 保护必要的接触、连接、方向、观察位置、遮挡、照明或形式规则 |
| 形式与时间 | 保留决定辨认和体验的节奏、关键姿态、线色影形及信息先后 |
| 支撑与装饰 | 保留选定设计中有作用的细节；用户要求精简时再按作品贡献取舍 |
| 研究解释与创作评语 | 默认移出提示词；制作或研究任务另存 |

默认完整表达选定设计，研究解释和无意义的重复不进入提示词；用户要求压缩时先精简解释与重复，再按价值取舍装饰。不能删掉关键条件后用“真实、细腻、复杂”补回字数。两项条件可合为一句画面关系，但不能互换驱动来源或参考系。

## 从概念到可见表达

以下是转换方法示例，不是所有作品的标准效果。它们为规范示范，没有新增模型运行或成片证据。

| 母版表达 | 连续画面表达 | 应保留的区别 |
|---|---|---|
| 稳定层衬托变化 | 固定机位，岸边石块的位置保持；薄雾依次遮住并显露石块间的暗色空隙 | 主体稳定与可见性变化不同 |
| 光独立承担事件 | 人物站在柱旁；窗外光源缓慢转向，斜光经窗框移过地面，再越过肩侧，柱影分开亮区 | 光源变化与人物越过固定光区不同 |
| 形式变化保留身份 | 墨色线群间距收窄，中央空隙逐渐组成同一个偏斜叶形；外缘仍断续，形状由负形被读出 | 图形显现与实体生长不同 |
| 两者共同运动 | 两人持续托住木板两端，前者引导板端进入门口，后者沿通行方向跟进；手位与板端保持联系 | 支撑关系不能只写成“默契配合” |

具体方案的尺度、照明或通行条件仍由当前设计决定。规范示例不能反过来替换用户的原作品。

## 压缩与长度冲突

仅在用户要求精简、指定长度或实际接口有已知容量限制时处理；限制存在不等于授权暗中删减设计。用户要求短版时可合并重复描述、缩短背景、采用相对位置与节奏表达，不为每层强行配置时间码。数值只在表达制作或艺术职责时保留，并具备参考尺度。

若容量不足以保护核心，保留完整母版，并标出短版实际损失或另分制作交接；不能宣称一份短提示词已经承载所有设计。没有模型或用户限制时不主动猜测一个通用最大长度。

### 可选的关系去向记录

研究和复杂交接可为核心关系赋予临时编号，逐项记录去向；编号不进入默认成稿，也不成为知识调用配额。

| 母版关系 | 成稿或控制位置 | 状态 | 损失与责任 |
|---|---|---|---|
| 当前设计的一项核心关系 | 对应画面句、关键帧或合成层 | 保留／改写／转交／丢失／待澄清 | 为什么改变，谁负责实现，需看什么证据 |

正常压缩解释不算核心丢失；保留同一词不等于保留同一关系。无法比较时标为待澄清，不自行补造母版原意。

## 母版存在冲突时

区分意图歧义、缺条件、无意矛盾和有意风格化。能在已授权设计范围内解决的，先修订母版并留版本差异，再转换。任务明确要求忠实转换时，实质冲突应简短指出或标成待处理，不能静默重构，也不能把原样复制冲突当作转换成功。

艺术上有意的错位、形变或非现实时间不必被纠正成写实。必要时明确图形层规则及作品保留项，使它与实体描述共存。修订的依据是当前关系，而不是永久禁止某种效果。

## 与制作环境的内容交接

设计中心交付可直接使用的提示词、参考画面需求、关键状态、时长画幅，以及值得观察的动作、空间或光影关系。用户已有 ComfyUI 等工作流时，按实际要求提供内容，不默认重新核对节点、构建工作流、调用生成或建立自动重试系统。

参考图、关键帧、分层或剪辑说明仅在本次交付需要时加入；不能因为设计丰富就默认要求全套控制工具。用户提供已知接口或输入字段时按其要求组织，未知能力不编造，但不为一般内容设计强制索取环境配置。

用户带回结果时，区分设计问题、转换遗漏与生成偏差；需要修改设计的变化按作品组织回写。实际节点、参数与运行记录由制作环境维护，只有用户另行请求执行或排查时才进入该任务。单独提示词不保证全部关系实现，这一边界不削弱艺术设计本身。
