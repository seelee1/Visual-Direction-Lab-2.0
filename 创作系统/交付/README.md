# 交付

同一套创作系统完成设计后，按用户要求交付。没有指定格式时直接呈现具体视觉设计，未指定模型的提示词采用通用画面或镜头描述。

| 用户要求 | 交付规则 |
|---|---|
| 将选定设计转成提示词或其他成稿 | [信息保留](信息保留.md) |
| Anima 提示词 | [Anima](Anima-生图.md) |
| GPT Image 提示词 | [GPT Image](GPT-Image-生图.md) |
| MiniMax-H3 提示词 | [MiniMax-H3](MiniMax-H3-视频.md) |
| 关键帧、分层、分镜等复杂制作交接 | [制作交接](制作交接.md) |

模型文件只负责格式与语言约定，不包含另一套助手核心，也不触发重新创作。只说图片或动画不等于指定生成模型。实际生成依据用户授权与可用环境执行。

Anima 与 H3 规则核对日为 2026-10-10，GPT Image 为 2026-10-26；迁移结构没有重新验证外部模型规则。效果验证范围见[当前状态](../../项目记录/当前状态.md)。
