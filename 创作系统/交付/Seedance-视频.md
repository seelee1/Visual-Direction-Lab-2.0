# Seedance 视频适配

能力判断遵循[交付层的意图理解与官方核验](README.md#从用户意图判断能力)：未收录的需求先核对官方支持情况，不把本文当作能力白名单。

适配层 v0.3 · 官方资料核对：2026-10-29。以 **Seedance 2.0** 为默认目标，兼容 **2.5**；不自动升级版本，也不把“即梦”“豆包”平台名直接等同于某个模型。仅在用户要求 Seedance 提示词或已明确该生成用途时读取。本文件负责交付，不另建艺术设计流程；概念、分镜与作品修改仍按原任务完成。

## 依据与适用范围

依据官方 [2.0 提示词指南](https://docs.volcengine.com/docs/ark/seedance-2-0-prompt-guide?lang=en)、[2.0 教程](https://docs.volcengine.com/docs/ark/seedance-2-0?lang=en)、[2.5 提示词指南](https://docs.byteplus.com/en/docs/modelark/seedance-2-5-prompt-guide)及 [2.5 教程](https://docs.byteplus.com/en/docs/modelark/seedance-2-5)。本次取得网页检索返回的相关正文；直接打开文档部分只返回页面框架，未观看示例视频，未调用生成模型。下文输出段序、默认语言与示范属于项目约定，不是官方必填字段或实测最佳模板。

2.0 已支持声画联合生成，以及多模态参考、编辑和延长；这些任务不能标为 2.5 专属。官方推荐区分参考新作与修改原视频的指令，并按素材顺序指代对象。本项目把它们组织为以下交付规则。

### 怎样理解“可接受”

自然语言提示词没有一份穷尽所有表达的固定语法表。可提交的文本、官方推荐写法、模型能否稳定执行、接口是否接受某组参数，是不同问题。自然段、分节、镜号、时间段、相对时间和声画描述都可用于表达意图；官方建议不自动变成禁令，也不因文本可提交就承诺准确生成。本文覆盖内容交付所需的主要任务；文件格式、上传和服务限制在实际执行时核对[官方 API](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)，不混进艺术规则。

依据采用官方文档的具体章节与示例；同域名下的社区文章、搜索摘要中的经验比例不当作接口规范。豆包、即梦、火山方舟和 BytePlus 的入口包装可能不同；未经查看实际入口，不猜测是否改写提示词或开启某项控制。

## 输出约定

按[默认交付](信息保留.md#默认交付)展示完整设计后，写「建议画幅：宽:高｜简短构图理由」，再用用户语言交付一个 `text` 代码块。用户已指定比例时沿用，沿用输入画幅但比例未知时写“沿用首帧／原视频”。明确只要正文时直接给代码块。对白和画面文字保留用户指定原文。

正文采用自然语言：按需交代参考职责、整体场景与风格、实际镜头中的动作和声画关系、贯穿全片的必要条件。2.0 与 2.5 的新创作默认使用“镜头号＋时间段”，镜内按需安排时间，不强制细分；编辑和忠实参考沿用原素材结构，不为统一格式新增编排。具体规则见下文。没有参考就不输出素材定义。不要套用 H3 字段、对齐句、发声者标签，也不默认加入 Positive／Negative、权重、质量标签串或 JSON。

默认完整保留选定设计的关键关系和可见细节，只移除研究解释与重复修饰；不为适配另编剧情、简化风格或硬凑固定字数。参数、上传顺序与待绑定材料只在需要时放在代码块外，不把操作说明混进作品描述。

### 表达完整性与创作自由

提示词不设字数上限、建议长度或默认精简目标，由作品需要决定表达深度。完整表达选定设计中的主体、空间、动作、镜头、声画关系与必要细节，不因篇幅较长就删减内容，也不把长短作为质量判断。只清理无贡献的重复与无关说明；为身份、连续性或跨镜理解服务的重述可以保留。用户明确要求精简时再按其要求处理。

自由创作时可以主动设计对白、配乐、复杂调度、幻想变化与多镜叙事；转换已有作品时才受既有内容边界约束。模型适配不预设作品必须简单、安静、短小或只有一种运镜。复杂运镜需表达连续路径与关注对象，避免把互相冲突的动作名称同时堆在一镜中。

官方 2.0 指南偏向每镜一种主要运镜以减少冲突，这是建议而非不接受复合运镜。可以写“先侧向跟随，在人物停步后绕至正面”，也可以写清同时发生的移动与朝向变化。景别、视点、焦点、速度、起止构图依作品表达，不把镜头名词当作互斥标签。风格词与质量词可以使用，但应落实为可见的造型、光色、材料和时间关系；不要求一律堆入品质词，也不自动把手绘、粗粝或有意模糊改成写实高清。

## 根据实际输入选择任务

| 实际任务 | 写法与边界 |
|---|---|
| 纯文生视频 | 建立主体、布局和起始状态，再写变化与观察方式；不虚构图片、视频或音频引用 |
| 首帧图生视频 | 从实际首帧状态继续；重点表达接下来的动作与镜头，不用文字另造冲突的开场 |
| 首尾帧 | 确认两图分别对应起点与终点，描述中间事件和到达路径；不把两张静态说明简单串联 |
| 全模态参考生成 | 明确从哪项素材借用身份、服装、场景、动作、运镜、风格或声音，再描述新作品 |
| 编辑原视频 | 直接点名要编辑的视频，说明对象、改动和必要保留项；不要只说“参考视频”而模糊任务 |
| 延长原视频 | 点名向前或向后延长哪段视频，描述新增事件及衔接状态；区分原视频时间与新增片段时间 |
| 片段衔接／轨道补齐 | 明确视频1的出点、过渡事件与视频2的入点，说明顺序与保留范围；输出是否含原片按实际入口核对 |
| 组合任务 | 如借图片1的人物编辑视频1，分别说明参考资产与被修改资产；不能只凭附件数量推断任务 |

用户讨论续接、补镜头、延长或已有片段衔接时，按当前缺口简短提醒：Seedance 2.0 已支持**向前补写、向后延续和片段间补接**，不把“续接”默认解释成向后延长。向前是在原片开始前补内容，不是倒放；向后是接原片结尾继续；片段间补接则让新增内容从前片末态到达后片初态。原片缺少铺垫时考虑向前，两片之间缺动作或空间连接时考虑补接，后续未完成时考虑向后。方向已明确就直接采用，不每次列菜单或追问。实际入口是否开放视频输入与相应功能需核对，不能只凭模型名称声称可执行。

上传图片不自动等于首帧，多张参考也不自动等于关键帧。严格首尾帧需要平台实际支持的输入模式或角色绑定，不能靠提示词文字冒充。仅有尾帧时不套用 H3 的 L2VA；需核对平台是否支持，或将其明确作为目标状态参考而非严格尾帧控制。素材职责只有在无法合理判断、且会改变任务时才澄清。

全模态参考可以用文字要求“图片1作为开场状态、图片2作为结尾状态”，官方 2.0 教程也展示这种用法；允许与动作、音频等参考组合，但属于语义参考。严格首帧、严格首尾帧和全模态参考在[官方 API](https://console.byteplus.com/ark/region%3Aap-southeast-1/docs/create-video-generation-task-api)中是互斥输入场景，不直接混用 `first_frame/last_frame` 与全模态参考角色。实际界面若提供组合功能，先确认它采用哪种模式，不用“互斥”误删可用的文字参考方案。

## 素材指代与连续性

默认按实际上传顺序称“图片1、视频1、音频1”，各类分别编号。平台使用 `@` 选择器或其他引用形式时，沿用实际界面生成的名称；编号是内容交接，不能宣称已完成上传绑定。未取得素材内容时只说明已知职责，不编造其外貌或声音。

引用用素材类型加同类序号；文件名、URL 或 Asset ID 不替代正文指代。可先定义“图片1中穿红外套的人为领航员”，后文持续使用同一名称，避免同一人物来回换称呼。无需每句都复制外貌与来源；出现歧义时再补绑定。引用视频局部时写明“源视频1的第2–5秒”，与目标片时间段分开。

同一素材含多个主体时，用可辨特征明确所指；同一人物跨多份素材时说明共同身份及各份职责。身份、妆造、动作和背景可以来自不同素材，不能把一个模糊“参考”扩成全量复制。音频仅参考音色时，不把原台词带入新片；视频仅参考运镜时，不自动继承其中的演员、剪辑或背景音乐。

2.0 指南对人物身份参考建议优先使用清楚的独立单人图，必要时分开提供面部与服装依据，避免将同一人物的多视图拼板误识别为多人。这不是禁止一切多图参考：同一指南也展示物品多角度参考。2.5 指南明确增加主体多视图支持；仍须说明各图属于同一主体，不能把这项支持当作所有视图必然准确融合的保证。

分镜板需写清阅读顺序及要采用的画格，不能把整张板当成视频首帧，也不能保证每格自动成为准确关键帧。参考冲突时依据用户确认的设计处理；首尾姿态不相容、旧图物件状态过时等问题不能通过重复“保持一致”解决。连续片段展开当前身份、站位、持物、光源及已发生的变化，具体按[制作交接](制作交接.md)处理。

参考可以提供构图、节奏、表演、特效、画法或音轨，不只用于外貌。如果用户要求忠实沿用参考动作或运镜，直接声明采用范围，只有需要改变或澄清的部分再展开，避免额外编写一条与参考相冲突的路线。参考强弱用明确自然语言说明，不虚构权重参数或固定的“素材总是高于文字”优先级。

## 镜头号与时间段：2.0／2.5 共用交付

新创作默认写为“镜头1｜0–6秒”“镜头2｜6–10秒”。镜号表示真实镜头，时间段表示它在目标片中的位置。单镜也用“镜头1｜0–10秒”，镜内可继续写“0–3秒……；3–7秒……；7–10秒……”，各阶段仍属于同一镜头。推近、转头、停顿或焦点变化不自动新增镜号；真实切镜才换号。简单持续镜头只标整镜范围即可，不为填时间格添加动作、停顿或转折。

默认采用从目标片开头计时的全局时间轴，镜内时间落在所属镜头范围内；确需局部计时须注明基点。分段连续覆盖总时长，无意的空档、倒序或超界需修正；并行声画可重叠，交叉叠化需明确重叠的含义。静止与停留也占时间，不必每秒安排新动作。总时长未指定时依据内容自主建议一个符合目标版本的时长，并与正文、实际生成设置一致。

默认用整秒清楚表达，也可用“动作完成后停留一秒”“第5秒起声音先入”等相对时间或时间点，不能与主时间轴冲突。用户提供的小数时间保留其设计意图，不宣称有亚秒精度保证。按动作、辨认和对白容量分配，不规定一秒只能有一个动作；精确次数、频率与音乐采样点不能仅靠时间标签保证。

**官方口径与本项目选择。** [2.5 指南的时间戳及版本差异章节](https://docs.volcengine.com/docs/ark/seedance-2-5-prompt-guide?lang=zh)明确增强整秒控制，并将 2.0 描述为响应镜号而非时间戳；但 [2.0 教程的全模态参考示例](https://docs.volcengine.com/docs/ark/seedance-2-0?lang=en)直接使用分秒段落。因此不能把前者推成“2.0 不允许写时间段”。本项目对新创作默认结合镜号与时间安排：对 2.0 表达预期节奏，对 2.5 同时利用其文档说明的时间控制；都不承诺逐帧锁定。该结合格式是项目默认约定，不是全部任务的硬规则，也不代表已经实测优于其他写法。无需在每次成稿附重复免责声明；只有精确同步本身是交付硬要求时，另明确验证或后期职责。

每镜说明看见什么、动作怎样发展、镜头如何观察及下一镜继承什么。一个镜头内可以出现多段动作、多种速度和观察重点；连续长镜头不等于均匀移动，保持也不必有转折。编辑任务直接用源视频时间范围与对象定位修改，已有且有助定位的镜号才沿用；不要求为全片重新编号，也不猜测未确认的切镜。忠实跟随参考动作、运镜或节奏时，沿用参考时序，只标明需要改变的部分，不另编一条可能冲突的时间轴。延长任务默认从新增片段0秒计时，并说明接原片开头还是结尾，不能将原片总时长与新增时长混用。

## 声音、对白、文字与约束

对白绑定明确说话者、原文、语种和必要语气，换人说话时明确顺序；画外音与画内说话分开。环境声、接触声与动作发生位置对应，配乐另说明。转换已定设计时不擅自添加对白、歌唱或配乐；自由创作可依作品主动设计声音。无配乐不等于全程静音。官方 2.0 指南建议台词语言统一，避免无意混用；用户明确指定的多语对白仍保留，并逐段标注语种，不擅自翻译。

官方 2.0 指南推荐用圆括号区分音乐、尖括号区分音效、花括号区分台词、〖〗区分字幕。本项目在需要区分这些信息时采用该记法，并明确主体；不要求无声段落填空字段。这是推荐记法，不是必需解析语法；官方示例也使用普通引号对白，不把不同括号判为无效提示词。画面内招牌等文字另写位置和原文，不与字幕混淆。仅禁止额外字幕时，保留作品原本需要的文字；提示词不保证文字和口型绝对准确。

音色、说话方式、台词内容、旋律、节拍、环境声可以分别引用；写清采用什么、由谁发声、何时进入退出。复用原音轨与借音色重新说话是不同要求，不能用“参考音频”笼统替代。多人对白绑定各自声源，跨切镜的声音说明继续；长句、重叠说话、歌唱和停顿按作品时间安排，不把所有文字默认当成要读出的内容。

声音与字幕可以分别控制，例如“无配乐，保留风声和脚步声”“有中文对白，不加对白字幕”“全程静音”。音频生成开关在调用层落实；无需声音时不能只写无配乐。需要字幕、招牌、标题或 Logo 时给出原文、位置和出现范围，要求跟随动作或声音时明确对应关系。合理的正向与负向自然语言都可用；不设置通用缺陷禁词套餐，不把无字幕扩成禁止所有画内文字，不把模型画面中的无水印要求与平台水印参数混为一谈。

正文默认中文，用户指定其他语言则遵从。中英文均有官方支持；2.0 系列另列日语、印尼语、西班牙语和葡萄牙语，2.5 扩展更多语种，具体见[API 语言说明](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。提示词语言、对白语种与画面文字分别处理，不为适配自动翻译台词。

## 兼容 2.5

用户明确选用 2.5 时，沿用上述艺术内容、素材职责和自然语言组织，再处理以下差异；默认 2.0 输出不混入这些专属选项。

| 项目 | 2.0 默认 | 2.5 兼容处理 |
|---|---|---|
| 时间组织 | 新创作默认镜头号＋时间段，镜内按需细分；编辑和忠实参考沿用原素材结构 | 同一原则，可利用整秒时间控制；不为格式新增编排 |
| 片段长度 | 当前官方教程为 4–15 秒 | 单次最长 30 秒；不因容量增加自动拉长作品或加镜 |
| 参考容量 | 采用当前入口实际限额，不用满素材为目标 | 官方教程支持最多 50 项参考；只增加对本作有用的材料 |
| 主体多视图 | 人物优先独立单人图，不把拼板建议扩成禁止多图或物品多角度参考 | 支持主体多视图，明确共同身份及视角职责 |
| 仅音频参考 | 官方 API 不支持仅音频参考输入，需配图像或视频 | 官方教程支持音频单独作为参考；不能据此推断平台界面也已开放 |
| 编辑与延长 | 已有这两类任务，需明确目标素材 | 可进一步指定声画修改的时间范围；原片保持项和新增部分仍需明确 |

2.5 编辑的画幅与时长、延长和首尾帧的画幅有随输入锁定的规则，交接时按[实际教程](https://docs.byteplus.com/en/docs/modelark/seedance-2-5)设置，不沿用自由生成参数。镜头号兼容不代表效果相同；切换版本后仍要复查身份、风格、动作和声音连续性，不承诺原样复现。

2.5 还强化白模视频、故事板、多关键帧参考及声画局部编辑：按需说明采用白模的机位／运动、图片的身份／布景或特定时间的状态，不因能力存在就要求用户准备全套资产。时间范围编辑说明修改从什么变成什么、哪些画面与声音保持。编辑与延长可按官方建议使用 MOV 改善交接，但格式属于执行设置，不是提示词咒语。

2.0 当前教程列出的固定画幅为 21:9、16:9、4:3、1:1、3:4、9:16；默认建议从这些比例选择，不能像旧示例一样把3:2当作已核实的直接输出档。用户明确要求其他比例时保留构图意图，另核对入口是否支持自适应或安排裁切。2.5 支持按输入素材控制更灵活的画幅；具体模式是否锁定输入比例按实际入口处理，不将模型能力扩成所有平台的选项。

## 参数与执行边界

提示词内容与 API 请求分开。时长、画幅、分辨率、音频开关、素材角色及任务模式依据实际平台和型号设置；不能仅在正文写参数名就声称生效，也不猜接口字段。2.0 的仅音频限制见[官方 API](https://docs.byteplus.com/en/docs/modelark/create-video-generation-task-api?redirect=1)。复杂请求超过实际容量时，保留母版并说明分段与接续办法，不静默截断，也不自动切到 2.5。

参考生成、编辑和延长在 2.5 中可能影响任务判定；创作新片时使用“借鉴视频1的运镜，生成……”等明确关系，修改原片才写“编辑视频1”。用户要求接口 JSON 时再核对具体模式与素材角色，不能直接把网页的 `@` 名称当资源 URL。实际生成依据用户授权与可用环境执行。

## 手工格式示范

以下均未生成视频；第二例假设用户实际提供了对应素材，不表示已取得或绑定附件。

### 无参考单镜头，目标 2.0

建议画幅：4:3｜让手部、灯罩与桌面支撑同时可见。建议时长：8秒。

```text
日式二维动画，夜间修灯工坊。固定三分之四中景，成年修灯师坐在画面左侧，桌面右侧的鱼形纸灯横放在两个木托架上。冷色窗光与左侧暖色台灯形成柔和对照，线条有轻重变化，影形清楚。

镜头1｜0–8秒，固定机位，全程不切镜。
0–4秒：修灯师左手轻扶纸灯竹骨，右手用平头刷沿腹部补纸边缘刷过。刷毛受压弯曲，湿润的补纸边缘贴合原纸面。
4–6秒：她抬起刷子，左手仍扶着竹骨，略微侧头检查接缝。
6–8秒：保持检查的姿态，湿痕仍在。纸灯始终留在托架上，内部没有光源；两手和补纸接点持续可见。

<刷毛擦过薄纸的轻响，室外低低的雨声>。没有对白、配乐或字幕。
```

### 多素材参考与两镜衔接，目标 2.0

假设图片1为成年修灯师身份参考，图片2为工坊场景，视频1仅提供缓慢推近的运镜参考；实际成稿须以看见的素材为准。

建议画幅：4:3｜兼顾工作台空间与接缝特写。建议时长：10秒。

```text
参考图片1中修灯师的人物身份与服装，参考图片2中的工坊布局、工作台和鱼形纸灯。视频1仅用于借鉴缓慢推近的镜头运动，不采用其中的主体与声音。生成一段日式二维修灯短片，保持细线与平涂影形。

镜头1｜0–6秒：工作台中景，纸灯横放在两个木托架上。0–4秒，修灯师用左手扶住竹骨，右手沿腹部补纸边缘刷过，镜头缓慢推近手部，保留接点；4–6秒，右手将刷子抬离纸面，左手继续支撑，镜头随之停止推进。

镜头2｜6–10秒：切到同一侧的接缝近景，接续刷子已抬起的状态。补纸平贴在原纸面上，边缘湿痕仍在。修灯师的左手保持原接点，停留至结尾，让接缝可辨；不重复刷涂动作。

<轻微刷纸声随刷子抬离而停止，室外雨声跨切镜持续>。无对白、配乐或字幕，纸灯内部保持无光源。
```

### 局部编辑与向后延长的交接示范

以下假设视频1就是上例的10秒两镜原片。编辑定位沿用源片时间；2.0 也保留区间意图，2.5 可进一步使用其时间范围编辑能力。示范不是像素级或逐帧保证。

```text
编辑视频1。
源视频6–10秒的接缝近景：仅将腹部补纸改为珊瑚红，颜色在该镜切入时已改变；保持补纸的形状、湿痕、接缝、原有动作与机位，其余时段及声画内容保持原样。
```

```text
向后延长视频1，生成末尾之后的6秒新内容，以下时间从新增片段起点计算。延续原片尾部的接缝近景、修灯师身份、纸灯状态与室外雨声。
镜头1｜新增0–6秒，连续接原片末镜，不另切机位。
0–2秒：左手继续扶住竹骨，补纸平贴，湿痕保留。
2–4秒：左手缓缓离开竹骨，纸灯仍由两个木托架支撑。
4–6秒：手离开取景，保持补纸与竹骨近景，窗外雨声继续。无对白、配乐或新增字幕。
```

实际延长返回新增片段还是含原片的组合，以入口输出规则为准；不把“向后延长”理解为再次生成全部原视频。前向补写同理，明确新增内容怎样到达原片开场状态。
