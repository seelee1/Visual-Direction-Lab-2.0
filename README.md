# Visual Direction Lab 2.0

帮助 LLM 充分调用已有视觉知识，主动提出具体、有表现力的设计，并保留艺术判断与自由创造的空间。重点为日式二维，也适用于其他风格。表现资源提供联想入口，不是固定流程或必用技法清单。

## 使用

让 agent 接入[启动入口](助手指令/启动入口.md)一次，之后直接说你想设计什么，例如「原创一幅有故事感的夏日插画」。不需要指定流程、专业技法或生成模型。

只能粘贴文本时使用[通用创作版](助手指令/使用版本/通用创作.md)。需要生成提示词时再指定模型；[Anima](助手指令/使用版本/Anima.md)与 [MiniMax-H3](助手指令/使用版本/MiniMax-H3.md)专用版保留对应格式。接入细节见[接入说明](助手指令/接入说明.md)。

## 内容边界

日常使用核心与相关表现资源，模型输出在最后按需适配。长期作品的保存、组织与制作交接是可选支持，不是创作的默认框架。

`助手指令` 内，入口与核心直接可见，`输出适配` 放模型格式，`创作规范` 放可选辅助说明，`使用版本` 专供整份复制。个人作品保存在本地 `创作输出` 或用户指定位置，默认不随助手项目提交。
