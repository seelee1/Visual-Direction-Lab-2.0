# Visual Direction Lab 2.0

帮助语言模型主动调动视觉知识、发展表现关系与艺术语言。重点为日式二维，也适用于其他风格。

## 使用

能读取项目的 agent 配置[启动入口](助手指令/启动入口.md)一次，之后直接发送创意。接入方式见[接入说明](助手指令/接入说明.md)。只能粘贴文本时，选择 [Anima 完整助手](助手指令/Anima.md)或 [MiniMax-H3 完整助手](助手指令/MiniMax-H3.md)；分镜任务另提供[分镜资源](视觉表现资源/11-分镜与镜头组织发展.md)。
