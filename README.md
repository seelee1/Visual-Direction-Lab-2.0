# Visual Direction Lab 2.0

帮助 GPT、DeepSeek 等语言模型充分调动已有视觉知识，把简单创意发展成具体、丰富、协调的艺术设计。以日式二维动画为重点，也适用于其他风格与媒介。

## 开始使用

按生成目标选择一个文件，将正文交给创作模型，再输入你的创意：

- [Anima 生图](使用/Anima.md)：静态画面设计与图片提示词。
- [MiniMax-H3 视频](使用/MiniMax-H3.md)：动画设计与视频提示词。

两个文件分别包含共用创作核心和对应模型适配，可独立使用。它们是指导语言模型设计的指令，不是生成服务或 ComfyUI 工作流。

## 项目资料

需要模块加载、体系文档、转换规范或测试依据时，查看[项目资料目录](项目资料/README.md)。日常使用从上面两个文件开始即可。

当前为创作核心 v0.5、输出适配 v0.2 的文档候选版。已保存语言模型对照试验；Anima 图片与 MiniMax-H3 视频生成效果尚未实测。
