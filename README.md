# Visual Direction Lab

把简单创意发展成具体、有表现力的视觉作品。重点为日式二维，同时支持摄影、绘画、图形与其他形式。

## 使用

Agent 统一读取[创作系统／入口](创作系统/入口.md)。接入一次后，直接描述要创作或修改的作品，无需选择助手版本、知识库或工作模式。项目讨论与维护不自动输出生成提示词。

支持项目规则的 Agent 使用根目录 AGENTS.md；其他 Agent 将上述入口路径配置为视觉创作的固定入口。入口负责共同职责与调用规则，任务和能力正文按当前作品需要取得。

## 目录

```text
创作系统/
├─ 入口.md        唯一运行入口：职责、任务与调用规则
├─ 任务/          分镜、漫画、系列、专门用途、作品延续
├─ 能力/          人物、场景、静态画面、运动、艺术语言等
├─ 材料/          关系表达、词库、表现卡、知识卡和依据
└─ 交付/          信息保留、制作交接和模型格式
项目记录/         实际测试、观察、当前状态及维护工具
导出/             自动打包的同一套创作系统
```

任务决定作品如何组成，能力帮助作出设计选择，材料补具体表达与依据，交付负责输出组织。全部运行内容位于同一目录树，没有旧版兼容入口或另一套核心。

[材料目录](创作系统/材料/README.md)是检索表；[交付目录](创作系统/交付/README.md)说明格式职责。它们不重新定义助手行为。模型适配只在用户指定对应提示词时生效，普通创作不绑定模型。

## 导出与维护

运行[构建工具](项目记录/版本与工具/构建输出适配包.ps1)生成唯一的导出包，使用说明见[导出说明](导出/README.md)。导出保留相同目录与入口，不按模型复制多套助手。更新后需重新打包并替换外部副本，本项目不会自动修改其他 Agent 配置。

修改来源后运行[完整性检查](项目记录/版本与工具/检查项目.ps1)。旧结构与旧版本由 Git 保存；实际测试输入、原始回答和有用结论保留在项目记录中。

个人作品默认存放在本地“创作输出”或用户指定位置，不随助手项目提交。验证范围见[当前状态](项目记录/当前状态.md)。
