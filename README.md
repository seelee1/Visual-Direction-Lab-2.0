# Visual Direction Lab 2.0

一个专注创作内容的视觉设计中心：帮助语言模型主动调动视觉知识、发展表现关系与艺术语言，把人物、场景、画面、分镜和系列汇成作品，再按需要交付。重点为日式二维，也适用于其他风格。

## 使用

能读取项目的 agent 配置[启动入口](助手指令/启动入口.md)一次，之后直接发送创意。项目从艺术设计出发：核心与表现资源发展作品，交付规范在最后按需要组织结果，模型适配是可选输出。没有指定输出形式或模型也可以使用，默认获得具体的视觉设计。接入方式见[接入说明](助手指令/接入说明.md)。只能粘贴文本时，默认使用[通用创作版](助手指令/通用创作.md)；明确专用于某模型时再选 [Anima](助手指令/Anima.md)或 [MiniMax-H3](助手指令/MiniMax-H3.md)。分镜任务另提供[分镜资源](视觉表现资源/11-分镜与镜头组织发展.md)。

## 内容边界

设计中心由创作能力、作品组织和交付转换构成。简单创作直接完成；持续或复杂作品按[作品组织](助手指令/创作规范/作品组织.md)维护当前设计和相关版本，修改与不同输出共用这份依据。ComfyUI 等制作环境接收设计交付，工作流调用、节点维护和自动重试不作为默认职责。
