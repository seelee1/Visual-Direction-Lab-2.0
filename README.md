# Visual Direction Lab 2.0

供语言模型使用的视觉创作指令与表现资源，帮助模型主动调动知识、发展元素关系与艺术语言。重点为日式二维，同时适用于其他风格。

## 使用

能读取项目的 agent 配置[启动入口](助手指令/启动入口.md)一次，之后只发创意；具体方法见[接入说明](助手指令/接入说明.md)。默认读取核心和对应模型格式，表现资源按创作需要调用。

只能粘贴文本时，使用 [Anima 完整助手](助手指令/Anima.md)或 [MiniMax-H3 完整助手](助手指令/MiniMax-H3.md)，两者择一。

## 内容

- [助手指令](助手指令/README.md)：创作要求与模型输出格式。
- [视觉表现资源](视觉表现资源/README.md)：运动、空间、光影、材料、二维形式与艺术风格。
- [资料归档](资料归档/README.md)：研究依据、案例验证、版本与工具，按需查阅。

当前核心 v0.5、输出适配 v0.3.1；新增资源仍待独立验证。已有语言模型对照与一张用户提供的 Anima 成图观察，H3 视频尚未实测。
