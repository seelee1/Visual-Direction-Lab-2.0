# Visual Direction Lab 2.0

一套供 GPT、DeepSeek 等语言模型使用的视觉创作指令与表现资源。帮助模型充分调动已有知识，把简单创意发展成具体、丰富、协调的艺术设计；以日式二维动画为重点，也适用于其他风格与媒介。

## 直接使用

选择一个助手文件，将正文交给创作模型，再输入你的创意：

- [Anima 生图助手](助手指令/Anima.md)：静态画面设计与图片提示词。
- [MiniMax-H3 视频助手](助手指令/MiniMax-H3.md)：动画设计与视频提示词。

两个助手分别包含共用创作要求和对应模型适配，可独立使用。需要组合自己的指令时，查看[共用内容](助手指令/共用内容/README.md)。

## 内容目录

| 内容 | 用途 |
|---|---|
| [助手指令](助手指令/README.md) | 告诉模型怎样开展创作、保留重要信息，以及怎样为目标模型输出 |
| [视觉表现资源](视觉表现资源/README.md) | 展开运动、物理、光影、空间、材质、节奏与二维形式，推演它们的关系 |
| [创作案例与验证](创作案例与验证/README.md) | 查看实际回答、对比分析、失败问题与验证边界 |
| [研究参考](研究参考/README.md) | 需要深入时查阅专业资料、知识卡、表现卡与原始样本 |
| [历史归档](历史归档/README.md) | 旧版本、通用单文件文本、版本记录和辅助工具 |

日常创作从助手指令开始，按任务需要调用表现资源；研究报告、测试答案和历史记录不默认加载给模型。

当前创作核心 v0.5、模型适配 v0.3.1，整体内容仍为候选版本。已保存语言模型对照试验，并查看一张[用户提供的 Anima 成图](创作案例与验证/Anima-夏日玻璃花房观察.md)；新增静态表现与艺术风格资源尚未验证，MiniMax-H3 视频尚未实测。
