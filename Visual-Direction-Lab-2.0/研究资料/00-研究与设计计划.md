# Visual Direction Lab 2.0：研究与设计计划

版本：0.4 · 日期：2026-10-10 · 状态：阶段 0/1 交付；阶段 2 原型、v0.2 内容深化与旧离线实验包已交付，独立模型对照未执行；阶段 3–6 待执行。最新进度见 [README](README.md)。

本轮交付计划、验收方法和原始案例初审，不发布未经测试的系统指令。阶段之间保留可独立检查的成果；发现问题时回到对应层修订，不把每个失败都变成一条新增禁令。

## 1. 项目定位与边界

目标是一个独立、跨模型的视觉创作助手：把普通语言中的创作意图转化为有艺术判断的画面和时间设计，并默认能够交付完整、连贯的视频生成提示词。知识体系、设计方法和模型适配分别维护。

核心目标是扩展 LLM 能主动展示的具体视觉表现可能性，并发展选择、组合和展现这些可能性的艺术判断。专业领域覆盖和流程可靠性是基础，不能替代这一能力目标。当前 150 张知识卡与 120 张表现卡覆盖基础与深化候选，仍需实际调用和观看验证；最终应用形式不锁定 Skill。定位与待执行实验见[定位修订](06-项目定位修订与表现能力实验.md)，本轮范围与证据欠项见[深化导读](11-知识与表现体系深化导读.md)及[完整性审计](13-完整性审计与后续验证.md)。

首版以可复制的指令与文档包为交付形式，不预设需要开发图形界面或部署服务。兼容静态画面、单镜头动画和多镜头构思，重点研究日式二维动画，同时用其他风格检查方法的适用边界。

默认用户只提供简单创意。助手应能做合理的创作选择并继续工作；只有会改变创作目标的缺失信息才值得追问。用户明确提出的风格、镜头、动作、情绪和禁用效果优先。

理想艺术方案先成立，随后再评估生成路径。技术适配可以改变实现方式，但必须记录对艺术意图的损失，不能悄悄以“稳定”为理由删除创意。

## 2. 需要验证的核心假设

| 编号 | 假设 | 验证方式 | 不成立时如何处理 |
|---|---|---|---|
| H1 | 根据意图和场景关系选用知识，比逐项填满清单更有效 | 与普通描述、清单式助手比较 | 修改知识选择机制，而非扩充形容词 |
| H2 | 明确动作、光影、空间和节奏的联系，可以减少局部精致而整体矛盾的设计 | 检查事件顺序、可见性、因果链和空间目标 | 修订场景表示与一致性检查 |
| H3 | 艺术判断可以通过可观察的表现变化表达 | 要求方案指出观众在哪里、何时感知到什么变化 | 删除只有解释意义却没有画面证据的细节 |
| H4 | 中间设计表示和信息保留审计，可以减少提示词转换损失 | 设计要点逐项映射至提示词或制作控制 | 修订转换规则，区分压缩损失与生成失败 |
| H5 | 日漫重点模块不会把所有场景变成速度线、白闪和过冲的组合 | 安静、自然现象及其他风格测试 | 加强适用边界、反例与主动省略机制 |
| H6 | 轻量指令配合独立知识模块，可以跨 LLM 使用 | 不同加载方式与不同模型实测 | 提供完整内嵌版和明确的模块调用方式 |
| H7 | 不提供外部资料，仅主动唤起就能展示部分默认未出现的表现机制 | 普通基线与唤起条件独立运行；检查条件变更和新场景迁移 | 判断哪些条件下仍需补资料；不从缺席推断模型完全不知道 |
| H8 | 具体表现资料的增益区别于流程、篇幅和专业语气增益 | 主动探索要求 × 外部资料的两因素对照，补相关性控制 | 修改资料粒度与使用方式；复述不算掌握 |

这些是研究假设，不是已证实结论。艺术质量由有理由的判断和实际观看共同评估，不以术语数量或提示词长度代替。

## 3. 知识研究地图

| 领域 | 重点问题 | 必须建立的跨域联系 |
|---|---|---|
| 艺术意图与视觉心理 | 注意力、预期、情绪、歧义、视觉层级、留白 | 情绪如何通过空间、时间和可见变化被感知 |
| 构图与空间 | 主次、负空间、深度、遮挡、尺度、视线、画外空间 | 动作路径是否被构图看见；遮挡如何改变信息揭示 |
| 摄影与镜头 | 景别、机位、透视、镜头运动、景深、剪辑与轴线 | 镜头变化如何影响速度、距离、关系和情绪 |
| 动画与角色表演 | 重量、支撑、姿态、力、惯性、跟随、重叠、动作动机 | 身体、服装、环境反馈与表演意图的统一 |
| 时间与节奏 | timing、spacing、停顿、动作密度、事件顺序、镜头节奏 | 动作、光影、构图和信息揭示是否争夺同一时刻 |
| 动态光影与色彩 | 光源、遮挡、投影、反射、透射、色温、色彩脚本 | 谁在移动；光影如何随几何关系或艺术意图改变 |
| 材质与形变 | 布、发、皮肤、金属、玻璃、柔软与刚性、干湿变化 | 材质怎样同时改变运动、轮廓和光学表现 |
| 流体与自然现象 | 水、烟、雾、风、雨、雪、火、波浪、尘土、植物 | 驱动力、尺度、传播、消散以及与物体的相互作用 |
| 特效与合成 | 发光、粒子、速度线、冲击帧、层级、二维/三维结合 | 效果是否强化主事件，是否破坏可读性或材质关系 |
| 风格与抽象 | 写实、日式二维、绘画、图形化、定格等 | 哪些规律必须保留，哪些可为表达目的改变 |

日式二维模块重点研究：演出与分镜、layout、关键姿态与原画、timing/spacing、选择性持帧、线条与轮廓、色指定、背景美术、效果作画、撮影合成，以及不同作品和创作者的差异。不能把某一技法说成日漫必需，也不能把有限动画等同于全片低帧率。

## 4. 研究方法与证据要求

优先使用创作者访谈、制作方资料、原始研究、作者教材与官方技术文档。作品分析须记录具体镜头或时间段；不能仅凭作品名称推断细节，也不能把个人审美当作行业共识。

每项重要知识使用统一研究卡：

> 概念 → 可观察现象 → 适用条件 → 失效/反例 → 与其他领域的关系 → 可操作设计选择 → 来源与证据性质。

明确区分：物理规律、知觉研究结论、制作惯例、作品观察和本项目提出的艺术建议。实验结论记录条件；制作惯例记录适用风格；艺术建议允许多个有效答案。

来源登记记录作者/机构、标题、链接、定位、访问日期、支持的主张和不能支持的主张。无法读取的正文标为待核验，不据此形成确定规则。最新模型能力在进入适配阶段时再核验并注明版本，不沿用旧样本的技术结论。

已经定位的研究入口：

- 京都动画官方[职种介绍](https://www.kyotoanimation.co.jp/recruit/job/)：提供原画、色指定、背景和撮影等部门的职责说明。用于划定研究范围，不能直接证明特定技法的艺术优越性。
- Pharr、Jakob、Humphreys 的 [PBRT 第四版](https://www.pbr-book.org/4ed/contents)：包含摄影机、反射模型、材质、体积散射和光传输。用于物理/光学关系研究，不直接规定二维动画该采用什么画法。
- Lasseter，1987，*Principles of Traditional Animation Applied to 3D Computer Animation*：[原始论文副本入口](https://www.cs.cmu.edu/afs/cs/academic/class/15462-f13/www/lec_slides/Lesseter.pdf)。本轮搜索定位到论文，正文读取超时，列为待核验；不能替代日式二维动画的专项资料。

上述入口只是种子资料。构图、视觉心理、流体、自然现象和日漫创作者资料仍需专项研究。

## 5. 候选整体架构

以下是待测试的架构，不是最终系统指令。

1. **理解意图**：提取用户的核心体验、事件与明确限制，区分用户要求和助手补充。
2. **建立场景关系**：记录主体、空间、光源、环境、材料、观察位置和时间事件。允许尚未选定的变量。
3. **作出艺术选择**：围绕意图寻找真正改变表现的关系；必要时探索不同机制的候选方案，选择一种并主动省略竞争细节。
4. **形成可观察的设计**：把“孤独”“急切”“惊讶”等意图转化为画面变化、动作、停顿、遮挡、色彩或空间关系。
5. **校验整体**：检查支撑与惯性、镜头与可见性、光影与几何、动作目标与视线、事件与节奏。允许有目的的风格化偏离，但不能用“夸张”掩盖无意矛盾。
6. **转换输出**：从同一设计生成自然语言提示词、分镜/关键帧说明或制作交接信息；按任务需要选择输出形式。
7. **适配与反馈**：根据指定模型和控制方式规划实现，记录损失并根据观看结果修订对应层。

内部结构用于可靠设计，不强迫每次对用户展示全套分析。默认给出一份可直接使用的完整提示词；用户要求时再展开设计依据、替代方案或制作计划。静态创作不强行添加动作，安静场景不强行添加高潮。

## 6. 艺术设计到提示词的转换研究

建立一个模型无关的中间表示，至少能表达：创作意图、用户约束、空间/观察关系、事件顺序、状态变化、光影/材质相互作用、风格处理、不可丢失的表现关系。字段按场景需要使用，不成为填空表。

给重要设计项分配可追踪编号和优先级：

- **核心项**：用户要求和决定作品意义/表现的关系，不能无记录丢失。
- **支撑项**：让核心可读的姿态、节奏、空间和光影条件。
- **可选项**：可以删减而不改变主要体验的修饰。

每项必须对应“已进入提示词 / 转交关键帧或制作控制 / 有依据的删减 / 尚无可靠实现”。核心项仅转入制作控制时，不能声称单独使用文字提示词已完整保留。

测试顺序：先验证不受长度限制的完整提示词，再研究压缩版与指定模型适配。保留对象—变化—顺序—关系；优先削减同义形容词、解释性散文和无辨识意义的数字。

设计时间码是意图表达，不等于生成模型能精确遵守。输出帧率、作画曝光、运动采样与后期处理分开描述。“不要平滑”等全局否定需检查是否误伤呼吸、发丝或推镜。

同一艺术母版可导出：通用视频提示词、静态关键帧提示、镜头/分镜设计、模型适配版本和 ComfyUI 制作交接。后者记录关键帧、遮罩/运动控制需求、分层与后期职责；只有读取实际环境后才设计具体工作流，不编造节点或控制能力。

## 9. 对照和评审协议

对照版本：B0 为普通简短创作描述；B1 为逐项补全专业领域的清单式助手；V2 为本项目原型。T01 另保留 DeepSeek 原文。原文不是可执行的全场景系统，因此只用于该案例比较。

控制用户输入、输出任务和可用资料；记录总长度。另做相近长度的比较，避免把更长误判为更好。消融实验逐次移除“关系选择”“一致性校验”或“信息保留审计”，观察该机制是否真的有用。

新增表现能力实验：独立比较普通基线、主动唤起、资料补充与二者组合；配合条件变更、反例、可见性、迁移和取舍探针。分别记录有效探索范围、展开程度、组合能力、艺术适合度、选择/省略、边界和转换保留。不根据单次输出反推模型内部知识，也不把复述视为掌握。完整控制与归因边界见定位修订文档第 6–8 节。

分别评审三个层面：

1. **设计**：是否贴合意图；空间、物理/风格规则和时间是否自洽；重点是否可见；艺术选择是否有取舍；细节是否必要。
2. **转换**：核心事件与表现关系是否保留；表达能否独立理解；有无新增冲突；实现分工是否明确。
3. **成片**：在实际观看中是否实现目标；哪些失真来自模型、控制方案、提示或艺术设计。

采用带文字依据的 0–3 级评审：0 缺失或冲突；1 提及但不可操作；2 清楚、基本有效；3 关系完整且支持创作意图。评分用于定位，不合并为掩盖严重问题的总分；无人类观看或成片时，不评价“观众效果已验证”。

初始硬性门槛：用户约束无未经说明的违反；关键动作/空间/光影无未解决矛盾；核心项去向 100% 可追踪；提示词可独立使用；资料和实际运行记录可追溯。100% 指可追踪，不能解释为模型实现率。

创意和审美单独进行有理由的比较。候选方案须在信息揭示、空间关系、光影或时间组织上有实质差异；仅换形容词不算不同方案。允许测试得出“某基线在某场景更好”。

修订后回测失败案例及至少一个机制相反的场景，防止为了急停而损害安静场景。若增加一条规则，必须同时记录其适用条件、可能副作用和支持它的失败证据。

## 10. 最终版本与使用方式

| 交付 | 用途 |
|---|---|
| 完整系统指令 | 规定角色、创作机制、默认输出与一致性责任 |
| 独立知识体系与设计原则 | 支持研究、检索和扩展；不依赖某个视频模型 |
| 转换规范与中间表示 | 保留关键关系，生成提示词或制作交接信息 |
| 案例、对照、失败与优化报告 | 展示有效范围、失败模式与修订依据 |
| ChatGPT 项目使用包 | 项目指令、知识文件、加载与验证说明 |
| 其他 LLM 通用包 | 可放入系统消息的版本、无系统入口时的起始指令与知识加载方法 |
| 完整内嵌便携版 | 无知识文件/检索能力时使用，明确篇幅与上下文代价 |

平台能力与长度限制在打包时查证。不能假定附件会自动成为长期知识，也不能声称仅复制一段角色描述就获得完整知识体系。外部检索版本需记录实际调用接口和模块选用；不具备接口时使用普通文档加载方式。
