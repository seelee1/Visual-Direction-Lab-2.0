# T01 原始参考案例初审

日期：2026-10-10 · 状态：文本初审，未做分镜、LLM 调用或视频生成验证

原始文件：[测试样本-1.md](../../测试样本-1.md)。保留原文不修改。以下判断来自文本内部对照；涉及运动合理性和技法普遍性的内容仍需研究与实际画面验证。

## 应保留的优势

原文有明确的“冲刺被打断、残余运动延续情绪”方向；5 秒拆成有功能差异的阶段；把主体运动、头发衣摆和呼吸分开；用满与空的节奏对照引导注意力。新系统应保留这种从意图到时间设计的能力。

不能因为发现局部问题而把整个方案平滑化，也不能预先认定白闪、速度线或夸张形变必然错误。

## 具体问题与待研究项

| 编号 | 原文证据 | 问题性质 | 后续验证或修订方向 |
|---|---|---|---|
| A01 | “切在膝盖上方”且“需要同时看到腿部制动”；随后详细描述踏地、脚掌和地面尘土 | 构图可见性冲突 | 脚部证据落在画外；可改景别，也可选择通过上身/画外反馈表达，但必须作出明确选择 |
| A02 | “所有运动瞬间归零，但头发、衣摆、粒子还在往前飞” | 状态表述冲突 | 区分主体位移停止、姿态持帧与次级对象继续运动；不能笼统写所有运动停止 |
| A03 | 全速时发裙向后拖；制动峰值仍是“最大后拖”；最终提示词写“继续前甩” | 运动过渡不完整；不宜直接判定物理不可能 | 画出相对身体与世界的运动路径、延迟与转向；检查是否有可读的前甩阶段 |
| A04 | “尘土/碎石向外炸开”，又说方向与奔跑相反 | 效果方向含混 | 分清接触喷散、脚部刮擦和既有粒子的运动；材质、摩擦和接触方式未设定时不制定统一方向 |
| A05 | 侧向机位、从左向右跑，随后“回头”被写成“视线落在镜头上” | 叙事目标/空间目标不明确 | 区分看向来路、看向侧方或看向镜头旁的目标；先定义目标位置，再确定转身幅度 |
| A06 | 固定镜头下跑 1.2 秒，同时称“全速”“她就已经冲过去了” | 空间与时间设计缺参数 | 结合画幅、起始位置、投影速度、停点与留白检查；无需强行指定真实速度，但需可排演 |
| A07 | “起始快”却括注“缓入”；转头还包含减速、过冲、回正 | timing/spacing 术语与可见行为不统一 | 以关键姿态与间距变化澄清，不靠术语自动成立 |
| A08 | 呼吸、手臂垂落被归为“全部被动、由惯性驱动” | 因果分类过度简化 | 区分惯性运动、生理运动和恢复平衡/放松的动作；不把“非主要表演”统称惯性 |
| A09 | 没有光源、投影、反射或角色入停点后的明暗变化设计 | 研究覆盖不足，未必必须增加效果 | 判断光影是否能强化本场景意图；比较恒定光、通过阴影边界、环境光揭示等方案，允许保持简单 |
| A10 | “唯一一次完全静止”与末段“完全定住，只有呼吸和碎发微动” | 停顿层级不明确 | 持帧可以只作用于某些层；将总体静止感与局部运动分开 |
| A11 | 多项技法被称为“日漫标志”“特有”“不可替代” | 适用范围缺证据 | 用创作者/作品资料核验；归纳为条件化选择，避免把审美偏好升级为普遍事实 |
| A12 | 对 Seedance/当前视频模型难点做笼统判断，无版本与测试记录 | 技术结论无法复现 | 仅作为历史样本的判断；指定模型版本、任务条件与控制方式后重新测试 |

## 转换损失的第一轮定位

原始最终提示词保留了主要事件、方向、部分形变、残余运动、视线先动和缓慢推镜。因此不能说“设计全部丢失”。问题在于具体关系的保留程度不一致。

| 设计项 | 最终提示词状态 | 风险 |
|---|---|---|
| 急停后留白与情绪重心 | 残余运动被保留，留白的阶段功能较弱 | 可能只得到“动作接动作”的流程 |
| 头部、肩部、躯干的先后与幅度差 | 压缩为头部带动身体 | 表演层级和身体朝向关系丢失 |
| 主体持帧与发裙继续运动 | 写成“身体静止”后残余运动 | 有一定保留，但主体姿态、位移、持帧的区别仍不清 |
| 发丝短暂遮眼再露眼 | 压缩为“发丝掠过面部” | 信息遮挡与揭示的功能被弱化 |
| 冲击帧和选择性曝光节奏 | 未明确进入主提示词，末尾概括为顿挫 | 若交给后期，需另有制作交接；主提示词不能声称完整包含 |
| 地面支撑与脚掌制动 | 仅“突然急停”，局部关系省略 | 失去重量感的证据，且母版构图本身仍有冲突 |
| 回头后的最终朝向与凝视 | 写“面向镜头” | 可能与偏侧躯干设计及“回头”含义不一致 |
| 部分数字与形容词 | 被省略 | 需按表现功能判断；不是所有删减都构成质量损失 |

## 初审如何影响系统设计

当前最需要的是场景关系、可见性、状态区分和信息保留机制。它们比增加“光影要丰富”“动作要有惯性”等泛泛规则更能定位问题。

后续对照至少保留三条路径：原文、保持原艺术意图的修正版、采用不同艺术机制的版本。先比较整体成立与表现差异，再分别转换提示词。不能把原文缺陷、审美偏好和模型实现难度混在一次评分里。

所有待研究项仍开放：例如“最大后拖”可能是有意的延迟处理；固定镜头下能否容纳动作取决于空间设计。需要关键姿态和场景布局来解决，不能仅凭文字把它们判成错误。
