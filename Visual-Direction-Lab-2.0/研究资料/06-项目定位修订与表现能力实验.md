# 项目定位修订与视觉表现能力实验

日期：2026-10-10 · 定位修订 v0.1 · 状态：研究目标与待执行实验设计，不是实验结果或最终系统指令。

修订依据：用户提供的网页 ChatGPT 讨论文本。该文本用于表达项目意图，不作为专业事实来源；本轮未检视其中链接的图片，也未用静态图证明运动过程。

后续状态：按本定位完成的表现库、机制、公开演练与离线实验包已交付，见[阶段 2 交付状态](10-阶段2交付与验证状态.md)。本文件保留定位修订时的实验计划，不冒充实际结果。

## 1. 核心目标重新表述

Visual Direction Lab 要扩展的是：面对简单创意，LLM 能主动提出的具体视觉表现可能性，以及将这些可能性发展为有表现力作品的能力。

执行流程、输出格式与一致性校验仍有作用，但它们服务于这个目标。核心资产是可持续扩展的视觉表现知识、具体案例、条件与反例，以及选择和组合它们的艺术判断。最终载体可以是项目知识文件、系统指令、检索知识库、独立助手或其他形式；当前不锁定 Skill。

同时区分两件事：

- **探索范围**：在同一创意下，能够想到多少实质不同、具体可见、条件成立的表现机制。
- **作品取舍**：选定方案是否适合意图；所选元素如何形成整体；何处需要静止、省略或保持常规处理。

探索丰富不意味着成稿必须密集。一个以人物保持和倒影变化为主的镜头，可能比同时添加发丝滴水、推镜、强逆光、飞溅和表情变化更有效，也可能因缺乏其他证据而失败；优劣需要具体比较。

“主动发现”也不能等同于不断添加陌生特效。熟悉的技法在恰当的构图、节奏和关系中仍可有表现力。评价关注可见贡献与艺术组织，不奖励术语数量、新奇措辞或细节总量。

## 2. 对阶段 1 成果的重新评价

现有六个模块、80 张知识卡建立了领域基础、条件、反例和跨域关系。它们保留使用，不宣称已经构成充分展开的视觉表现库。

例如 N02 涵盖液面、滴落、气泡与润湿，但仍将多种现象压在一个入口里。知道“表面张力与界面会影响液体形状”，不等于能设计一段清楚可见、节奏合适的挂滴过程。后者还需要接触位置、观察尺度、变化顺序、受光条件、风格画法与作品作用。

下一阶段在基础知识之上增加**视觉表现条目**，并用实验检验它们是否真的扩展输出。数量只记录工作规模，不作为能力证明。

## 3. 三层知识结构

| 层 | 解决的问题 | 典型内容 | 成功证据 |
|---|---|---|---|
| 专业基础 | 为什么会发生；哪些条件限制它 | 动态、光学、知觉、制作惯例与风格边界 | 条件、依据和反例清楚 |
| 视觉表现 | 具体看见什么；可以怎样展开 | 对象变化、形状、遮挡、显露、时间过程、观察方式 | 能从描述中识别具体画面或事件，且关键条件成立 |
| 艺术判断 | 为什么此处值得采用；如何与其他元素组合 | 意图、视觉重点、形式美感、对比、节奏、取舍 | 选择有可见贡献，整体协调；比较与观看支持判断 |

三层互相往返，而非固定流水线。可以从某个形状、光影或节奏发现表达方向，也可以从用户的情绪意图寻找视觉证据；不要求先确定情绪再为它查表配技法。

## 4. 视觉表现条目的粒度

条目以一个可辨认的表现机制或感知变化为单位，允许包含多个对象。既不使用“光影”“水滴”这样的宽泛标题，也不拆成大量脱离画面目的的微小步骤。

每个条目记录：

| 字段 | 内容 |
|---|---|
| 可见变化 | 开始、变化过程与结束；静态设计则记录空间关系与观看路径 |
| 成立条件 | 对象、尺度、接触、光源、观察位置、时间和必要环境；区分必需条件与自由选择 |
| 展现方式 | 可选景别、轮廓/色块/线条、曝光与节奏、遮挡和空间安排 |
| 可发展范围 | 可表现到哪些阶段，哪些在当前景别下不可辨，哪些需要参考补充 |
| 跨域组合 | 与动作、光影、材质、构图和时间形成哪些有意义的联系 |
| 艺术机会 | 可以服务哪些形式或情绪方向；不宣称固定情绪对应 |
| 不采用的情形 | 不相关、不可见、重复、争夺注意、破坏风格或违背用户限制 |
| 变体与反例 | 改变关键条件后的结果；避免把一个镜头记成通用模板 |
| 依据与状态 | 基础来源、实际观察定位、设计推断、待核验部分与测试记录 |

表格用于知识建设和审查，不要求最终回答逐字段展示。成稿仍可直接给完整视频提示词。

“表现到什么程度”至少分开记录五个方面：现象是否具体、过程是否展开、相关关系是否成立、当前镜头是否看得见、风格处理是否清楚。这些不是艺术优劣的统一等级；远景用少数色块表现雨幕，不因省略水珠微观过程而低于特写。

## 5. 雨中少女：公开诊断场景 T09

输入固定为：“设计一个少女站在雨中的日漫镜头。”本输入没有指定伞、夜晚、街道、悲伤、孤独或镜头长度。补充这些条件是创作选择，应与用户原要求区分；不得让所有候选自动拥有同一场景设定。

下表是 D 类设计草案，用于说明条目粒度和比较方式，不是已经验证的表现库，也不要求同时采用六项。

| 草案 | 具体机制与可见变化 | 必需/补充条件 | 可以展开的方向 | 主要审查点 |
|---|---|---|---|---|
| E-R01 雨的空间层次 | 前景少量雨痕越过画幅，人物平面的雨保持可辨，远处降水与背景形成不同密度层次 | 景别与前后距离足以区分；具体清晰度/模糊规则须选定 | 短暂遮挡与重新显露人物，或仅构成持续空间层次 | “近景必清晰、远景必模糊”不能写成固定规则；前景雨不得无意遮掉重点 |
| E-R02 挂滴事件 | 特写选择一个接触点，水珠出现、增长或合并，随后脱离；脱离后的接触区保持可辨 | 实际接触面、受力与尺度有依据；需补润湿参考 | 用一次事件与人物的保持形成时间对比 | 发梢回弹不是必然伴随结果；不能把全部微观步骤挤进不可辨的远景 |
| E-R03 倒影的变化 | 人物姿态基本保持，水面扰动使倒影局部破碎并逐渐恢复可辨 | 可见积水、合适观察关系与反射条件 | 观众在本体与倒影之间转移注意，改变二者显著性 | 不是任何角度都能看到完整倒影；密集落雨可能持续干扰，不应无理由完全恢复平静 |
| E-R04 遮挡与受光揭示 | 选定人物、遮挡物和光源关系，局部明暗边界改变，使眼部或轮廓逐渐可见 | 伞、屋檐或其他遮挡物属于新增选择；变化来源明确 | 将人物的微小动作与信息显露连接 | 低头不必然让眼睛脱离阴影；必须检查光源方向、伞沿和头部相对位置 |
| E-R05 雨势与表演的错位 | 外界雨的视觉变化持续，人物只发生一次有辨识意义的局部变化，随后保持 | 选择可读的手、视线或姿态；改变动作时不得变成奔跑等新主事件 | 时间重心落在一次松手、移开视线或恢复姿态上 | 不机械加入叹气、流泪、眨眼和衣摆；必须说明所选变化的可见贡献 |
| E-R06 图形化雨幕 | 用有限层的线、色块和保持组织雨，选择在人物轮廓附近出现/断开的图形节奏 | 明确为二维形式处理；保留角色与空间辨认所需关系 | 依靠线条密度、方向与轮廓显露构成韵律 | 不把图形变形冒充物理现象；不把所有日漫都规定为同一种曝光或画法 |

比较时应发展成实质不同的方案，例如：

1. **本体保持、倒影变化**：让 E-R03 承担主要表现，其他雨层帮助建立空间，不再同时强调眼部显露与挂滴特写。
2. **一次局部事件**：用 E-R02 组织观看，选择能辨认接触点的尺度；人物与背景为这次事件提供稳定参照。
3. **轮廓与图形韵律**：以 E-R06 发展二维形式美感；主要差异来自线与色的组织，不只是把写实方案改称“日漫”。

这些是可能方向，尚不评价哪一种更优。审查必须包含“没有采用这些效果是否反而更适合”的对照。

T09 已公开用于讨论，不用作保留测试。后续独立场景应在原型与条目初稿冻结后再确定，避免只证明系统能复现雨景示范。

## 6. 核心实验：调用不足还是掌握不足

通过输出只能研究模型在给定条件下**展示了哪些能力**。一次没有出现某种表现，不能证明模型不知道；一次正确复述，不能证明能独立迁移。实验记录条件间的变化，不声称直接测量模型内部知识。

### 6.1 两因素主对照

对同一模型、同一输入、同一输出任务，分别改变“是否明确要求主动探索具体视觉机制”和“是否提供专业表现资料”。

| 条件 | 主动探索要求 | 外部表现资料 | 要比较的变化 |
|---|---|---|---|
| C00 普通基线 | 无额外探索要求 | 无 | 简单请求下的实际默认输出 |
| C10 唤起条件 | 有；要求实质不同、可见、条件成立并进行取舍 | 无 | 只改变调用要求后能否出现更多有效机制 |
| C01 资料条件 | 无额外探索要求 | 有 | 资料是否自然进入创作，还是仅被复述/堆叠 |
| C11 组合条件 | 与 C10 相同 | 与 C01 完全相同 | 资料与主动调用要求能否共同改善输出 |

另保留原计划 B1 清单式助手作为诊断对照：给出领域检查流程，但不直接提供具体雨景答案。它用于判断流程补全本身的贡献，不与主对照混为一个变量。

主对照先用未提供外部答案的基线，再运行资料条件。不同条件使用独立会话，保留全部输入输出与运行配置；实际执行前核验可用环境，不假定当前对话能清空上下文，也不把本轮写作当独立实验。

### 6.2 控制与重复

- 固定用户要求、交付形式和输出长度范围；另记录实际长度，检查优势是否仅来自更长输出。
- 资料只介绍机制、条件与反例，避免直接给该测试输入的最终方案；保留完全相同的资料版本。
- 做资料相关性对照：用相近篇幅的无关资料替换相关资料，判断是否只是额外上下文/专业语气带来的变化。资料质量本身也要审查。
- 同一条件先做至少三次独立探索性运行，报告逐次结果；样本少时不声称统计显著或普遍能力。确定性配置的重复只能核对稳定性，不能算独立行为样本。
- 可控时记录模型标识、日期、采样配置、上下文和文件加载情况；不可控项明确标注。跨模型分别比较，不把一个模型的结果外推给全部 LLM。
- 输出去除条件标签后再评审；保持长度差异记录。只有独立评审实际参与时才称盲评，自评属于开发者诊断。

### 6.3 掌握程度的进一步检查

| 探针 | 操作 | 可支持的结论与限制 |
|---|---|---|
| 条件变更 | 改景别、光源、遮挡、运动来源或风格，要求修订设计 | 能适应本组变更；不等于理解所有类似情形 |
| 反例判断 | 给“低头必出阴影”“水滴脱离必使发梢回弹”等绝对说法，要求判断并说明所需条件 | 能识别本组条件缺失；只会答“取决于情况”不算有效 |
| 可见性检查 | 将挂滴过程移到人物远景，检查是否还值得写进主方案 | 能区分现象知识与当前镜头的可读性 |
| 新场景迁移 | 用未示范对象/场景，测试接触、显露、波动或图形节奏等关系 | 能迁移到指定新场景；避免仅换名词而照搬原例 |
| 取舍压力 | 禁止一个常见技巧，或要求安静、克制、特定二维形式 | 能在限制下寻找其他有效机制，或有理由保留简单处理 |
| 转换保留 | 将设计转成单独可用的提示词，核对主关系去向 | 能表达关系；不证明生成模型会实现 |

资料在新会话中移除后仍能正确使用，只支持“该新输入下无资料也可展示相应能力”。本项目资料未必进入模型训练，不能称为模型被永久教会。

## 7. 评价：从领域齐全转向表现证据

先检查用户约束与关键矛盾，再分别评估各项，不合并成掩盖错误的总分。

| 维度 | 观察证据 | 避免的误判 |
|---|---|---|
| 有效探索范围 | 非重复、条件成立且与创意相关的具体机制；按机制聚类记录 | 同义形容词或把一个过程拆成十项来凑数量 |
| 展开程度 | 初始/变化/结束清楚；对象、驱动、顺序和可见关系明确 | 术语多就算深入；微观数字多就算精确 |
| 组合能力 | 元素互相支持；依赖条件满足；主要事件不被竞争细节覆盖 | 逐领域各写一句就算跨域整合 |
| 艺术适合度 | 贴合用户目标、形式选择有理由、重点与节奏可辨 | 一律奖励戏剧化、反常或新奇 |
| 选择与省略 | 能说明采用/删除改变了什么；替代方向实质不同 | 每次都输出固定数量效果或方案 |
| 迁移与边界 | 条件改变后修订恰当；知道何处需补参考 | 将“会复述例子”当作掌握 |
| 转换保留 | 主表现关系能在提示词中独立识别 | 仅保留物体和风格标签就算保留设计 |

可以沿用原计划 0–3 级诊断，但每个等级必须附具体片段和理由。对纯形式美感允许评审分歧；不要求作者编造剧情价值。

设计文本只能评估“可预期的画面与关系是否清楚”。实际视觉强度、观众注意、情绪与审美表现留到作品观看。最终艺术质量不能由条目命中率代替。

## 8. 如何解释实验结果

| 观察 | 下一步 | 不能直接声称 |
|---|---|---|
| C10 明显优于 C00，资料增益小 | 加强主动唤起与选择，检查更广场景 | 模型已经知道所有视觉表现 |
| C01/C11 出现基线没有的可靠表现，并能通过条件/迁移探针 | 优先补相应资料与案例，扩大测试 | 已证明原模型内部完全没有这些知识 |
| 提供资料后只复述，条件变更即失败 | 调整资料粒度、解释与例子；核对模型能力和加载 | 知识补充已经成功 |
| 候选多了但作品更散乱 | 改艺术判断、可见性与取舍机制 | 更多知识必然提升创作 |
| 文本设计好，提示词丢失主关系 | 修转换层并回测 | 该专业领域知识不足 |
| 提示词保留，成片未实现 | 检查模型/控制/分层实现，再评估艺术母版 | 创意本身无效或需要删除 |

允许实验得出“这组输入下普通基线更合适”或“没有足够证据区分两种解释”。

## 9. 调整后的下一阶段交付

阶段 2 先围绕下列目标组织工作，再提炼系统指令原型：

1. 将关键基础入口展开为有变化过程、条件与反例的视觉表现条目初稿，优先覆盖角色运动、安静表演、动态光影、流体与自然、二维图形表现。雨景作为诊断案例，不成为所有场景的模板。
2. 设计允许“从意图找表现”和“从现象发现表达”的主动探索与选择机制，检验其输出能否出现实质不同方向。
3. 冻结探索性对照协议与资料版本；在可访问的独立环境执行并保留运行证据。环境尚未具备时交付待执行包，明确与实际结果分开。
4. 根据失败归因修订知识条目、调用方式或艺术判断。系统指令只固化被支持的机制，不把表现库全量改写成强制执行规则。

阶段 3 继续做转换与信息保留；阶段 4 做更广案例与消融；阶段 5 检验实际视频表现。表现知识建设贯穿后续阶段，不因阶段 1 已交付而停止。
