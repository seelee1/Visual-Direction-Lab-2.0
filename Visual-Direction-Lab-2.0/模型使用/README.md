# 模型使用入口

使用包 v0.5，候选修订版；核心指令与相关资源根据首轮测试优化。适用于能接收文字指令的语言模型；不预设平台功能、上下文容量或某个视频模型。

平台装载见[跨模型部署](../交付/跨模型部署与任务用法.md)，复杂转换与制作交接见[完整规范候选](../交付/艺术设计到提示词与制作交接规范.md)，整体交付范围见[当前状态](../交付/整体交付与当前状态.md)。这些补充不要求日常创作全部加载，也没有改写现有三个包。

## 最快开始

生图使用[Anima 生图使用版](../发布包/VDL-v0.5-Anima-生图使用版.md)，视频使用[MiniMax-H3 视频使用版](../发布包/VDL-v0.5-MiniMax-H3-视频使用版.md)，把对应正文作为创作要求，再输入简单创意。每包包含基础版和一个模型适配；[适配入口](输出适配/README.md)负责选择与管理，不默认同时装载两套规则。适配层 v0.2，核心仍 v0.5；这次没有新增模型或生成实测。

需要保留纯通用输出时使用[单文件基础版](../发布包/VDL-v0.5-基础版.md)。它包括完整核心指令、广域激活地图与输出约定。

需要更广的构思提示时使用[单文件扩展版](../发布包/VDL-v0.5-扩展版.md)。需要表现变体、过程展开、观察形式和日漫画法的进一步提示时使用[单文件深化版](../发布包/VDL-v0.5-深化版.md)。通用三包择一；采用扩展或深化版时另提供当前需要的一个模型适配文件，不再叠加基础或模型单文件使用版。更长不保证效果更好，按任务选择。文件可用并不代表模型实际读取了全部内容；容量不足时按模块加载。

## 模块方式

把[核心指令](核心指令.md)放入可用的系统、项目或起始会话指令位置。通过实际可用的附件、上下文或检索方式提供[资源路由](资源路由.md)及相关资源。这里描述的是通用装载原则，不承诺任何平台的附件行为。

| 内容 | 装载时机 |
|---|---|
| 核心指令 | 每次创作的基础要求 |
| 视觉表现激活地图 | 建立广域构思入口；按相关关系使用 |
| 运动与物理表现机会 | 动作、材料、环境和相互作用是重点时 |
| 跨域关系与艺术发展 | 单项细节丰富但整体常规，或需要新的组织方向时 |
| 二维与风格转译 | 日式二维、绘画、图形化或风格迁移时 |
| 同一事件的艺术变体 | 候选只是换修饰，或第一种方案过于常规时 |
| 过程展开与关联发展 | 已想到现象，但可见过程或多层联系不足时 |
| 观察证据与视觉形式 | 需要不同观看方式，或形式本身是主要目标时 |
| 日式二维的多种表现发展 | 需要具体画法与演出差异，而非只换风格词时 |
| 输出与信息保留 | 默认提示词及其他交付的表达约定 |
| 既有表现卡、知识卡、证据 | 核心现象需深入，或存在重要条件不确定时 |

只有核心指令也应主动使用模型自身知识；不能以“资料没加载”为理由退回普通场景复述。反过来，不能宣称使用了不可访问的文件。资源标题不等于全文；路由也不会自动读取链接。

## 给模型的任务示例

“请按 Visual Direction Lab 的要求，设计一个少女站在雨中的日漫镜头，默认直接给完整提示词。”

“同一个奔跑急停回头的创意，请提出观看重点实质不同的方案，并说明选择；不要只增加效果数量。”

“保留这份艺术设计的核心关系，转成视频生成提示词，再指出哪些信息被压缩。”

无需每次提供专业词汇或指定调用模块。模型自行判断相关性，不向用户展示资料命中列表。示例是使用方式，不是每个任务的固定格式。

## 当前限制

v0.5 是依据上述首轮问题的候选修订；已做[四项仅核心复查](../评估/实际试验/DeepSeek-v0.5-定向复查/复查报告.md)与[12 项相关资源对照](../评估/实际试验/DeepSeek-v0.5-资源对照/资源比较报告.md)。选定资源能唤起具体表现，但连接、轴向与空间关系仍有失败；仅按开发者预定选段装载，不能证明自动路由或稳定改善。另完成[四个新场景、8 次母版与转换请求](../评估/实际试验/DeepSeek-v0.5-母版转换/母版转换报告.md)，转换加载输出约定全文；主要关系大体保留，也继承母版问题并丢失部分取景条件。没有直接成稿对照，不能证明两阶段或输出约定的独立效果。三个完整包尚未重新对照。具体改动与使用边界见[v0.5 说明](../维护/v0.5-基于首轮测试的优化.md)。

已完成 [DeepSeek 首轮 16 项有效对照](../评估/实际试验/DeepSeek-v0.4-首轮/首轮比较报告.md)，每场景每条件仅一次。部分表现更具体，但更长的深化包未稳定胜出，仍有连接、空间和依据问题。没有独立盲评、跨模型或成片验证；已有开发例子仍为手工材料。效果依赖模型本身、实际读取内容和任务条件。冻结包中的验证声明是构建时状态，不因此修改旧试验输入。使用时保留输入、版本及输出，可按[v0.4 评估说明](../评估/v0.4-深化资源评估.md)比较。研究原型 v0.1 用于历史比较，旧 v0.3 单文件包保留。
