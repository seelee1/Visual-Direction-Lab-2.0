# v0.3 公开开发场景与文本审查

本页是评审侧开发材料，不默认提供给主创作模型。以下为人工构造的任务、设计机会与失败风险；没有执行独立模型测试。预期方向不构成标准答案，其他有效方案可以更好。

| D32 | 5 秒，少女站在雨中，日式二维，白天；不要自动赋予悲伤 | 全身远景，禁止发丝飘动、眨眼和呼吸作为主要表现 |

## 公开文本审查：资源是否有可用方向

以下只是对文档的开发审查，不是模型输出或效果证明。每场景列两种机会，检查新资源能否支持不同重点，也检查是否容易退回套路。

**D31：动作与接触 / 空间与观察。** 可以从支撑与停止姿态发展，也可以在保留脚部证据的前提下让固定画幅中的运动余地改变用途。风险：把所有身体层都写成回弹；空间方案删掉用户要求的关键动作。修订：核心指令把层的状态分开，要求核心证据保留，不固定停止形式。

**D32：雨层空间 / 本体与倒影。** 可关注前后雨层与遮挡，也可在条件合适时让水面变化对照主体保持。风险：倒影变成每次雨景的答案；远景仍描述发梢单滴过程。修订：地图提供替代入口，要求按尺度重译；允许主要以线色和空间表达。

**D33：接触关系 / 负形与信息。** 可看承重交接与手势，也可看两人之间的空隙随交接开合。风险：为了显得细腻拉长停顿，把普通交接演成犹豫。修订：快速自然任务允许流畅无停顿，取舍服从用户节奏。

**D34：连续流路 / 图形化形态节奏。** 可突出源、液面与去向，也可用二维主形和边缘组织表达同一过程。风险：转译后只剩抽象水线，流入溢出关系丢失。修订：输出约定保留事件关系，不把简化等同于删除原因和后果。

**D35：差异响应 / 环境层级。** 可观察不同载体响应，也可关注远近区域和遮蔽关系。风险：全部同速同幅；反过来强制每层按固定延迟依次动作。修订：入口提醒条件判断，关系可以重叠而非统一顺序。

**D36：连接与停止 / 朝向与观看。** 可通过门轴、支撑和运动终止表现结构，也可通过距离与朝向改变表现目标回应。风险：泛写“机械精准”，或为无脸对象添加人类情绪符号。修订：具体连接和可见变化优先，不要求拟人。

**D37：共同方向与形态 / 峰值和辨认锚点。** 可让水、袖、光的主形汇聚，也可组织短暂失读与清晰结尾。风险：为了安全退回稀疏场景，或每层独立爆发。修订：核心指令允许高密度与有意形式规则，关系资源提供整体组织而非效果清单。

**D38：轮廓与负形 / 色块与时间。** 可通过遮挡和图底关系显现，也可通过色块比例及一次节奏变化建立形。风险：强加故事含义，或必须寻找物理因果。修订：纯形式价值明确有效，艺术关系与物理因果分开。

## 尚未证明的部分
