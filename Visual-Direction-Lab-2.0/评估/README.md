## 怎样继续评估

先确定场景、版本、条件与交付，再冻结材料和请求。记录实际发送内容、装载方式、模式与不可控项；完整保存失败，不挑选漂亮样本。母版转换是顺序依赖，转换输入在对应母版采集后冻结，不能声称所有输入预先冻结。

审查分开用户要求、核心表现、成立条件、形式节奏与实际观看；明确问题出现在构思、转换、生成或合成。案例已经公开就作为开发场景，不再冒充未见测试。条件隐藏文件只算评审准备，实际独立评审才可称盲评。
