# Visual Direction Lab 2.0

当前模型使用候选：v0.5 · 2026-10-10；根据首轮实际测试优化核心、相关资源与成稿表达。

帮助 GPT 等语言模型充分调动已有视觉知识，把简单创意发展成丰富、具体、协调的视觉设计。核心资产是构思入口、表现可能性、关系推演和艺术判断。专业资料为必要的深入和校核提供支持；不要求模型先学习一套百科再创作。

## 项目结构

| 目录 | 作用 | 模型的使用方式 |
|---|---|---|
| `模型使用/` | 当前核心指令、构思资源、输出约定与资源路由 | 日常创作使用；只调用相关部分 |
| `发布包/` | 从当前源文件生成的可复制单文件版本及清单 | 不能装载多个文件时使用；与模块版择一 |
| `交付/` | 整体架构、转换规范、部署与当前状态 | 完整项目导读；转换与交接时按需提供 |
| `研究资料/` | 既有研究、150 张知识卡、120 张表现卡、案例和历史实验 | 按需参考；研究报告不默认加载 |
| `评估/` | 新方向的对照协议与公开开发场景 | 评审时使用；不放进主创作上下文 |
| `维护/` | 版本说明、构建与结构检查 | 维护项目使用 |

既有根目录内容已整体迁入 `研究资料/`，内部层级保留；旧文件名和 E/K 等编号没有重编。原始 [DeepSeek 样本](../测试样本-1.md)仍在项目外一层的原位置。历史内容入口为[研究资料目录](研究资料/README.md)，迁移记录见[修订说明](维护/v0.3-结构与方向修订.md)。

## 本轮变化与边界

v0.3 建立视觉激活地图、运动物理机会、跨域关系、二维转译四组资源。v0.4 新增[同一事件的艺术变体](模型使用/构思资源/05-同一事件的艺术变体.md)、[过程展开与关联](模型使用/构思资源/06-过程展开与关联发展.md)、[观察证据与视觉形式](模型使用/构思资源/07-观察证据与视觉形式.md)、[日式二维的多种发展](模型使用/构思资源/08-日式二维的多种表现发展.md)。它们提示模型展开自身知识、寻找新方案，不是效果配额、物理教材或封闭白名单。

“丰富”同时包括表现范围、展开程度、关系组织和艺术选择；安静、简洁、密集、抽象的作品都可成立。默认交付完整连续的视频提示词，也支持艺术构思、静态画面、分镜和制作交接。

v0.5 改写已有入口的连接与轴向条件，补充连续协作、持续发展与非描边式显现，区分动态光影的驱动来源，优化最终方案的确定性与参数表达。范围和资源编号保留，未添加每次执行清单。已完成[四项仅核心复查](评估/实际试验/DeepSeek-v0.5-定向复查/复查报告.md)及[12 项相关资源对照](评估/实际试验/DeepSeek-v0.5-资源对照/资源比较报告.md)：选段能唤起更具体的关系，但连接、轴向与空间衔接仍未稳定解决。资源选段由开发者预定，包含简短举例；本轮不是纯例子消融、自动检索或完整包测试，不声称能力提升。改动依据、取舍及验证边界见[v0.5 修订说明](维护/v0.5-基于首轮测试的优化.md)。

v0.4 已整理为可使用的候选包；[本轮开发示例](评估/v0.4-发展示例与反向审查.md)为手工设计材料。另已完成 [DeepSeek 首轮实际对照](评估/实际试验/DeepSeek-v0.4-首轮/首轮比较报告.md)：4 场景 × 4 条件 × 1 次，共 16 项有效回答，另 1 项模式偏差排除。资源能唤起部分具体关系，但深化版没有稳定胜过仅核心指令；仍有空间、连接及依据不足问题。未做独立盲评、跨模型或视频验证，不构成统计可靠性证明。冻结发布包中的验证声明是构建时快照，最新状态以比较报告为准。历史 144 个实验请求保持原冻结版本，本轮不是它们的执行结果；旧 v0.3 单文件包保留，迁移见[v0.3 说明](维护/v0.3-结构与方向修订.md)，本轮见[v0.4 修订](维护/v0.4-资源深化与验证状态.md)。

已补[四个新场景的母版与转换诊断](评估/实际试验/DeepSeek-v0.5-母版转换/母版转换报告.md)，完成 8 次独立新会话请求，覆盖安静、移光、水面倒影与雾的空间变化。主要关系大体保留，母版已有的可见性与空间缺口也被继承；另有取景条件在转换中丢失。该诊断不证明两阶段优于直接成稿，流体和自然过程尚未全面覆盖。

后续先维持整体交付与版本衔接，选择实际环境完成端到端交接；扩大不同模型、取向与条件迁移验证。局部修订随后按失败分类开展，不以继续增加条目代替效果验证。维护方法见[维护说明](维护/README.md)。
