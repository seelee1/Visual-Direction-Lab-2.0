# 统一导出

[视觉助手.zip](视觉助手.zip)由[构建工具](../项目记录/版本与工具/构建输出适配包.ps1)自动生成，原样包含完整“创作系统”目录。

解压后统一读取“创作系统/入口.md”。只有这一套入口和正文，不提供按模型区分的独立助手；目标模型只决定交付时的格式。

压缩包是源目录的发布副本，不在这里维护正文。适用于能读取解压目录的 Agent；仅能粘贴文本、不能访问文件的环境无法通过一个路径取得整套资料，不将链接当作已加载内容。

项目记录与维护工具不装入运行包。正文指向项目记录的链接属于源项目中的验证证据；包内“导出说明.md”明确这一边界，不能声称已访问未附带证据。

构建后检查每个打包文件与来源是否一致。更新后的包需手动替换外部副本，本项目不会自动修改其他 Agent 配置。
