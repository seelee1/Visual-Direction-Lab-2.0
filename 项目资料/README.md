# 项目资料目录

[返回使用首页](../README.md)。本目录保存源文件、体系文档、研究和验证材料；直接使用的两个文件位于根目录 `使用/`。

| 目录 | 内容与用途 |
|---|---|
| [模型使用](模型使用/README.md) | 当前核心、构思资源、输出约定和独立模型适配；模块加载与源文件维护 |
| [交付](交付/整体交付与当前状态.md) | 整体交付状态、体系架构、艺术设计到提示词的转换规范和部署方法 |
| [研究资料](研究资料/README.md) | 专业研究、知识卡、表现卡、原始参考样本与历史实验；按需深入 |
| [评估](评估/README.md) | 测试协议、开发场景、实际对照记录和分析；评估时使用 |
| [发布包](发布包/README.md) | 通用单文件包、历史版本和构建清单 |
| [维护](维护/README.md) | 构建、完整性检查、结构迁移与版本说明 |

体系与判断见[设计原则](交付/体系架构与设计原则.md)，成稿与制作交接见[转换规范](交付/艺术设计到提示词与制作交接规范.md)。历史版本与验证边界见[项目沿革](维护/项目沿革与验证记录.md)。

研究、测试答案和版本记录不默认装入创作模型；根据任务加载相关创作资源。
