# v0.5：基于首轮测试的优化

日期：2026-10-10。依据 [v0.4 首轮实际比较](../评估/实际试验/DeepSeek-v0.4-首轮/首轮比较报告.md)修订模型使用材料，目标仍是激活模型自己的知识和艺术判断。v0.5 是候选修订，不是已经验证优于 v0.4 的版本。

## 优化落点

| 首轮暴露的问题 | 实际改动 | 希望保留的创作空间 |
|---|---|---|
| 共挂钥匙被写成串联链；轻重或材料名直接决定响应 | 改写 M-A13、M-A14、M-A16 和 R-A01，按实际连接选择共同驱动、传播或碰撞；核心用条件审查替换原检查段 | 同步、差异、错峰和局部保持都可选；不要求所有运动一致 |
| 搬运时长轴、板面、倾斜和通行路径混淆 | M-A04、M-A07 与 S-V05 发展支撑分工、轴向和连续协作，输出约定保留必要方向证据 | 托举、翻面、侧转、补位、顺畅通过或受阻调整均可发展 |
| 回头目标与脚部构图含糊 | S-V01 区分来路与镜头目标，为接点选择足够景别；核心和输出约定强调观察证据 | 不禁止对镜头表演；依据用户任务与选定空间决定 |
| 光影只剩气氛标签 | R-A05、S-V01、P-D08 补固定照明、越过遮挡、移动光源的不同发展关系 | 光影可协同动作，也可独立成为主角；不规定每次出现光效 |
| 总是先受阻再调整，最后所有层归稳 | 核心、关系资源与 P-D02/P-D05 允许连续协作、直接完成、持续发展及未完成结尾 | 保留制动、回弹、戏剧高潮等原有机会，不以反向模板替代 |
| 抽象任务总是描边填色；闭合后缺口缺少过渡 | S-V14 补线群间隔重排、色面邻接与局部显现；输出约定要求状态转变留下证据 | 轮廓生成仍可采用，歧义或开口也可有意保留 |
| 成稿保留“六边形或花瓣”等未决项 | 默认成稿明确选择；探索任务再交付候选 | 不削弱探索范围，只区分探索与最终交付 |
| 像素、比例、周期等伪精确与排除项膨胀 | 输出约定采用可辨关系或有尺度的参数，保留必要限制；核心交付段同步调整 | 可用数值、夸张和非现实节奏，但说明其制作或艺术职责 |

主要是替换已有段落和资源行，不新建一套每次必查的流程。核心正文相较 v0.3 增加 144 个字符；资源编号保持，已有 36 个运动入口、16 个关系入口及 57 个深化入口仍可检索。未改旧研究卡，未重写旧测试答案。

## 使用与版本组织

- 模型运行入口仍为 `模型使用/`，主指令、资源、输出约定分开。路由和使用说明更新到 v0.5。
- [基础版](../发布包/VDL-v0.5-基础版.md)、[扩展版](../发布包/VDL-v0.5-扩展版.md)、[深化版](../发布包/VDL-v0.5-深化版.md)重新构建，分别为 5822、13298、22892 个字符，非 token 数。
- v0.3 两个包及 v0.4 三个包原文保留；v0.4 清单存入 `发布包/历史/`。历史清单的源文件哈希对应当时源码，不要求当前源码仍与它们一致。
- 当前清单记录当前源码和包哈希；历史检查验证五个旧包，试验检查验证各轮独立冻结输入和回答。不会把 v0.4 的 16 次有效运行计入 v0.5 效果验证。

只需少量资源即可发展当前关系时按相关内容使用；需要广泛探索时可用整包。首轮没有验证哪种加载方法最优，不能把模块化当成已证实的性能结论。

## 反向审查：避免修订成为新套路

下面是开发者对文档意图的审查条件，不是独立模型已通过的测试，也不是应加载到创作上下文的答案。

| 场景变化 | 修订仍应允许怎样的发展 | 应发现的过度限制 |
|---|---|---|
| 多人搬物顺利经过宽门 | 可发展分工、手位、步幅与影形，不必制造碰撞 | 把“顺畅”固定成必须安静或不能有重量变化 |
| 真正的串联吊饰受拨动 | 在实际结构中发展局部传递、接触与不同响应 | 为防错误传播而禁止所有延迟和连锁 |
| 少女明确看向镜头 | 按指定目标建立视线与身体转向，保留脚部要求 | 把回望来路变成永久唯一答案 |
| 非现实色块背景有意滑移 | 明确图形层规则，用主体身份、接点或方向保持理解 | 把固定镜头误解成所有图层都禁止运动 |
| 光源移动而人物不动 | 由表面、遮挡、投影或反射发展独立照明事件 | 强求人物动作驱动每一次光影变化 |
| 连续生长或循环形式作品 | 可继续变化或明确循环闭合，不必定格为完整形 | 将未完成结尾或不稳定状态规定成“更有艺术性” |

## 复查与尚未解决的事

新增 [四项核心指令定向复查](../评估/实际试验/DeepSeek-v0.5-定向复查/复查报告.md)，保持原场景和交付约定。仅装载 v0.5 核心，对照参照是上一轮仅核心输出，非同期随机对照；没有测试新资源全文、输出约定文档、整包或视频。

结果没有证明稳定改善：搬运不再先碰门、抽象方案没有出现闭合后无过渡的缺口，但连接差异、搬运轴向、回头目标与景别问题仍出现，两项还短于要求。保留全部失败记录，没有改写答案或选取漂亮样本。

因此不继续往核心添加逐错误禁令。复查后的计划是比较核心与相关资源，并进一步分离例子及篇幅因素。当前版本保持可用、可回退、可比较的候选状态。

## 后续实际资源对照

已完成[12 项相关资源对照](../评估/实际试验/DeepSeek-v0.5-资源对照/资源比较报告.md)：同轮四个公开场景比较核心、通用相关选段、追加场景变体。钥匙没有对应场景变体，两次资源请求完全相同，作为同文重复；因此只有 11 种独特输入。通用选段本身包含短例，追加段还增加方向、条件与篇幅，未完成纯例子移除或长度控制实验。

选段更容易唤起支撑、遮挡、负形与光影等具体表现；共挂与串联、长轴转动与朝向改变、运动留白与回望空间仍未稳定区分。保留全部输出，不以细节增加判成功。没有独立盲评、跨模型、完整包或视频验证；当前累计 32 项有效模型回答另 1 项排除，不能将不同版本与条件混成效果样本。

本轮只更新评估与使用状态，v0.5 创作源码和发布包保持冻结。下一步先分开观察简短艺术母版与提示词转换，定位关系问题在构思还是压缩中产生；同时补安静场景、复杂动态光影、流体和自然过程，避免持续围绕四个公开案例调词。例子消融、长度控制与重复对照仍待执行。

## 新场景母版与转换诊断

后续已完成[四组母版与独立成稿、共 8 次请求](../评估/实际试验/DeepSeek-v0.5-母版转换/母版转换报告.md)，覆盖安静教室、柱间移光、水盘倒影和雾过树林。母版仅加载核心，转换仅加载要求、母版和输出约定全文，不加载评审意见。母版请求预先冻结，转换请求待原文采集后逐项冻结；未做直接成稿对照或重复采样。

成稿保留多数主线，也继承不可见的观察重点、未定照明条件、未明示图形规则和遮挡层次矛盾；柱间场景另丢失柱脚与地面取景要求。因此后续修订需分别处理母版成立与转换保留，不能统一归咎于压缩。此时累计 40 项有效回答、1 项历史排除、0 项视频；本轮未更改创作源码和发布包。下一次候选修订以泛化的观看条件、关系成立和冲突交接为重点，不增加逐案例答案或强制教学步骤。
