# 维护与冻结约定

当前创作源码在 `助手指令/共用内容/`，当前版本为 v0.5 候选。完整交付规范另在 `视觉表现资源/设计说明/`；其补充不自动改写核心或既有发布包。

当前两模型输出适配在 `助手指令/共用内容/输出适配/`，版本 v0.2，分别维护。`构建输出适配包.ps1` 从同一个基础版和各自适配生成两个独立使用包，Anima 另装入静态表现资源 v0.1，清单分别记录来源和包哈希；管理入口不打包，也不包含另一模型规则。不会覆盖原三个通用包；旧合并包撤下，原文在 Git 历史保留。适配源码变动后重建，基础内容变化时先处理原包版本，再重建适配包。

## 日常维护

当前布局见[目录整理说明](目录整理说明.md)。根目录 `助手指令/` 为生成后的直接使用文件；本目录及 `助手指令/共用内容/` 为维护来源，研究与评估记录按需查阅。

只重建两个模型使用文件时，从仓库根运行：

```powershell
pwsh -File ./历史归档/版本与工具/构建输出适配包.ps1
```

使用 PowerShell 7 从仓库根运行：

```powershell
pwsh -File ./历史归档/版本与工具/检查项目.ps1
```

检查本地 Markdown 链接、编码、JSON、资源编号、当前包与源码哈希、历史包、旧冻结请求及实际试验保存记录。通过只说明文档结构与保存完整性，不证明物理、艺术、外部链接可访问或模型效果。

只有决定发布新的当前包并完成版本安排时才运行构建：

```powershell
pwsh -File ./历史归档/版本与工具/构建使用包.ps1
```

该脚本会写当前 v0.5 包和清单，不用于每次阅读或验证。新增版本先保存旧包和清单，再调整构建目标；不覆盖旧试验输入。构建清单描述构建当时状态，实时测试总览看[评估入口](../../创作案例与验证/README.md)。

## 试验工具

`创作案例与验证/` 的准备程序按批次建立冻结材料，记录程序采集已经取得的网页回答；它们不是自动联网测试客户端。准备目录存在时通常拒绝覆盖。不要为重新运行删除历史目录，使用新批次并明确版本。母版转换程序按依赖逐项冻结转换输入，不能提前伪造母版或结果。

历史研究下的准备程序仍服务原实验，不能与当前试验混用。当前有效 40 项、排除 1 项；原 144 项仅准备未运行。

## Git 与字节保存

仓库 `.gitattributes` 禁用自动换行转换，原因是历史材料、输入、输出和包按原始字节计算 SHA-256。编辑器改写冻结文件的换行也会导致检查失败。非冻结说明可以编辑；冻结文件不为了格式美化重新保存。

`.gitignore` 排除环境、缓存与密钥文件，保留研究、案例、原始试验和装载页。GitHub 提交保存完整文档项目，不将仓库创建或提交成功写成生成效果验证。未指定开源授权，不自行添加开源许可证。
