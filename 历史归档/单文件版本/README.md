# 通用与历史发布包

当前 Anima 和 MiniMax-H3 的直接使用文件见[使用首页](../../README.md)，由共用基础版与一个对应适配构建。

本目录保存模型无关的通用包和冻结版本，用于模块加载替代、版本比较及维护：

- v0.5 基础、扩展、深化版是当前通用候选；选择方法见[模块使用说明](../../助手指令/共用内容/README.md)。
- v0.3 与 v0.4 包保留构建时原文，验证声明是当时快照。
- `历史/` 保存历史包清单；当前清单用于检查源文件与生成文件是否一致。

旧包不作为日常默认入口，不能与当前包混合加载。最新验证状态见[评估目录](../../创作案例与验证/README.md)。
