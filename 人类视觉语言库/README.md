# 人类视觉语言库

把人看得懂、却常常说不出的视觉经验，转成具体可用的描述。人说“坐下”“转身”“打拳”时，现实已经包含支撑、牵拉、接触、形变与环境响应；生成提示词未必自动展开这些关系。Agent 主动辨认并表达这一层，不要求用户先掌握专业术语。

## 如何使用

从[日常经验索引](日常经验索引.md)找到与当前动作或场景相关的关系，读取对应条目。结合对象、材料、连接、动作和镜头条件，把可见变化写进作品。已经明确要表现的自然细节应充分展开，不能因为“现实中自然发生”就省略，也不必给每个细节另找剧情寓意。

这里是检索与表达支持，不是每次向用户展示的流程。Agent 可以直接调用可靠知识，库中缺项不妨碍创作。不要全库遍历，不逐个关节机械排程；细致来自同一事件中相互成立的变化，而不是对象各演一段无关动画。

## 内容分工

| 层 | 职责与入口 |
|---|---|
| 日常经验 | [索引](日常经验索引.md)：从普通人的说法查找关系，允许同一句话关联多个领域 |
| 条件与过程 | [身体与接触](关系条目/身体与接触.md)、[衣发与柔性材料](关系条目/衣发与柔性材料.md)、[空间与光影](关系条目/空间与光影.md)：描述成立条件、可见过程与表达示例 |
| 表达方法 | [表达与维护](表达与维护.md)：将关系写成镜头或静态画面，区分知识、设计和验证 |
| 艺术发展 | [视觉表现资源](../视觉表现资源/README.md)：发展造型、风格、形式、构图与时间组织 |
| 专业依据 | [参考资料](../参考资料/README.md)：既有知识卡、表现卡与来源；按需要深入 |
| 模型交付 | [输出适配](../助手指令/输出适配/README.md)：最后转换格式，保留选定关系 |
| 实际反馈 | [案例与验证](../项目记录/创作案例与验证/README.md)：保存真实输入、输出及观察，不能用生成结果反推自然规律 |

首批关系条目是依据项目已有资料整理的条件化表达示例，不是新的实拍观察或模型验证。专业卡片保持原位，条目链接到它们，不复制成第二套知识库。新增领域沿相同结构扩充，不为尚未研究的主题建立空文件。
